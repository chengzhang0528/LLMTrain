# 概率与 softmax

概率是 0 到 1 之间的数，一组互斥候选的概率总和为 1。模型内部先产生任意实数分数 `logits`，再用 softmax 转成分布。

假设两个候选的 logits 是 $[0, 1]$：

1. 取指数得到约 $[1.00, 2.72]$。
2. 总和约 $3.72$。
3. 各自除以总和，得到约 $[0.27, 0.73]$。

softmax 保留排序并放大差距，但它不证明 0.73 是“现实中 73% 正确”。这是模型在当前条件和训练目标下分配的概率质量。

温度可以理解为调节分布尖锐程度：温度较低通常更集中，较高通常更分散。温度为 0 常在软件中被实现为贪心选择，而不是直接代入 softmax 公式。
