# 模型系列论文目录审计

核查日期：2026-08-09。本页记录 [论文库](../06-拓展知识库/论文研读/01-论文库.md) 的收录范围、官方来源和版本空白，防止课程把产品发布、论文和第三方评测混为一谈。

## 核查方法

1. 先查模型团队的官方 GitHub 组织与仓库 README。
2. 对仓库中列出的 arXiv 编号核对标题、日期和作者；稳定链接统一使用 `https://arxiv.org/abs/<id>`。
3. 没有 arXiv 编号但官方仓库随附完整 PDF 的，标为“仓库随附报告/论文”。
4. 只有博客、模型卡或 README 的版本，标为“发布说明”，不补写虚构的论文编号。
5. 第三方使用某模型做实验的论文不计入模型家族主干，后续可进入可靠性、Agent 或系统专题的外部证据。

## 证据边界

- arXiv 是公开预印本平台，不等同于同行评审通过。
- 官方技术报告是最接近团队实现的一手材料，但仍包含作者自评和发布叙事。
- 模型卡能核对配置、许可证和运行说明，通常不能提供完整因果消融。
- 官方博客适合记录发布时间和产品定位，不负责证明机制有效。
- 仓库 benchmark 图片和表格必须记录代码版本、硬件、精度、上下文和评测 harness。

## 维护要求

论文库每次新增条目都要同步更新本页的核查日期或版本空白。若正式论文后来出现，应保留旧发布说明的历史角色，再把新论文登记为独立条目；不能悄悄把旧来源 URL 替换后声称当时已经有论文。
