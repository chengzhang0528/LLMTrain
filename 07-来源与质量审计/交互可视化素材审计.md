# 交互可视化素材审计

核查日期：2026-08-09。本页记录“动画学习 AI 模型”相关成熟项目的一手来源、适用边界和本站使用决定。它不是转载授权清单：即使代码采用开放许可，项目截图、商标、论文图和站点文案仍不自动等于可以无条件复制。

## 审计结论

### Transformer Explainer

一手来源：[官网](https://poloclub.github.io/transformer-explainer/) · [论文](https://arxiv.org/abs/2408.04619) · [仓库](https://github.com/poloclub/transformer-explainer)。它可检查浏览器内 GPT-2 风格小模型的 token、Embedding、Attention、MLP、logits 与采样。仓库标注 MIT。本站吸收“同一输入贯穿全链、局部放大、参数即时反馈”，不复制截图、SVG、文案或实现。

### CNN Explainer

一手来源：[官网](https://poloclub.github.io/cnn-explainer/) · [论文](https://arxiv.org/abs/2004.15004) · [仓库](https://github.com/poloclub/cnn-explainer)。它可检查图像分类网络中的卷积核、特征图、池化与类别证据，仓库标注 MIT。本站用它规划多模态前置课中的局部到整体视觉，不把单一分类网络当作全部视觉模型。

### GAN Lab

一手来源：[官网](https://poloclub.github.io/ganlab/) · [仓库](https://github.com/poloclub/ganlab)。它可检查二维真实分布、生成分布、判别边界与两方训练动态，仓库标注 Apache-2.0，并使用浏览器内 TensorFlow.js。本站吸收“同时展示互相作用的状态”，只把它作为对抗训练动力学的玩具模型观察。

### TensorFlow Playground

一手来源：[官网](https://playground.tensorflow.org/) · [仓库](https://github.com/tensorflow/playground)。它可检查小型前馈网络、特征、层数、激活、loss 与二维决策边界，仓库标注 Apache-2.0，并注明并非 Google 官方产品。本站吸收“单变量控制、即时反馈、预测边界”，不把二维分类结果泛化为 LLM 训练规律。

### LLM Visualization

一手来源：[官网](https://bbycroft.net/llm) · [仓库](https://github.com/bbycroft/llm-viz)。它可检查 GPT 风格网络中的参数、激活、算子和层级关系；GitHub API 未识别到仓库许可证，仓库说明首个带权重示例是微型字母排序网络。本站只观察和引用官方链接，不复制代码或资产，并吸收“从参数点阵缩放到算子”的空间导航。

### Embedding Projector

一手来源：[官网](https://projector.tensorflow.org/) · [论文](https://arxiv.org/abs/1611.05469) · [旧独立仓库](https://github.com/tensorflow/embedding-projector-standalone)。它可检查高维向量的邻域、标签、PCA、t-SNE 与三维投影。旧独立仓库已归档，GitHub API 未识别到许可证。本站用它教授投影边界，不下载内置数据或复制界面，引用时记录模型、层、样本和投影设置。

### BertViz

一手来源：[仓库](https://github.com/jessevig/bertviz) · [论文](https://arxiv.org/abs/1906.05714)。它可检查 Transformer 的层、头、token 连线及 Query/Key 神经元视图，仓库标注 Apache-2.0，主要面向 Jupyter/Colab。本站把它作为 Attention 局部观察参考，并保持纯前端，不要求学习者运行 notebook。

## 为什么确认是 Transformer Explainer

用户截图中可见 `TRANSFORMER EXPLAINER` 标识、Embedding、Multi-Head Self Attention、MLP、多个 Transformer Blocks、候选概率，以及 temperature、top-k 等控制。它们与 Georgia Tech Polo Club 官方项目的界面和功能一致。官方仓库说明该项目允许学习者输入文字，并实时观察 GPT 风格模型怎样预测下一 token。

项目论文在 arXiv 以 `2408.04619` 发布；官方仓库当前还列出后续 CHI 2026 版本。课程引用具体结论时应优先注明所用版本，不把论文年份、会议版本和当前在线界面混成同一时间点。

## 可吸收的共同设计

1. **身份连续**：输入样本在总览和局部图中保持同一名称、顺序和颜色。
2. **结构与数值同时可见**：既能看到层之间怎样连接，也能看到当前数据或概率怎样改变。
3. **单变量控制**：一次只改变一个参数，并立即显示可归因的结果。
4. **多尺度导航**：先看整体，再放大一层、一个头、一个神经元或一次矩阵乘法，最后返回整体。
5. **观察任务先行**：界面不只提供自由拖动，还明确告诉学习者应盯住什么、暂停后回答什么。
6. **玩具模型诚实标注**：小模型用于看清机制，不宣称代表所有现代模型的规模、数据或能力。
