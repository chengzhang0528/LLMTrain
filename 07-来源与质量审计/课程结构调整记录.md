# 课程结构调整记录

调整日期：2026-08-08。

## 本次调整

- 课程定位从“固定天数训练课”改为持续更新的开放学习系统。
- D01-D21 保留为基础闭环的稳定模块编号和兼容路径，不再作为学习时限或完成承诺。
- 新增全局知识图谱与能力路线入口，明确训练链、推理链和应用链的责任边界。
- 新增小模型与蒸馏路线，覆盖从零训练、适配小基座、回答/logit/特征/策略蒸馏、量化、剪枝、QAT 和部署对照。
- 新增前沿瓶颈地图，将数据、训练、长上下文、推理、部署、多模态、Agent 与可靠性按问题组织。
- 新增学科地图，允许按模型生命周期、可观察现象、实际项目和研究瓶颈四个角度进入同一套课程。
- 建立五个专题课程群：幻觉与可靠性、模型后训练、实际模型案例、多模态基础、软硬件瓶颈。每组统一包含现象集合、课程单元、案例证据与失败边界。
- 明确课程四层结构：理论基础、案例闭环、专题课程、研究前沿。D01-D21 继续作为基础闭环编号，不承担整个领域的广度上限。
- 前端新增通用课程浏览组件，课程标签、说明、链接和产物仍由 Markdown 提供，未把课程正文复制到组件。
- 术语表补充模型幻觉、解码策略、后训练、置信度校准、模型拒答、灾难性遗忘、模态对齐、显存带宽、HBM、推理延迟与吞吐等跨专题概念。

## 第二轮：从目录覆盖到正式课程

- 为 D01-D21 全部增加“为什么要学这一课”，从真实困惑说明学习必要性、缺失后的误判和后续连接；内容检查将其作为强制项。
- 新增“课程为什么这样安排”，解释神经网络为何是大模型必修，以及一般机器学习算法、历史模型和数学急救的主线或选修边界。
- 将幻觉与可靠性、模型后训练、实际模型案例、多模态基础、软硬件瓶颈从单页总览扩展为 25 个正式单元。
- 每个专题单元统一包含学习导航、本课目标、学习必要性、具体数字或场景、本课验收和方法边界。
- 专题侧边栏由统一课程清单生成；内容检查会验证 25 个文件存在且结构完整，避免目录、导航和正文漂移。
- 术语表同步新增模型基线、事实性、证据忠实度、prefill、连续批处理、分页 KV Cache 和内存墙。

## 仍需持续复审

课程不会因为增加专题就变成“全部大模型知识”。每个前沿模块都要在后续版本中补充一手来源、硬件与软件版本、独立评测和失败样例。新模型案例不得替代稳定原理，也不能把作者主张写成普遍规律。

## 第三轮：一级目录与推荐顺序

- 一级目录按第一次学习顺序重排：开始与路线、理论基础、按需学习辅助、训练过程案例、实际模型案例、方法与质量专题、前沿瓶颈、论文研读、速查和质量审计。
- 删除重复的“专题课程群”一级项；拓展知识库总览保留在开始学习区，各专题直接作为后续学习阶段。
- 数学急救包与图解材料合并为“学习辅助（按需）”，明确它们在主线卡住时调用，不构成完成理论课前的额外门槛。
- Kimi K3 不再以具体模型名称占据一级课程目录，归入“论文研读”案例；稳定方法、当前瓶颈和具体论文分层展示。
- 推荐进阶顺序统一为：实际模型案例、模型后训练、幻觉与可靠性、小模型与蒸馏、多模态基础、软硬件瓶颈、前沿瓶颈、论文研读。

## 第四轮：当前浏览器学习记录

- 建立统一学习单元清单，覆盖理论基础、训练过程案例、实际模型案例、后训练、可靠性、小模型与蒸馏、多模态、软硬件、前沿、论文以及按需数学和图解材料。
- 学习位置、完成或跳过状态、题目草稿、选项、作答结果和复习日期只保存在当前浏览器，不增加账号、后端或跨设备同步。
- 阅读与掌握拆成两个状态维度，允许“已读完但待复习”；首页、课程工具条、侧边栏和学习记录页共享同一状态源。
- 首页提供小说式续读入口，保存最近标题和滚动位置；带锚点的直接链接优先服从链接本身，不强制恢复旧位置。
- 错题、部分正确和到期题进入复习队列，并按 1、3、7 天起步的间隔规则安排后续复习。

## 第五轮：模型运行主干与纯前端案例边界

- 将 D07 提升为“模型一次运行到底发生什么”，从消息模板、token ID、Embedding、Transformer、logits 和采样串到输出，并补充 prefill、KV Cache、decode、流式返回和推理引擎责任。
- D07 使用两组分步铅笔动效：第一组解释一次 token 选择的完整数据形态变化，第二组解释 prefill 与 decode 循环。动效只承载状态变化，不把课程正文写进 Vue 组件。
- D15-D21 保留旧路径以兼容链接和浏览器学习记录，显示内容改为“训练过程案例”，使用预生成环境快照、数据统计、张量形状、训练日志、对照结果和模型卡。
- 全课程改为纯前端、非实操教学：学习者不安装环境、不执行命令、不编程、不训练或部署模型，也不上传数据或调用外部服务。
- 实际项目、后训练、可靠性、多模态和软硬件专题使用课程提前准备的案例档案。学习目标改为解释流程、审查证据、比较方案和定位失败。
- 仓库开发命令与课程学习任务明确分开；前者仅供站点维护者使用。
