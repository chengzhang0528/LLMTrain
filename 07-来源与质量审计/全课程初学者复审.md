# 全课程初学者复审

复审日期：2026-08-08。范围包括理论基础模块、训练过程案例、数学急救包、图解材料、速查表与 Kimi K3 拓展。复审目标不是继续增加术语，而是检查初学者能否把知识接起来、算出来、说出来并在预设案例中认出来。

## 七个审查问题

每一页都从下面七个角度检查：

1. **先修关系**：正文是否使用了尚未解释的对象、符号或代码动作？
2. **概念深度**：是否只给一句类比，还是说明了输入、动作、输出与边界？
3. **具体到抽象**：是否先用具体数字完成计算，再压缩成公式？
4. **标题闭环**：小例子结尾是否明确回答标题提出的主张？
5. **上下文联系**：是否说清从上一课带来什么、下一课会拿它做什么？
6. **学习证据**：学完后能否计算、判断、画图、排错或产出文件，而不只是觉得“看懂了”？
7. **视觉必要性**：图或动效是否帮助定位、跟随变化和立即回忆，而不是只增加装饰？

## 主要问题与处理

| 共性问题 | 初学者受到的影响 | 本轮统一处理 |
|---|---|---|
| 页面各自正确，但课与课之间缺少接力 | 记得词，却不知道新知识从哪里来、要送到哪里 | 基础闭环模块增加紧凑学习导航，并新增全局知识图谱与能力路线 |
| 目标常写成“理解” | 无法判断自己是否真正掌握 | 改成能画、能算、能解释、能设计、能排错等可观察动作 |
| D03 一天承担过多数学概念 | 容易把“今天没有全背会”误认为不适合学习 | 标出第一遍必修线与随后加深项；保留小数字到通式的路径 |
| 符号和公式一次压缩过多动作 | 会读出公式，却不知道每个符号指什么、从哪一步得到 | 统一先做小算式、对象与形状表，再给通式；补数学下标与 Python 索引 |
| 抽象标题没有回到例子 | 算完数仍不明白“矩阵映射空间”等句子 | 区分空间、具体向量、矩阵规则和输出，并在例子末尾回扣标题 |
| 图解容易被当成浏览材料 | 看完有印象，但无法主动调用 | 图解页增加看前预测与看后立即回答；动效保留反思问题和总览 |
| 理论到实战交接过快 | 会背 Transformer 图，却认不出真实代码和张量 | D14-D21 明确产物链；D17 增加不训练的真实形状检查 |
| 数学急救包深浅不均 | 某些页面只有定义，缺少“会用”的证据 | 01-05 补使用位置、数值例子和立即自检；06-08 标明拓展边界 |
| 高级内容与必修内容混在一起 | 容易把论文名词误当成入门门槛 | D12、数学 06-07 和 K3 深读明确“先抓共同结构、推导可后学” |

## 主线能力链

| 阶段 | 页面 | 学完应留下的能力 |
|---|---|---|
| 输入与表示 | D01-D03 | 追踪文本、token、ID、向量、logits、概率和 loss，并完成小数字计算 |
| 模型与生成 | D04-D07 | 解释参数怎样更新、注意力怎样汇总信息、Decoder 怎样逐 token 生成 |
| 数据与训练 | D08-D10 | 设计数据流水线、读训练日志、粗估计算与内存并理解规模化约束 |
| 后训练与应用 | D11-D14 | 选择微调、RAG 或 Agent，设计独立评测，并把多模态接口接回表示与形状 |
| 案例闭环 | D15-D21 | 解释基线、检查数据、读张量形状、沿日志排错、比较对照并审查模型卡 |

若某一阶段只能复述名词，不能完成右列动作，应回到对应页面的“学习导航”和验收，不建议仅靠继续向后阅读解决。

## 动效取舍

本轮没有把所有重点都改成动画。只有三类知识保留或新增状态变化：表示形式沿流程变化、向量位置与汇总过程、生成上下文逐轮增长。矩阵映射、对照表、公式单次代入和固定系统结构使用静态图或表格，因为播放不会增加新的学习信息。

详细逐项判断见[教学动效审计](教学动效审计.md)。

## 仍需持续复查

- 模型、硬件、前沿架构和排行榜会变化，相关数字必须保留来源、日期和适用条件。
- 初学者难点会随真实使用继续暴露；新增解释应优先修复共性压缩，而不是在每页复制一套更长定义。
- 每次新增主线术语、公式或动效，都应重新回答本页的先修关系、完成证据和使用边界。

自动检查会保持基础闭环模块的学习导航、理论课每课的 6 道验收题、Wiki 锚点与动效结构不被后续修改破坏。人工复审仍负责判断解释是否真正连贯，自动规则不能替代初学者试读。
