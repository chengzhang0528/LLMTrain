# 版本与适用范围

- 核查日期：2026-08-10。
- 本课程是纯前端、非实操教程；学习者不需要安装 Python、PyTorch，也不需要运行训练或推理代码。
- 预生成案例的内部复核目标为 Python 3.10-3.13、PyTorch 2.x；首版单元测试使用 Python 3.12.13 与 PyTorch 2.9.1+cpu。这些版本用于追溯材料，不是学习环境要求。
- 内部复核以 CPU 为基准路径；GPU 速度和显存占用受硬件、驱动、PyTorch 构建、精度、序列长度和 batch 大小共同影响。
- 文中显存公式用于建立量级感，不代替实测。
- 案例引用的模型和框架命令若发生变化，以对应版本官方文档为准。
- 法律、许可证和隐私要求取决于数据来源与所在地区；课程案例只使用自带演示数据或已确认授权的数据。
