# 版本与适用范围

- 核查日期：2026-08-07。
- 实战代码目标：Python 3.10-3.13、PyTorch 2.x；首版单元测试使用 Python 3.12.13 与 PyTorch 2.9.1+cpu。
- CPU 是基准路径；GPU 速度和显存占用受硬件、驱动、PyTorch 构建、精度、序列长度和 batch 大小共同影响。
- 文中显存公式用于建立量级感，不代替实测。
- 模型和框架命令若发生变化，以对应版本官方文档为准。
- 法律、许可证和隐私要求取决于数据来源与所在地区，项目实践只使用自带演示数据或由学习者确认授权的数据。
- Kimi K3 深读材料核查于 2026-08-07，依据 arXiv:2607.24653、官方模型卡和官方技术博客。模型用法、推理引擎支持、排行榜和第三方评测属于易变信息，后续阅读应重新核对。
