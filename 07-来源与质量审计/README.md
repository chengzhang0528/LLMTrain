# 来源与质量审计

本课程不以原始素材的 `status: done` 作为正确性证明。每个关键结论需要满足以下至少一项：

- 可由教材中的小例子直接验证。
- 有原始论文、官方文档或官方模型卡支持。
- 明确标为工程经验、近似估算或存在争议的观点。

工具版本、显存数字、排行榜和法律政策属于易变化内容，必须带适用条件或核查日期。绝对词如“总是”“完全无损”“必然”默认需要重点复查。

## 维护网站

本目录只供课程维护者使用，不进入网站侧栏、学习进度或站内搜索。

```powershell
pnpm install
pnpm docs:dev
pnpm docs:check
pnpm docs:build
```

课程 Markdown 是教学内容源；前端组件只提供通用呈现与交互。新增课程、术语、动效或论文内容前，先阅读[内容编写规范](内容编写规范.md)。
