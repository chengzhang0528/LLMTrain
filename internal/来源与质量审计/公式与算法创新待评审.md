# 公式与算法创新待评审

本文件是新公式、新训练目标、新算法部件与原创解释框架进入课程前的隔离区。**状态不是“通过”的项目不得出现在 `course/`，也不得被学习页面链接或引用。**

## 评审状态

- `草案`：只有动机或初步写法，尚未完成推导。
- `待数学审查`：已有推导，等待检查定义、条件、反例和与既有方法的等价性。
- `待实验`：数学关系已核对，但效果主张还没有受控对照支持。
- `通过`：数学、来源和所需实验均已评审，可另行进入课程事实核查流程。
- `驳回`：存在不可修复错误、无新增价值或证据不支持。

## 登记模板

| 字段 | 必填内容 |
|---|---|
| 编号 | 稳定 ID，例如 `INNOV-0001` |
| 提案公式或方法 | 完整定义，不只写名称 |
| 来源类型 | 原创提案、论文改写、工程经验或教学解释；附可核查来源 |
| 动机 | 现有公式、算法或讲解具体失败在哪里 |
| 推导 | 从定义与约束逐步得到，不跳过关键等价变换 |
| 参数与形状 | 每个符号的对象类型、形状、单位和允许范围 |
| 可反驳条件 | 哪个反例、数学矛盾或实验结果会推翻提案 |
| 与既有方法差异 | 排查是否只是改名、特殊情形或已知方法等价变换 |
| 需要的评审或实验 | 数学审查、实现核对、数据、基线、指标、随机种子和停止条件 |
| 状态 | `草案 / 待数学审查 / 待实验 / 通过 / 驳回` |
| 评审记录 | 评审人、日期、结论和证据链接 |
