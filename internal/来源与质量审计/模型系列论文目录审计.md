# 模型系列论文目录审计

核查日期：2026-08-11。本页记录 [论文库](../../course/06-拓展知识库/论文研读/01-论文库.md) 的收录范围、官方来源和版本空白，防止课程把产品发布、论文和第三方评测混为一谈。

## 核查方法

1. 先查模型团队的官方 GitHub 组织与仓库 README。
2. 对仓库中列出的 arXiv 编号核对标题、日期和作者；稳定链接统一使用 `https://arxiv.org/abs/<id>`。
3. 没有 arXiv 编号但官方仓库随附完整 PDF 的，标为“仓库随附报告/论文”。
4. 只有博客、模型卡或 README 的版本，标为“发布说明”，不补写虚构的论文编号。
5. 第三方使用某模型做实验的论文不计入模型家族主干，后续可进入可靠性、Agent 或系统专题的外部证据。

## 证据边界

- arXiv 是公开预印本平台，不等同于同行评审通过。
- 官方技术报告是最接近团队实现的一手材料，但仍包含作者自评和发布叙事。
- 模型卡能核对配置、许可证和运行说明，通常不能提供完整因果消融。
- 官方博客适合记录发布时间和产品定位，不负责证明机制有效。
- 仓库 benchmark 图片和表格必须记录代码版本、硬件、精度、上下文和评测 harness。

## 逐篇深读的筛选记录

论文库收录的是“可追踪材料全集”，逐篇深读则按四项门槛筛选代表性论文：

1. **研究转折**：提出新的训练目标、容量/计算分离、长上下文访问、后训练反馈或多模态接口。
2. **一手证据**：至少有论文/技术报告和稳定的官方来源，能复核配置、流程或实验口径。
3. **跨课程连接**：能和 token、注意力、训练循环、推理、系统或可靠性课程形成前后文。
4. **可教学验收**：可以用真实场景、信息流、训练/推理拆分、数字对账和失败反例解释给初学者。

当前主线入口：

- [GLM 论文深读](../../course/06-拓展知识库/论文研读/GLM深读/)：GLM、GLM-130B、ChatGLM、GLM-4.5、GLM-5。
- [Kimi 论文深读](../../course/06-拓展知识库/论文研读/Kimi深读/)：k1.5、MoBA、K2、Kimi Linear、K2.5、K3；K3 在单篇论文课内展开六个子课。
- [DeepSeek 论文深读](../../course/06-拓展知识库/论文研读/DeepSeek深读/)：DeepSeek LLM、DeepSeekMoE、V2、V3、R1、Janus。
- [Qwen 论文深读](../../course/06-拓展知识库/论文研读/Qwen深读/)：Qwen、Qwen2.5、Qwen2-VL、Qwen2.5-Coder、Qwen3、Qwen2.5-Omni。

未进入主线不代表不重要：代码、数学、Prover、OCR、音频、Embedding、Guard、图像生成和实验性架构会在论文库中按“选读/查阅”维护。只有当材料的版本、来源和消融足以支持一篇完整教学闭环时，才升级为深读单元；这能避免用一篇泛泛综述冒充每篇论文的研读。

## 维护要求

论文库每次新增条目都要同步更新本页的核查日期或版本空白。若正式论文后来出现，应保留旧发布说明的历史角色，再把新论文登记为独立条目；不能悄悄把旧来源 URL 替换后声称当时已经有论文。
