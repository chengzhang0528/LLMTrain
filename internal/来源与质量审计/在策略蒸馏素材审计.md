## 直接采用的一手事实

| 事实 | 原文位置 | 课程口径 |
|---|---|---|
| OPD 在学生生成轨迹上比较学生与教师的逐 token 分布 | §2 | 用“学生先走、教师在同一前缀评分”解释 |
| 作者提出思维模式兼容与新增能力两个条件 | §3 | 写成该论文受控实验中的经验条件，不写成普遍定律 |
| 成功配置中 top-k 重叠上升，重叠 token 承载约 97%-99% 概率质量 | §4、附录 B | 数字绑定模型、k、数据和训练设置 |
| 重叠 top-k 消融接近标准学生 top-k，非重叠部分更弱 | §4.2 | 作为针对性消融证据，不写成所有蒸馏只需重叠 token |
| 离策略 SFT 冷启动和教师对齐提示可恢复部分失败配置 | §5 | 作为候选补救，仍要求独立验证 |
| 过长轨迹的奖励可靠性下降，尾部先出现熵与梯度不稳定 | §6、附录 D | 作为长程风险证据，不给出通用 token 长度阈值 |

## 作者解释与未证实项

- “thinking pattern”是作者对局部 token 分布动态的概括。课程始终配合 top-k 重叠、熵差和学生访问状态解释，不把它写成人类可读的真实思维链。
- “全局奖励有信息但局部梯度不可利用”得到实验现象支持；各位置梯度方向各向异性并互相抵消，是作者明确标注尚未直接验证的假设。
- 相同家族 1.5B 与 7B 教师在特定学生视角下训练结果近似，不等于两模型在知识、能力或全部输入分布上等价。

## 不能外推的范围

- 全部主要实验位于数学推理任务，不能直接推广到代码、开放问答、多模态和真实 Agent。
- 预训练数据差异与“新增能力”的关系尚未被控制实验隔离。
- 自蒸馏、特权信息蒸馏和长程多轮环境仍是未来工作。
- 论文中的 3K/7K 较优与 10K/15K 不稳定只属于其配置，不是通用长度配方。
