## 建议深入顺序

1. 根据真实项目选择一个问题，不要顺序通读全部领域。
2. 先读对应原始笔记，列出所有绝对表述、数字和版本命令。
3. 用原始论文、官方文档和模型卡逐条核查。
4. 写一个可运行实验或可反驳的评测标准。
5. 将确认后的结论补充到审计记录，而不是直接覆盖来源。
