# Qwen 论文深读

Qwen 是一个模型家族而不是单一模型。本路线选出通用主干、视觉、代码、推理和 Omni 五类影响力材料，逐篇说明输入输出接口、训练数据、后训练和验收集如何变化；[论文库](../01-论文库.md)中的音频、Embedding、Guard、图像生成等分支保留为选读。

完整材料请进入[Qwen 全部论文](论文.md)：目录会列出当前论文库中的全部 Qwen 条目，点击标题进入论文导读或完整课件。

## 为什么不是把所有 Qwen 版本都写成深读

相邻版本的发布说明常常只给模型卡、接口和排行榜变化，缺少足以解释因果的消融。它们会保留在论文库并标注“发布说明/查阅”，等有稳定一手报告再升级为深读。这样目录长，但每篇正文仍然能让初学者完成问题、机制、证据和边界的闭环。

课程不包含编程实操；代码、视觉和 Omni 的案例都用预生成输入和结果来讲解。
