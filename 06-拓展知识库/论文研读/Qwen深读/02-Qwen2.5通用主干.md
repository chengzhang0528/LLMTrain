# Qwen2.5：通用主干的训练与后训练

> 学习导航：Qwen2.5 适合练习“版本升级不是一项魔法改动”。把预训练数据、长上下文、指令数据、安全和评测分开，才能理解通用模型为什么会变好或回退。

```paper-lesson
qwen25
```

## 论文回答什么

Qwen2.5 面向更广的知识、代码、数学和长文本场景。报告的重点不是一个新注意力公式，而是更大/更干净的数据配方、预训练课程和后训练组合。对初学者来说，它是从单篇架构论文转向“训练系统论文”的桥梁；版本名相邻不等于可以在没有报告证据时断言“直接从 Qwen2 检查点接着训练”。

```mermaid
flowchart LR
  A[模型与 tokenizer 设计] --> B[更广/更高质预训练数据]
  B --> C[预训练与长上下文阶段]
  C --> D[指令、偏好与安全后训练]
  D --> E[通用/代码/数学/安全分层评测]
```

## 核心机制

数据质量、去重、合成样本和课程安排会改变参数形成的分布；后训练再把已有表示和能力转成更稳定的指令响应。长上下文训练还要处理位置外推、检索位置和注意力成本。报告的组合结果不能简化为“参数增加所以更强”。

## 训练与推理分开

训练阶段更新权重和对齐行为。推理阶段的 thinking 开关、模板、temperature、top-p、上下文和工具决定表现。一个服务平台能改变 batch、缓存和吞吐，但不会替代 Qwen2.5 的数据与后训练。

## 数字证据账本

| 记录 | 对账方式 |
|---|---|
| 数据增量 | 领域、语言、合成比例和去重规则 |
| 上下文长度 | 训练长度、评测长度、位置策略 |
| 后训练效果 | 基座 vs instruct、同模板同预算 |
| 安全结果 | 误拒、漏放、语言和类别分层 |

教学复核：一个长上下文评测若把窗口从 8K 换成 128K，同时允许更多检索片段，分数变化包含输入证据变化；不能只标注“长上下文能力提升”。

## 代价与边界

- 合成数据带来覆盖和格式收益，也可能复制教师偏差与错误。
- 后训练可能提高服从性，却牺牲开放问答、多样性或少数语言，需要回归。
- 安全 benchmark 的定义与攻击集会变，版本必须锁定。

## 本课验收

**L1 · 直接应用**：Qwen2.5 的升级至少要拆成哪两层？

<details><summary>参考答案</summary>

预训练/继续训练改变知识与表示，后训练改变指令、偏好和安全行为；还要单独记系统和评测条件。

</details>

**L2 · 变形迁移**：为什么合成数据不是无条件的“免费数据”？

<details><summary>参考答案</summary>

教师会带入事实错误、风格和偏见，重复生成还会降低多样性；必须做去重、过滤和独立验收。

</details>

**L3 · 构造反例**：长上下文分数升高但短问答变差，如何定位？

<details><summary>参考答案</summary>

继续训练或后训练可能把容量和预算偏向长文档，造成短任务分布回退；用固定短模板和同预算回归集验证。

</details>

**L4 · 多概念综合**：给“Qwen2.5 全面提升”补上最小证据清单。

<details><summary>参考答案</summary>

记录版本、数据/训练预算、基座与 instruct、提示模板、解码和工具条件，并提供质量、安全、成本的分层结果。

</details>

## 方法边界

Qwen2.5 报告是家族通用主干的组合证据，不代表每个专门分支都继承同一训练配方。具体模型卡和评测脚本优先于媒体摘要。
