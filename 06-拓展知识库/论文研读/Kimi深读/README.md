# Kimi 论文深读

Kimi 的论文主线用同一套问题链串起 RL、稀疏注意力、MoE、Agent 和原生多模态。这里的“主线”不是每个发布版本一篇文章，而是从影响力和学习转折中挑出代表性论文；[论文库](../01-论文库.md)保留完整版本清单，Kimi K3 则在旁边作为完整技术报告案例。

完整材料请进入[Kimi 全部论文](论文.md)：目录会列出当前论文库中的全部 Kimi 条目，点击标题进入论文导读或完整课件。

## 选读边界

Kimi-VL、Kimi-Audio、Muon 和 AttnRes 等材料分别作为多模态、优化器和架构伴读。K3 路线已经对 AttnRes、KDA、LatentMoE 和基础设施做了更完整的拆解，因此这里不重复复制正文，而是要求读者把单篇论文放回统一的信息流框架中。

课程不包含下载、编程或集群实操；所有示例均是预生成的纸面推演。
