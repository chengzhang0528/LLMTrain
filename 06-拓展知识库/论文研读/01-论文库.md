# 论文库与阅读状态

学习导航：本页把四个模型系列的官方主论文、技术报告和官方版本说明放在同一张可筛选目录里；先按研究问题选 1–3 篇，标记“待读”，再用[论文证据卡](03-论文证据卡.md)完成复核。

## 为什么先看目录

“全部找到”不等于把所有论文排成一条必读队列。本库采用三个边界：

- **纳入**：模型团队的正式论文、arXiv 技术报告、官方仓库随附的完整报告，以及重要的官方机制伴读论文。
- **单独标注**：只有博客、模型卡或仓库发布说明而没有独立论文的版本；它们可以帮助理解产品演进，但不能充当论文证据。
- **暂不纳入**：第三方只把模型当作实验对象的评测、应用或安全论文。它们属于对应专题的外部证据，不属于模型家族主干。

目录核查日期：**2026-08-09**。论文的版本、模型卡和仓库内容会变化；链接打开后仍需核对版本号。

> **字段边界**：`evidence` 是原始出处，`source` 是官方关联入口，`note` 是教学阅读问题，不是对论文结果的独立证明。论文或报告中的收益只在它记录的模型、数据、预算和评测条件下成立。

## 阅读顺序

1. 先在当前系列中选一篇标为“先读”的主干材料，建立基线问题；不要求按年份把所有条目读完。
2. 再选一篇讨论效率或训练瓶颈的机制论文作为对照，学会区分“参数量”和“每 token 计算量”。
3. 最后读一个推理、代码、数学或多模态分支，把基础模型接到实际任务。
4. 只有当证据卡完成，才把某篇标成“已复核”；打开 PDF 不等于掌握。
