# Kimi K3 技术报告深读

这是一条完成 14 天理论主线后的选修路线。目标不是记住 Kimi K3 的全部缩写，而是借一份真实技术报告练习四种能力：读架构、算数字、找边界、审证据。

## 开始前

- 先完成 D05–D07，能解释注意力、残差连接和 KV Cache。
- 先完成 D10、D12，知道显存组成、并行和评测条件为什么重要。
- 公式卡住时查 [外积与状态矩阵](../../03-数学急救包/06-外积与状态矩阵.md) 和 [分位数与平滑封顶](../../03-数学急救包/07-分位数与平滑封顶.md)。
- 来源、许可和已核对数字见 [Kimi K3 素材审计](../../07-来源与质量审计/Kimi-K3-素材审计.md)。

## 推荐路线

| 顺序 | 主题 | 带走的问题 |
|---:|---|---|
| 1 | [先学会审技术报告](01-先学会审技术报告.md) | 一句话属于事实、实验、主张还是推断？ |
| 2 | [三维信息流全景](02-三维信息流全景.md) | 序列、深度、宽度分别在扩什么？ |
| 3 | [KDA 与混合注意力](03-KDA与混合注意力.md) | 固定状态省了什么，又牺牲了什么？ |
| 4 | [AttnRes 与 Stable LatentMoE](04-AttnRes与Stable-LatentMoE.md) | 为什么深度和宽度都需要新的信息通路？ |
| 5 | [预训练、长上下文与原生多模态](05-预训练长上下文与原生多模态.md) | “1M 上下文”是架构、数据还是训练课程的结果？ |

| 7 | [基础设施与评测](07-基础设施与评测.md) | 如何把模型分数还原成可比较的实验？ |

每篇末尾有 L1–L4 四级练习。先闭卷作答，再展开参考答案。不会做 L3 反例题时，通常说明你只记住了机制的优点，还没有理解适用边界。

## 不属于主线要求

你不需要推导 KDA 的完整分块并行式、Quantile Balancing 的对偶问题，也不需要运行 2.8T 模型或自定义 GPU 内核。能画出信息流、复核关键数字、说清每项设计的交换条件，就达到了本路线目标。
