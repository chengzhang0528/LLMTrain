# 在策略蒸馏论文深读

这条路线研读论文 [Rethinking On-Policy Distillation of Large Language Models: Phenomenology, Mechanism, and Recipe](https://arxiv.org/abs/2604.13016v2)。论文讨论的不是“怎样把大模型完整复制成小模型”，而是一个更具体的问题：当学生在自己的生成轨迹上接受教师的逐 token 指导时，什么情况下能学到，什么情况下会停滞或退化？

## 开始前

- 先读 [模型蒸馏](../小模型与蒸馏/03-模型蒸馏.md)，能区分回答、logit、特征和策略信号。
- 先读 [概率与 softmax](../../03-数学急救包/03-概率与softmax.md) 和 [对数与交叉熵](../../03-数学急救包/05-对数与交叉熵.md)，知道“分布接近”不等于“答案一定正确”。
- 先完成 D12，能区分 SFT、可验证奖励、训练指标和独立评测。

## 证据口径

本文以 arXiv v2 为准，共 30 页、23 幅图。作者实验集中在数学推理任务，主要使用 AIME 2024、AIME 2025 和 AMC 2023；因此课程不会把结论直接推广到代码、开放问答、多模态或真实 Agent 环境。

论文中的“thinking pattern”是作者对模型局部输出分布关系的解释。课程会把它具体化为 student-visited states 上的 top-k token 重叠、概率质量、熵差和梯度动态，而不会把它写成模型拥有可直接读取的人类思维过程。

## 完成标准

完成后应能审查一份预生成蒸馏方案：教师是否提供了新能力、学生和教师是否在可学习区域相遇、训练信号是否随轨迹变深而退化、补救方法是否有独立评测，以及结论能否迁移到目标任务。

来源版本、许可和事实边界见 [在策略蒸馏素材审计](../../07-来源与质量审计/在策略蒸馏素材审计.md)。课程不要求下载论文代码、运行训练或复现实验。
