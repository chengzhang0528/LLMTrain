# 图解与数字漫画

这是主线课程卡住时的短练习，不是另一套必须从头读完的课程。每页只解决一个问题：先用一个小场景预测，再沿着数字或状态变化走一遍，最后用新情境复述。图中的数字是教学示例，不是模型配置，也不能直接推出真实模型的性能。

## 统一用法

1. **看前先猜**：先读页面顶部的问题，遮住正文，用一句话写下预测；猜错也要保留，它是定位误解的证据。
2. **只追一条链**：每一格只回答“输入是什么、发生了什么、输出是什么”，不要同时解释所有术语。
3. **回到标题**：看完后用页面给出的新数字或新情境重做一次，不要只复述比喻。
4. **决定是否回主线**：如果仍说不清对象、动作或边界，回到页面列出的 D 课；如果能完成迁移题，就可以继续主线。

## 使用边界

- 本目录只要求阅读、纸笔计算和浏览器内的页面交互；不要求安装外部项目、运行代码、训练模型或上传数据。
- 外部可视化项目放在[动画模型实验室](动画模型实验室.md)的可选区，用来观察设计思路；外站打不开不影响本站学习闭环。
- 静态分镜负责固定关系，程序动效才负责时间顺序；没有状态变化的内容不会为了“更像动画”而播放。
