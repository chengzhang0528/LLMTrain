# 数字漫画：旋钮下山

## 第一格：机器猜错

```text
预测 = w × 输入
w=1，输入=2，目标=6
预测=2，loss=(2-6)²=16
```

## 第二格：梯度举路牌

```text
梯度=-16
含义：在当前点，增大 w 会让 loss 降低
```

## 第三格：只走一小步

```text
学习率=0.05
新 w = 1 - 0.05×(-16) = 1.8
```

## 第四格：重新测量

```text
新预测=3.6
仍不等于6，但比2更接近
```

真实训练同时调整许多旋钮，并用 AdamW 等优化器决定步幅。梯度只描述当前位置附近，不是一张通往全局最优的地图。
