# 数字漫画：训练、验证与测试是三套题

> **学习导航**：承接 D04 的过拟合和 D09 的训练循环；本页用同一组分数区分“用来更新参数”“用来选方案”和“最后一次独立检查”。完成后应能根据训练、验证、测试的变化判断过拟合和数据泄漏。

## 为什么要学这一页

训练 loss 下降只说明模型更贴合看过的样本。真正要做选择时，还要知道它对没有参与更新的数据是否有效；如果反复偷看测试集，最后的分数也会被开发过程污染。把三套数据的责任分开，是读懂训练记录和评测报告的最低证据。

## 先预测

先看四个阶段的数字，暂时不读解释：

| 阶段 | 训练 loss | 验证 loss | 你会怎么判断 |
|---|---:|---:|---|
| A 初始 | 4.0 | 4.0 | 还没有学到稳定模式 |
| B 学到模式 | 1.0 | 2.0 | 训练外样本也有改善 |
| C 记住训练题 | 0.2 | 2.5 | 可能开始过拟合 |

先回答：应该用哪一列决定“继续训练”，哪一列保留到最后才看？

## 四格：从练习到独立检查

### 第一格：训练集是练习册

训练集的样本参与前向计算、loss、反向传播和参数更新。阶段 A 到 B 中，训练 loss 从 `4` 降到 `1`，说明模型在这批数据上的误差下降了。

### 第二格：验证集是陌生练习

验证集不参与这轮参数更新，用来比较 checkpoint、学习率或停止时机。验证 loss 从 `4` 降到 `2`，说明当前模式对一批未参与更新的样本也有帮助，但这仍然不是最终成绩。

### 第三格：只背答案会过拟合

继续训练后，训练 loss 从 `1` 降到 `0.2`，验证 loss 却从 `2` 升到 `2.5`。两条曲线方向分开，是过拟合信号之一：模型越来越贴合训练题，泛化到新样本的表现反而变差。

### 第四格：测试集要留到最后

测试集用于一次尽量独立的最终检查。若根据测试分数反复改数据、配置或提示，测试集就已经参与开发，不能再把它当作无偏的最终证据。此时应重新保留一套未使用的测试数据，或如实报告测试集被看过。

## 三套数据各自负责什么

| 数据 | 是否更新参数 | 用来回答 | 常见误读 |
|---|---|---|---|
| 训练集 | 是 | 模型能否拟合已见样本 | loss 低就代表真实任务变好 |
| 验证集 | 否 | 哪个方案、checkpoint 或停止点更合适 | 验证集看过一次就完全独立 |
| 测试集 | 否 | 冻结方案后的最终估计 | 反复调参后仍叫“独立测试” |

准确率、loss 或生成样例都要附带数据划分和评测口径；单独报一个数字无法说明泛化程度。

## 本页验收

1. 训练 loss `1 -> 0.2`，验证 loss `2 -> 2.5`，为什么不能只庆祝训练 loss 下降？
2. 你用验证集选出最好的 checkpoint 后，下一步应使用哪套数据做一次最终报告？
3. 如果测试集已经被看过十次并据此改了配置，报告中最重要的限制是什么？

核对：第 1 题因为训练外表现恶化，可能发生过拟合；第 2 题是只在方案冻结后使用测试集；第 3 题是测试集不再是独立证据，应重新准备未使用的数据或明确披露开发污染。若把验证集和测试集说成同一套，回到“各自负责什么”表逐行解释。

## 方法边界

- 训练、验证、测试是责任划分，不保证数据本身没有重复、时间穿越或标签错误；还要检查数据构造。
- 验证 loss 下降是选择依据之一，不等于真实用户满意度、事实性或安全性已经得到证明。
- 小样本验证集可能波动很大，实际项目应同时报告样本量、置信范围或分层结果，而不是只看一条曲线。
