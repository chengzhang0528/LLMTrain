# 数字漫画：训练与验证是两套题

> **看图方法**：先判断“训练 loss 更低”是否足够；看完四格后遮住正文，用“练习、陌生题、背答案、独立期末”解释四个阶段。

## 第一格：练习册

学生反复做训练题，训练 loss 从 4 降到 1。

## 第二格：陌生卷

老师拿出未参与训练的验证题，验证 loss 从 4 降到 2，说明学到的模式对新样本也有帮助。

## 第三格：背答案

继续练习后，训练 loss 从 1 降到 0.2，验证 loss 却从 2 升到 2.5。这是过拟合信号之一。

## 第四格：别偷看期末卷

如果根据测试集反复改配置，测试集已经参与开发，不再是独立的最终检查。应保留新的测试集或明确报告开发过程。

**立即回答**：训练 loss 从 `1` 降到 `0.2`，为什么模型仍可能变差？因为验证 loss 同时从 `2` 升到 `2.5`，对训练外数据的表现正在恶化。
