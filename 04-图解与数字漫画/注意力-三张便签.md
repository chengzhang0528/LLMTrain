# 数字漫画：注意力的三张便签

> **学习导航**：承接 D03 的点积与 softmax；本页只追踪一个位置怎样给可见位置打分，再按权重搬运信息。完成后应能区分 Q、K、V 的职责，手算一次加权汇总，并说明因果遮罩挡住了什么。

## 为什么要学这一页

“当前位置需要上下文”不是一句口号。模型必须先比较当前位置与其他位置的匹配程度，再决定从哪里取多少信息。若不把“打分”和“搬运”分开，就会把 Key 当成被复制的内容，或把一张注意力图误当成完整解释。

## 先预测

当前 Query 对三个 Key 的分数是 `[2, 1, 0]`，对应 Value 是 `[10, 0, -10]`。先回答：

1. 分数能直接当作概率吗？
2. 哪一个对象会被权重真正加权搬运，Key 还是 Value？
3. 当前位于序列中间时，未来位置的分数会不会进入汇总？

## 四格：从匹配到汇总

### 第一格：同一个位置产生三种向量

```text
输入：当前位置的隐藏表示 h
Q（Query）：拿什么去匹配？
K（Key）：怎样接受别人的匹配？
V（Value）：匹配后贡献什么信息？
```

Q、K、V 都是隐藏表示经过可训练投影得到的向量。上面的问句只是记忆桥梁，不是模型里预先写好的标签。

### 第二格：Query 给 Key 打分

```text
原始分数： [4, 2, 0]
除以 √dₖ（这里 √4=2）：[2, 1, 0]
```

这三个数表示相对匹配程度，还不是概率，也不要求加起来等于 1。分数可以为负；除以 `√dₖ` 是为了控制高维点积的尺度。

### 第三格：softmax 变成读取比例，再搬运 Value

```text
权重： [0.67, 0.24, 0.09]   （总和约为 1）
Value：[10, 0, -10]
汇总：0.67×10 + 0.24×0 + 0.09×(-10) = 5.8
```

权重由 Q 和 K 的匹配分数决定，真正被加权求和的是 Value。序列长度通常没有因此改变，变化的是当前位置的表示数值。

### 第四格：因果遮罩划出可见范围

```text
位置 0：只能看 0
位置 1：可以看 0、1
位置 2：可以看 0、1、2
```

训练时可以把整段输入并行送入模型，但位置 2 的未来位置会在 softmax 前被屏蔽。并行计算不等于偷看答案。

## 把四格压回一句话

`隐藏表示 -> Q/K/V -> QK 匹配分数 -> 遮罩与 softmax -> 按权重汇总 V`。

多头注意力只是并行使用多组投影；不同头可能捕捉不同模式，但“高权重就是完整原因”仍然是错误的。最终输出还会经过多头组合、MLP、残差和后续层。

## 本页验收

遮住正文，完成三问：

1. 权重 `[0.5, 0.3, 0.2]`，Value `[4, 0, -4]`，加权汇总是多少？
2. 为什么分数 `[2,1,0]` 不能直接拿来做加权平均？
3. 位置 4 在因果注意力中最多能读取哪些位置？

核对：第 1 题是 `0.5×4 + 0.3×0 + 0.2×(-4) = 1.2`；第 2 题因为分数可能为负且总和不为 1，需先经过遮罩和 softmax；第 3 题是位置 `0` 到 `4`。如果把 Key 当成被搬运内容，回到第三格重新标出“权重 × Value”。

## 方法边界

- 本页用一维 Value 突出顺序；真实 Q/K/V 通常是向量或张量，形状需回到 [D05：注意力机制](../01-14天理论课/D05-注意力机制.md)核对。
- 数字例子只证明一次计算怎样进行，不证明模型真的“理解”了词义。
- 注意力权重是关联线索，不单独构成最终决策的因果证明。
