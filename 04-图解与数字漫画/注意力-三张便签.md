# 数字漫画：注意力的三张便签

> **看图方法**：先预测 Query、Key、Value 哪一个真正被加权搬运；看完四格后遮住正文，用 `匹配 -> 归一化 -> 搬运 -> 遮罩` 四个词复述一次。

## 第一格：每个位置写三张便签

```text
Query：我拿什么去匹配？
Key：我拿什么接受匹配？
Value：匹配后我贡献什么信息？
```

## 第二格：Query 给三个 Key 打分

```text
分数： [2, 1, 0]
权重： [0.67, 0.24, 0.09]  <- softmax 后总和为 1
```

## 第三格：按权重搬运 Value

```text
Value： [10, 0, -10]
汇总：0.67×10 + 0.24×0 + 0.09×(-10) = 5.8
```

## 第四格：拉上因果遮罩

当前位置不能偷看未来答案。训练时虽然一次输入整段，未来位置的分数会在 softmax 前被屏蔽。

注意：实际 Q/K/V 是向量，分数会除以 `√dₖ`，这里为突出逻辑而简化。

**立即回答**：注意力权重很大，说明被搬运的是 Key 还是 Value？答案应是 Value；Key 只参与匹配打分。
