# 基础闭环路线

这条路线用于第一次建立完整心智模型，不是整门课程的时间边界。D01-D21 是稳定模块编号，不表示必须按自然日完成。

## 各阶段为什么存在

| 阶段 | 学习必要性 | 缺少后会怎样 |
|---|---|---|
| D01-D04 表示与神经网络 | 建立文字变数字、数字经训练改变参数的主链 | 无法区分上下文变化、参数更新和普通程序规则 |
| D05-D07 Transformer 与生成 | 解释上下文怎样汇总、logits 怎样逐 token 变成回答 | 无法理解长上下文、采样、KV Cache 和幻觉边界 |
| D08-D10 数据与规模化 | 解释能力从哪里来以及训练为什么昂贵 | 容易把数据、step、算力和模型质量做线性想象 |
| D11-D12 后训练与评测 | 选择适配方法并保护旧能力、真实目标和安全边界 | 只看新任务分数，忽略遗忘、投机和评测污染 |
| D13-D14 系统与多模态 | 把模型接入检索、工具、服务和其他模态 | 把最终产品错误全部归因给模型权重 |
| D15-D21 训练过程案例 | 用同一个微型模型把理论连到形状、日志、对照和模型卡 | 看过概念却不能解释训练证据、定位失败或判断结论 |

| 模块 | 核心问题 | 学习产物 |
|---:|---|---|
| D01 | 大模型是什么，不是什么 | 一张输入到输出流程图 |
| D02 | 文字如何变成数字 | 手工编码一句话 |
| D03 | 训练需要哪些数学 | 点积、平均数和概率练习 |
| D04 | 神经网络如何学习 | 手算一次参数更新 |
| D05 | 注意力如何找相关信息 | 手算三 token 注意力 |
| D06 | Transformer 如何组装 | 画出一个 Decoder Block |
| D07 | 模型如何逐 token 生成 | 模拟一次采样 |
| D08 | 数据和分词器如何决定上限 | 一份数据质检清单 |
| D09 | 训练循环做了什么 | 读懂一段训练日志 |
| D10 | 预训练为什么昂贵 | 算一次粗略显存与算力账 |
| D11 | SFT、LoRA、QLoRA 有何不同 | 完成方法选型题 |
| D12 | 对齐与评测如何避免自欺 | 设计一组训练外测试题 |
| D13 | 模型如何进入应用 | 画出 RAG、Agent 和服务链路 |
| D14 | 多模态与应用全景 | 闭卷重画总知识地图 |
| D15 | 看未训练基线 | 环境快照与基线输出判断 |
| D16 | 审查数据 | 训练集、验证集和数据卡缺口 |
| D17 | 沿形状看模型 | 张量形状与因果遮罩解释 |
| D18 | 从过拟合现象排错 | 单 batch 曲线的证据判断 |
| D19 | 读完整训练记录 | 检查点与损失日志解释 |
| D20 | 读评测和对照 | 指标表、生成样例与对照结论 |
| D21 | 审阅模型卡 | 模型卡与复现证据缺口 |

可以按自己的节奏完成。建议每个知识点在学习后的第 1、3、7 次复习时闭卷回忆；学习记录只写“能否说出来或做出来”，不写“看过了”。

完成本路线后，根据目标进入[能力路线](能力路线.md)，不要继续无目的顺序阅读。
