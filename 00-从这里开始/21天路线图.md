# 21 天路线图

| 天 | 核心问题 | 当日产物 |
|---:|---|---|
| 1 | 大模型是什么，不是什么 | 一张输入到输出流程图 |
| 2 | 文字如何变成数字 | 手工编码一句话 |
| 3 | 训练需要哪些数学 | 点积、平均数和概率练习 |
| 4 | 神经网络如何学习 | 手算一次参数更新 |
| 5 | 注意力如何找相关信息 | 手算三 token 注意力 |
| 6 | Transformer 如何组装 | 画出一个 Decoder Block |
| 7 | 模型如何逐 token 生成 | 模拟一次采样 |
| 8 | 数据和分词器如何决定上限 | 一份数据质检清单 |
| 9 | 训练循环做了什么 | 读懂一段训练日志 |
| 10 | 预训练为什么昂贵 | 算一次粗略显存与算力账 |
| 11 | SFT、LoRA、QLoRA 有何不同 | 完成方法选型题 |
| 12 | 对齐与评测如何避免自欺 | 设计一组训练外测试题 |
| 13 | 模型如何进入应用 | 画出 RAG、Agent 和服务链路 |
| 14 | 多模态与应用全景 | 闭卷重画总知识地图 |
| 15 | 建环境并跑基线 | 环境报告、未训练输出 |
| 16 | 准备数据 | 训练集、验证集和数据卡 |
| 17 | 理解项目模型 | 通过形状和因果遮罩测试 |
| 18 | 小样本排错 | 成功过拟合单个 batch |
| 19 | 正式训练 | 检查点与损失日志 |
| 20 | 评测和对照 | 指标表、生成样例、对照结论 |
| 21 | 整理交付 | 模型卡和复现记录 |

复习节奏：每个知识点在学习后的第 1、3、7 天各闭卷回忆一次。打卡表中只记录“能否说出来”，不要记录“看过了”。
