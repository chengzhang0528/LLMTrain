# 运行环境与硬件概念

这页用于看懂课程中出现的 CPU、GPU、显存、运行时和推理引擎，不是安装指南。学习者不需要检测本机硬件，也不需要配置训练环境。

## 三种观察场景

| 场景 | 主要观察点 | 课程中的含义 |
|---|---|---|
| CPU 运行小案例 | 通用、易获得，但并行吞吐较低 | 适合解释流程，不代表生产训练速度 |
| 单张 GPU | 并行计算与显存带宽更强 | 能缩短矩阵计算时间，但仍受显存容量限制 |
| 多 GPU 或集群 | 参数、数据或流水线被切分 | 同时引入通信、同步、排队和故障恢复成本 |

硬件只决定计算怎样被执行以及成本多高，不决定模型已经学会哪些知识。相同权重与上下文在不同合规实现上应保持语义行为可比，但浮点精度、批处理和采样状态可能造成差异。

## 看运行记录时检查什么

- 模型、tokenizer、模板、精度和软件版本是否一致。
- 输入长度、输出长度、batch、并发和硬件型号是否写清。
- 比较实验是否一次只改变一个变量。
- 数字是课程教学示例、公开材料还是特定机器实测，证据标签是否明确。
