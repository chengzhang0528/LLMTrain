# 环境与硬件选择

## 先选路线

| 条件 | 路线 | 建议配置 |
|---|---|---|
| 没有 NVIDIA GPU | CPU | `configs/cpu.yaml`，完成全流程优先 |
| NVIDIA GPU，显存约 6-10 GB | 小 GPU | `configs/gpu-small.yaml` |
| NVIDIA GPU，显存 12 GB 以上 | GPU | 先用小配置验证，再逐步增大 |

本仓库当前检测不到 `nvidia-smi`，因此验收以 CPU 配置为准。Windows 原生环境可以运行；做更大规模 CUDA 训练时通常更适合 Linux 或 WSL2。

## 环境原则

- 安装 PyTorch 时使用官方安装选择器，不根据显卡驱动界面的 “CUDA Version” 盲选包。
- 先跑 20 步 smoke test，再开始长训练。
- 一次只改变一个配置项，否则无法判断变化来自哪里。
- `outputs/` 不提交 Git；配置、日志摘要和模型卡要提交。

具体命令见 [实战入口](../02-第3周实战/)。
