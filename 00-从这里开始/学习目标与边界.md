# 学习目标与边界

## 基础理论模块的能力

- 看懂一张 Transformer 结构图以及训练循环伪代码。
- 解释注意力、交叉熵、梯度下降和过拟合，不要求手推复杂偏导。
- 判断预训练、LoRA、RAG、提示工程和 Agent 的适用边界。
- 识别“参数更多一定更好”“训练 loss 越低越好”等常见误区。

## 训练过程案例的能力

你将沿一组已经准备好的字符级微型语言模型材料，完整观察从未训练基线到数据、张量、训练、评测和模型卡的链路。字符级不是现代商用 LLM 的主流分词方案，但它删掉了分词器训练这一层复杂度，适合第一次理解训练闭环。课程仍会讲 BPE、Unigram 等实际方案。

看完后必须能审查：

- 固定的数据切分与随机种子。
- 可读的模型配置和参数量。
- 训练与验证损失。
- 训练前后相同提示词的输出。
- 至少一次改变单个变量的对照实验。
- 说明用途、限制和数据来源的模型卡。

这个字符级案例只负责建立第一个训练闭环，不承担真实业务效果。需要理解实际问题时，再沿[能力路线](能力路线.md)进入开源小模型适配、蒸馏、RAG、多模态或部署案例。

## 后续能力不是统一终点

- 小模型路线：根据任务、硬件和延迟目标判断应从零训练、适配、蒸馏还是压缩。
- 蒸馏路线：区分回答、logit、特征与策略蒸馏，并从预设独立评测检查学生模型。
- 部署路线：读懂质量、延迟、吞吐、显存与可复现性之间的对照。
- 前沿路线：按瓶颈比较新方法，区分一手事实、作者主张和课程推导。

## 暂不要求掌握

- 从头推导矩阵微积分。
- 多机多卡通信和自定义 CUDA 算子。
- 训练十亿参数模型所需的集群运维。
- 背诵所有模型家族、Benchmark 或论文年份。

这些主题在拓展知识库中保留入口，完成主线后再深入。
