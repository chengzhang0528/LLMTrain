# 学习目标与边界

## 14 天后的能力

- 看懂一张 Transformer 结构图以及训练循环伪代码。
- 解释注意力、交叉熵、梯度下降和过拟合，不要求手推复杂偏导。
- 判断预训练、LoRA、RAG、提示工程和 Agent 的适用边界。
- 识别“参数更多一定更好”“训练 loss 越低越好”等常见误区。

## 21 天后的作品

你将得到一个自己训练的字符级微型语言模型。字符级不是现代商用 LLM 的主流分词方案，但它删掉了分词器训练这一层复杂度，适合第一次完整理解训练链路。课程仍会讲 BPE、Unigram 等实际方案。

作品必须包含：

- 固定的数据切分与随机种子。
- 可读的模型配置和参数量。
- 训练与验证损失。
- 训练前后相同提示词的输出。
- 至少一次改变单个变量的对照实验。
- 说明用途、限制和数据来源的模型卡。

## 暂不要求掌握

- 从头推导矩阵微积分。
- 多机多卡通信和自定义 CUDA 算子。
- 训练十亿参数模型所需的集群运维。
- 背诵所有模型家族、Benchmark 或论文年份。

这些主题在拓展知识库中保留入口，完成主线后再深入。
