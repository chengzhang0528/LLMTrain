# 从这里开始

先看[学科地图](学科地图.md)，从生命周期、现象、项目或研究问题选择角度；不明白某门基础为什么存在时，先读[课程为什么这样安排](课程为什么这样安排.md)；再用[全局知识图谱](全局知识图谱.md)定位上下游，最后按[能力路线](能力路线.md)确定完成证据。课程持续扩展，不要求从第一页顺序读到最后一页。

## 三张入口图各自负责什么

| 页面 | 解决的问题 | 不负责什么 |
|---|---|---|
| 学科地图 | 我可以从哪个问题进入课程 | 展开每个概念的全部依赖 |
| 课程为什么这样安排 | 为什么需要某个课群，哪些只是按需前置 | 替代每课的具体例子和验收 |
| 全局知识图谱 | 一个概念在模型和系统的哪一层 | 替你决定当前项目目标 |
| 能力路线 | 读到什么、做到什么才算完成一条路线 | 要求看完整个知识库 |

## 每个学习单元的固定动作

1. **回忆 10 分钟**：不看笔记，说出上一个单元的三个关键词。
2. **学习 45-70 分钟**：先读直觉，再看数字例子，最后看公式。
3. **观察 20-40 分钟**：播放站内动效、阅读预生成记录，或完成纸笔和浏览器内计算。
4. **闭卷 10 分钟**：完成单元验收。问答和计算先写下自己的结果，选择题先勾选再显示答案；逐步对照解析，答不上来就回看对应小节。
5. **写一句话**：到[学习记录与复习](学习记录与复习.md)写下本单元最模糊的一点，记录保存在当前浏览器。

一个学习单元通常需要 1.5-2.5 小时。所有训练、推理和部署过程都由课程用预生成材料展示，不要求等待外部计算。

## 三条学习规则

- 不背公式名称，先说清输入、动作和输出。
- 不用“loss 下降了”代替“模型变好了”，还要看未参与训练的数据。
- 不追逐模型名和排行榜，先判断问题需要生成、检索、微调还是普通程序。
- 遇到“模型为什么失败”，先判断错误发生在数据、模型、解码、推理服务还是应用系统，不把所有问题都归因给模型权重。

## 卡住时怎么做

- 看到数学符号：到 [数学急救包](../03-数学急救包/) 找同名概念。
- 术语太多：查 [术语速查](../05-速查表/术语速查.md)。
- 不知道选什么方法：查 [方法选择](../05-速查表/方法选择.md)。
- 看不懂日志或报错：先读 [训练排错](../05-速查表/训练排错.md)，再对照课程提供的完整日志和配置定位层级。

## 完成标准

课程没有统一的“全部学完”。每条能力路线单独验收：基础闭环要求能画出训练与推理链路，并解释微型模型案例；可靠性、后训练、多模态、小模型、部署和前沿研究路线分别以证据判断题、案例审计或方案比较验收。

完成一条路线表示获得了对应能力，不表示大模型领域已经学完。
