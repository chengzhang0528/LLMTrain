# LLMTrain：零基础大模型训练课

这是一套面向数学和编程基础薄弱学习者的 21 天课程。前 14 天建立正确的知识地图，后 7 天从零训练、评测并记录一个微型语言模型。

## 从哪里开始

1. 打开 [课程入口](00-从这里开始/)。
2. 做一次 [学前自测](00-从这里开始/学前自测.md)，只用于选择解释深度，不计分。
3. 每天按 [21 天路线图](00-从这里开始/21天路线图.md) 学习并完成当日验收。
4. 遇到公式时再查 [数学急救包](03-数学急救包/)，不必提前学完。

## 你最终要能做到

- 用自己的话解释 `数据 -> token -> Transformer -> 概率 -> 文本`。
- 区分预训练、监督微调、偏好对齐、RAG 和 Agent，知道何时不该训练模型。
- 看懂损失、学习率、batch、epoch、过拟合等训练日志。
- 在 CPU 或 GPU 上训练一个小型 Decoder-only Transformer。
- 用验证损失、固定提示词和对照实验判断模型是否真的变好。
- 交付配置、检查点、样例、指标和模型卡，使实验能够复现。

内容扩充必须遵守 [内容编写规范](07-来源与质量审计/内容编写规范.md)：核心术语统一登记，正文自动链接并提供悬停预览，不能在文章之间复制出互相冲突的定义。
