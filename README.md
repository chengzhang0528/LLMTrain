# LLMTrain：零基础大模型开放课程

这是一套面向数学和编程基础薄弱学习者的开放课程。课程从文本语言模型的基础闭环出发，继续延伸到实际模型案例、后训练、可靠性、多模态、软硬件系统与前沿研究；知识库持续更新，但每条学习路线都有明确的能力出口。

## 从哪里开始

1. 先看 [学科地图](00-从这里开始/学科地图.md)，从生命周期、现象、项目或研究问题选择入口。
2. 不知道为什么要学神经网络、数学或系统时，先读 [课程为什么这样安排](00-从这里开始/课程为什么这样安排.md)。
3. 再看 [全局知识图谱](00-从这里开始/全局知识图谱.md)，确认概念在模型与系统中的上下游位置。
4. 根据目标选择 [能力路线](00-从这里开始/能力路线.md)，不要求顺序读完整个知识库。
5. 第一次学习建议完成 [基础闭环路线](00-从这里开始/基础闭环路线.md)；遇到公式时再查 [数学急救包](03-数学急救包/)。

## 课程的四层结构

| 层 | 回答的问题 | 主要入口 |
|---|---|---|
| 理论基础 | 模型怎样表示、学习、生成和评测 | D01-D14 与数学急救包 |
| 案例闭环 | 怎样从预设训练与应用材料中判断方案是否解决问题 | D15-D21、实际模型案例、小模型与蒸馏 |
| 专题课程 | 为什么会幻觉、怎样后训练、怎样做多模态、为什么系统变慢 | 六个专题课程群 |
| 研究前沿 | 当前瓶颈在哪里，新方法缓解什么又牺牲什么 | 前沿瓶颈地图与论文研读 |

## 基础闭环完成后

- 用自己的话解释 `数据 -> token -> Transformer -> 概率 -> 文本`。
- 区分预训练、监督微调、偏好对齐、RAG 和 Agent，知道何时不该训练模型。
- 看懂损失、学习率、batch、epoch、过拟合等训练日志。
- 沿一份预生成的小型 Decoder-only Transformer 记录解释数据、张量、训练和生成。
- 用验证损失、固定提示词和对照实验判断模型是否真的变好。
- 审查配置、检查点说明、样例、指标和模型卡是否足以支持复现结论。

这不是课程终点。推荐先进入[实际模型案例](06-拓展知识库/实际模型项目/)学习怎样确定问题和验收方式，再按需要学习[模型后训练](06-拓展知识库/模型后训练/)、[幻觉与可靠性](06-拓展知识库/幻觉与可靠性/)、[小模型与蒸馏](06-拓展知识库/小模型与蒸馏/)、[多模态基础](06-拓展知识库/多模态基础/)和[软硬件瓶颈](06-拓展知识库/软硬件瓶颈/)。完成至少一条案例路线后，再进入[前沿瓶颈地图](06-拓展知识库/前沿瓶颈地图.md)与[论文研读](06-拓展知识库/论文研读/)。

## 开发者运行网站

```powershell
pnpm install
pnpm docs:dev
```

以上命令只面向维护本仓库的开发者，不是课程学习任务。生产构建使用 `pnpm docs:build`，输出位于 `.vitepress/dist/`。课程 Markdown 仍是唯一内容源；网页学习进度仅保存在当前浏览器。

内容扩充必须遵守 [内容编写规范](07-来源与质量审计/内容编写规范.md)：核心术语统一登记，正文自动链接并提供悬停预览，不能在文章之间复制出互相冲突的定义。
