# D03：够用就好的数学基础

> **学习导航**：承接 D02 得到的向量；本课只搭建 `向量计算 -> logits -> 概率 -> loss -> 梯度 -> 参数更新` 的数学骨架；完成后应能用两三个数手算每一步，并把答案翻译回模型行为。

## 今日目标

能用小数字计算向量长度、点积、余弦相似度、概率、平均 loss 和参数更新，并解释线性投影改变了什么形状。

## 为什么要学这一课

大模型里的公式不是为了增加门槛，而是把“很多位置、很多维度同时计算”压缩成短写法。只要能把公式重新拆回具体数字，就能判断注意力在比较什么、loss 为什么变化、矩阵怎样改形状，也能发现维度不匹配和计算口径错误。目标是读懂模型行为，不是完成一门纯数学考试。

这页内容比其他单日课密。第一遍先守住三条必修线：会算点积、会把 logits 变成概率并读懂 loss、会按梯度更新一个参数。向量范数、余弦相似度和投影先做到“能跟着例子复算”；需要时再进入数学急救包加深，不要求今天背下全部通式。

点积是 $1\times3 + 2\times1 = 5$。它把两排数压成一个匹配分数。注意力会对多个 Key 得到多个分数，再转成权重。

## 点积为什么不是通用距离尺

点积同时受方向和长度影响。向量 `[1, 0]` 与 `[2, 0]` 方向完全相同，点积是 2；把第二个向量放大为 `[20, 0]` 后，方向没有改变，点积却变成 20。

### 再把小计算翻译成通用公式

若一个向量有 $d$ 个坐标，那么数学公式通常把它们编号为 $a_1,a_2,\ldots,a_d$。$a_i$ 表示第 $i$ 个数，$\sum_{i=1}^{d}$ 表示从第 1 个位置一直加到第 $d$ 个位置，$\lVert a\rVert_2$ 表示“向量 $a$ 的长度”。上面的步骤可以压缩成：

$$
\lVert a\rVert_2=\sqrt{\sum_{i=1}^{d} a_i^2}.
$$

这行公式不是新的计算方法，只是“从第 1 个到第 $d$ 个，逐个平方、全部相加、最后开方”的简写。写成 Python 循环时，索引通常改用 `0` 到 `d-1`。

### 再用具体数字算余弦相似度

现在比较 $a=[1,0]$ 与 $b=[20,0]$。不要直接套大公式，先分别算三个小结果：

| 要算什么 | 小公式 | 结果 |
|---|---|---:|
| 点积 | $a\cdot b=1\times20+0\times0$ | 20 |
| $a$ 的长度 | $\sqrt{1^2+0^2}$ | 1 |
| $b$ 的长度 | $\sqrt{20^2+0^2}$ | 20 |

然后把点积除以两边长度的乘积：

$$
20\div(1\times20)=1.
$$

余弦相似度是 1，说明两个向量虽然长度不同，但方向完全相同。把这几步压缩后，才得到通用公式：

$$
\cos(a,b)=\frac{a\cdot b}{\lVert a\rVert_2\lVert b\rVert_2}.
$$

可以把三种量先区分成三个问题：

| 量 | 它主要回答什么 | 是否受长度影响 |
|---|---|---|
| 点积 | 两组数合起来的匹配分数有多大 | 是 |
| 余弦相似度 | 两个向量的方向有多像 | 基本排除长度影响 |
| 欧氏距离 | 两个点相隔多远 | 是 |

所以看到“相似”或“距离”时，必须先问使用了哪一种量。注意力点积是模型内部为预测目标学出的匹配分数，不等于一把通用的人类语义尺。

## 矩阵把表示投影到新空间

本课程通常用小写 $x$ 表示一个位置的输入向量，用大写 $X$ 表示把许多位置堆起来的矩阵或张量，用大写 $W$ 表示权重矩阵，用 $y$ 表示一个输出向量。这只是命名习惯，局部说明和形状才是判断依据。

```text
输入空间 R^D 中的 x  --矩阵 W-->  输出空间 R^D_out 中的 y
```

$x$ 和 $y$ 是两个空间中的具体向量；$W$ 是中间的变换规则，不是空间。若一批 token 的隐藏状态写成 $X$，形状为 `(batch, time, D)`，线性层 `D -> D_out` 只改变最后一维，输出形状是 `(batch, time, D_out)`。矩阵学习的是怎样组合输入坐标，`D_out` 变大不代表知识凭空增加，变小也不代表必然丢掉任务需要的信息。

多头注意力把 `D` 写成 `H × D_h` 时通常只是 reshape，满足 `D = H × D_h`；这与使用矩阵学习 `D -> D_out` 的投影不同。

假设两个候选 token 的 logits 是 `[0, 1]`。softmax 后约为 `[0.27, 0.73]`。如果第二个 token 是正确答案，单位置交叉熵约为 $-\ln(0.73) = 0.315$。

一句话会在多个位置产生 loss。若两个需要计分的位置 loss 分别是 `0.315` 和 `0.693`，平均 loss 就是：

$$
(0.315+0.693)\div2=0.504.
$$

平均值方便观察整体趋势，但会隐藏“某个位置特别差”的细节，所以训练日志之外仍要检查具体样例。

现在某个参数是 `2.0`，梯度是 `0.4`，学习率是 `0.1`：

$$
\text{新参数} = 2.0 - 0.1\times0.4 = 1.96
$$

这条链已经覆盖训练的数学骨架：

```text
向量计算 -> logits -> 概率 -> loss -> 梯度 -> 更新参数
```

## 常见符号翻译

| 符号 | 读法 | 朴素含义 |
|---|---|---|
| `Σ` | 求和 | 把一组数加起来 |
| `aᵢ` | a 的第 i 项 | 向量中第 i 个位置的数 |
| `d` | dimension | 向量包含的坐标数量 |
| `x / y` | input / output | 一个具体的输入向量与输出向量 |
| `X` | 一批输入表示 | 把多个位置的向量堆成矩阵或张量 |
| `W` | weight matrix | 学习得到的矩阵变换规则，不是空间 |
| `√` | 开平方 | 找到一个数，使它乘自己等于根号里的数 |
| `‖a‖₂` | a 的二范数 | 向量 a 的长度 |
| `×` 或 `·` | 乘或点积 | 组合数字得到新数 |
| `p` | probability | 某候选的概率 |
| `log` | 对数 | 把概率变成适合累加的惩罚尺度 |
| `∇` | 梯度 | loss 对各参数的变化方向和敏感度 |

需要补课时分别查看 [向量与点积](../03-数学急救包/02-向量、矩阵与点积.md)、[高维表示与投影](../03-数学急救包/08-高维表示、投影与降维.md)、[概率与 softmax](../03-数学急救包/03-概率与softmax.md)、[梯度](../03-数学急救包/04-导数、梯度与学习率.md) 和 [交叉熵](../03-数学急救包/05-对数与交叉熵.md)。

## 不要掉进三个坑

- 向量的某一维通常没有预先命名的人类含义。
- 训练 loss 是许多位置和样本的汇总，单个数字看不出所有失败模式。
- 梯度告诉局部变化，不能保证一步就走到全局最好位置。
