D04：神经网络如何学习 ​

今日目标 ​

说清前向传播、loss、反向传播、优化器、batch、step 和 epoch。

一台由旋钮组成的机器 ​

一个极简模型是 预测=w×输入。设输入为 2，目标为 6，初始 w=1：

  • 前向传播：预测 1×2=2
  • 平方误差：(2−6)2=16
  • 计算梯度：这个例子的梯度是 2×(2−6)×2=−16
  • 若学习率为 0.05：w=1−0.05×(−16)=1.8
  • 新预测：1.8×2=3.6，更接近 6，但还没到

真实 LLM 有大量参数，损失常用下一 token 的交叉熵，PyTorch 用自动微分计算梯度。核心循环没有变。

配套分镜：梯度下降：旋钮下山

python
optimizer.zero_grad()
logits, loss = model(inputs, targets)
loss.backward()
optimizer.step()

zero_grad() 很重要，因为 PyTorch 默认累积梯度。需要梯度累积时，程序会有意延迟清零和更新。

训练词汇 ​

  • sample：一个训练样本。
  • batch：一次并行处理的一组样本或序列片段。
  • step：通常指完成一次优化器更新。
  • epoch：完整看过一遍训练集。语言模型常直接按 token 或 step 计量，超大数据甚至不强调整数 epoch。
  • optimizer：把梯度变成参数更新的方法，如 AdamW。
  • learning rate：更新尺度，不是模型“学会了多少”的百分比。

为什么要非线性和多层 ​

只有线性变换时，多层线性变换仍可合并成一个线性变换。激活函数给网络加入非线性，使其能表达更复杂关系。Transformer 的 MLP 通常包含非线性或门控激活。

今日验收 ​

  1. 前向传播与反向传播分别产出什么？
  2. batch 与 epoch 有什么区别？
  3. 为什么训练前要有 loss？
  4. 学习率过大和过小分别可能怎样？

参考：前向得到预测和 loss，反向得到梯度；batch 是一次处理的小组，epoch 是遍历全训练集；loss 把训练目标变成可优化的标量；过大可能震荡或发散，过小可能收敛很慢。
