# D09：一次完整训练循环

> **学习导航**：承接 D04 的参数更新和 D08 的训练 batch；本课把数据、前向、loss、反向、更新、验证和保存连成循环；完成后应能逐行解释训练伪代码，并从日志提出下一步排查动作。

## 今日目标

能读懂训练日志，知道何时看训练 loss、验证 loss、梯度范数和吞吐。

## 为什么要学这一课

前向、loss、反向和优化器如果只作为分散名词，就无法运行或排查训练。训练循环把它们变成有顺序、可记录、可恢复的工程过程；缺少这层理解时，loss 不降、显存溢出或验证变差都只能靠猜。

## 训练循环

```python
for step in range(max_steps):
    x, y = next_train_batch()
    optimizer.zero_grad()
    logits, loss = model(x, y)
    loss.backward()
    clip_grad_norm_if_needed()
    optimizer.step()
    scheduler.step()

    if step % eval_interval == 0:
        evaluate_without_updating_parameters()
        save_checkpoint()
```

真实代码还要处理设备、混合精度、分布式同步、随机种子和异常恢复，但主线就是前向、损失、反向、更新、验证。

| 代码动作 | 接上了哪一课 | 它产生什么 |
|---|---|---|
| `next_train_batch()` | D08 的切分与打包 | 输入 `x` 和错开一位的目标 `y` |
| `model(x, y)` | D02-D06 的模型前向 | logits 与平均 loss |
| `loss.backward()` | D04 的梯度 | 每个可训练参数的梯度 |
| `optimizer.step()` | D04 的参数更新 | 一组新参数 |
| `evaluate...()` | D08 的独立验证集 | 不更新参数的验证指标 |

## 日志怎么读

```text
step=0   train_loss=4.20 val_loss=4.25
step=200 train_loss=2.10 val_loss=2.20
step=500 train_loss=1.20 val_loss=2.35
```

前两行说明训练和验证都改善。最后一行训练继续改善而验证变差，是过拟合信号之一，但单次波动不足以下结论，应看重复评测和整体趋势。

配套分镜：[训练与验证：两套题](../04-图解与数字漫画/训练与验证-两套题.md)

| 现象 | 可能原因 | 下一步 |
|---|---|---|
| train/val 都不降 | 学习率、数据、实现或容量问题 | 先尝试过拟合一个 batch |
| train 降、val 升 | 过拟合或分布差异 | 检查切分、正则化、训练时长 |
| loss 为 NaN | 数值不稳定、异常数据或过大学习率 | 定位首个异常 step |
| OOM | 激活、参数或 batch 超出内存 | 先减 batch 或序列长度 |

## 先过拟合一个 batch

这是最有效的训练单元测试之一。让模型反复看同一小批样本，若 loss 无法明显下降，应先怀疑数据对齐、遮罩、模型、梯度或优化器，而不是购买更多数据。

成功过拟合一个 batch 只证明管线具备记忆这批数据的能力，不证明泛化。

## 梯度累积

显存只能放 batch=2，但希望每 8 个小 batch 更新一次，可以累计 8 次梯度，得到有效 batch 约 16。严格等价还取决于 loss 缩放、随机层、归一化、分布式和优化器细节，所以应称“近似获得更大有效 batch”，而非无条件完全等价。
