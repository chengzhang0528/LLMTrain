D05：注意力机制 ​

今日目标 ​

理解 Q、K、V、缩放点积、softmax、因果遮罩和多头，而不把注意力权重误当成完整解释。

三张便签 ​

处理每个位置时，模型从该位置的表示经过可训练投影得到：

  • Query：这个位置拿什么去匹配。
  • Key：其他位置拿什么接受匹配。
  • Value：匹配后真正汇入的信息。

“搜索词、索引、内容”是有用类比，但 Q/K/V 实际都是训练得到的向量，不是人工写好的句子标签。

三 token 小例子 ​

当前 Query 对三个 Key 的简化分数是 [2, 1, 0]。softmax 后约为 [0.67, 0.24, 0.09]。若三个 Value 是 [10, 0, -10]，加权汇总为：

0.67×10+0.24×0+0.09×(−10)=5.8

正式的缩放点积注意力为：

Attention(Q,K,V)=softmax(QKTdk)V

除以 √d_k 是为了在维度增大时控制点积分数尺度，改善 softmax 和优化的数值行为。把它仅解释为“防止梯度消失”过于狭窄。

配套分镜：注意力：三张便签找信息

Decoder 必须遮住未来 ​

训练因果语言模型时，整段 token 可以并行输入，但位置 2 不能借用位置 3 的答案。因果遮罩把未来位置的注意力分数屏蔽掉：

text
       可看位置
位置0  0
位置1  0 1
位置2  0 1 2
1
2
3
4

所以“自注意力能看到所有位置”只在没有相应遮罩时成立。

为什么多头 ​

不同头使用不同投影，在不同表示子空间中计算注意力，再拼接并投影。某些头可能学到局部、语法或长距离模式，但不能预先保证每个头有清晰的人类角色。

MQA 和 GQA 通过减少或分组共享 Key/Value 头来降低推理时 KV Cache 成本；这是质量、速度、实现与内存之间的权衡，不应笼统宣称某方案“完全无损”。

今日验收 ​

  1. Q/K/V 是人工规则还是训练得到的表示？
  2. 因果遮罩防止了什么？
  3. 缩放因子解决的核心问题是什么？
  4. 为什么单看注意力热力图不能完整解释模型决策？
