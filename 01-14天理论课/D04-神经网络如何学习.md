# D04：神经网络如何学习

## 今日目标

说清前向传播、loss、反向传播、优化器、batch、step 和 epoch。

## 一台由旋钮组成的机器

一个极简模型是 $\text{预测} = w \times \text{输入}$。设输入为 `2`，目标为 `6`，初始 $w = 1$：

- 前向传播：预测 $1\times2 = 2$
- 平方误差：$(2-6)^2 = 16$
- 计算梯度：这个例子的梯度是 $2\times(2-6)\times2 = -16$
- 若学习率为 `0.05`：$w = 1 - 0.05\times(-16) = 1.8$
- 新预测：$1.8\times2 = 3.6$，更接近 6，但还没到

真实 LLM 有大量参数，损失常用下一 token 的交叉熵，PyTorch 用自动微分计算梯度。核心循环没有变。

配套分镜：[梯度下降：旋钮下山](../04-图解与数字漫画/梯度下降-旋钮下山.md)

```python
optimizer.zero_grad()
logits, loss = model(inputs, targets)
loss.backward()
optimizer.step()
```

`zero_grad()` 很重要，因为 PyTorch 默认累积梯度。需要梯度累积时，程序会有意延迟清零和更新。

## 训练词汇

- **sample**：一个训练样本。
- **batch**：一次并行处理的一组样本或序列片段。
- **step**：通常指完成一次优化器更新。
- **epoch**：完整看过一遍训练集。语言模型常直接按 token 或 step 计量，超大数据甚至不强调整数 epoch。
- **optimizer**：把梯度变成参数更新的方法，如 AdamW。
- **learning rate**：更新尺度，不是模型“学会了多少”的百分比。

## 为什么要非线性和多层

只有线性变换时，多层线性变换仍可合并成一个线性变换。激活函数给网络加入非线性，使其能表达更复杂关系。Transformer 的 MLP 通常包含非线性或门控激活。

  question="前向传播与反向传播分别产出什么？"
  answer="前向传播产生预测并计算 loss；反向传播产生各参数对应的梯度。"
  :steps="['前向传播从输入出发，按网络层顺序得到 logits 或预测。', '预测与目标经过损失函数得到一个标量 loss。', '反向传播从 loss 倒推，计算每个参数对 loss 的局部影响。']"
  mistake="反向传播只计算梯度，真正改参数通常发生在 optimizer.step。"
/>

<ExerciseBlock

  question="PyTorch 训练循环中，为什么通常要调用 zero_grad？"

  correct="B"
  answer="B。PyTorch 默认会累积梯度，常规单步更新前要清除旧梯度。"

/>

<ExerciseBlock
  type="calculation"
  question="参数 w=1.5，梯度为 4，学习率为 0.05。一步梯度下降后 w 是多少？"
  answer="更新后的 w 是 1.3。"
  :steps="['写出更新式：新 w = 旧 w - 学习率 × 梯度。', '计算更新量：0.05 × 4 = 0.2。', '用 1.5 - 0.2，得到 1.3。']"

/>

<ExerciseBlock
  type="qa"
  question="batch、step 和 epoch 有什么区别？"
  answer="batch 是一次处理的数据小组，step 通常是一次参数更新，epoch 是完整遍历一次训练集。"
  :steps="['数据先被分成若干 batch。', '通常处理一个 batch 并更新一次参数算一个 step，但梯度累积会改变这层对应关系。', '当全部训练样本都被遍历一遍时完成一个 epoch。']"
  mistake="超大规模语言模型常按 token 或 step 计量，未必强调完整 epoch。"
/>

<ExerciseBlock
  type="choice"
  question="学习率明显过大时，训练日志最可能出现什么现象？"
  :options="['loss 平稳缓慢下降', 'loss 剧烈震荡、发散或出现 NaN', '参数永远不变化', '验证集自动变成训练集']"
  correct="B"
  answer="B。过大的更新步幅可能越过较好区域，引起震荡、发散或数值异常。"
  :steps="['梯度给出局部方向，学习率决定沿该方向走多远。', '步子过大时可能从低 loss 一侧跨到另一侧。', '反复跨越会震荡，极端时数值迅速放大并出现 NaN。']"
  mistake="loss 不降也可能由数据或实现错误造成，不能只凭一个现象断定学习率。"
/>
