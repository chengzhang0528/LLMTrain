## 一台由旋钮组成的机器

一个极简模型是 $\text{预测} = w \times \text{输入}$。设输入为 `2`，目标为 `6`，初始 $w = 1$：

- 前向传播：预测 $1\times2 = 2$
- 平方误差：$(2-6)^2 = 16$
- 计算梯度：这个例子的梯度是 $2\times(2-6)\times2 = -16$
- 若学习率为 `0.05`：$w = 1 - 0.05\times(-16) = 1.8$
- 新预测：$1.8\times2 = 3.6$，更接近 6，但还没到

真实 LLM 有大量参数，损失常用下一 token 的交叉熵，PyTorch 用自动微分计算梯度。核心循环没有变。

配套分镜：[梯度下降：旋钮下山](../04-图解与数字漫画/梯度下降-旋钮下山.md)

```python
optimizer.zero_grad()
logits, loss = model(inputs, targets)
loss.backward()
optimizer.step()
```

`zero_grad()` 很重要，因为 PyTorch 默认累积梯度。需要梯度累积时，程序会有意延迟清零和更新。

## 训练词汇

- **sample**：一个训练样本。
- **batch**：一次并行处理的一组样本或序列片段。
- **step**：通常指完成一次优化器更新。
- **epoch**：完整看过一遍训练集。语言模型常直接按 token 或 step 计量，超大数据甚至不强调整数 epoch。
- **optimizer**：把梯度变成参数更新的方法，如 AdamW。
- **learning rate**：更新尺度，不是模型“学会了多少”的百分比。

## 为什么要非线性和多层

只有线性变换时，多层线性变换仍可合并成一个线性变换。激活函数给网络加入非线性，使其能表达更复杂关系。Transformer 的 MLP 通常包含非线性或门控激活。
