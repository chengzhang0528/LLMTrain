# D05：注意力机制

> **学习导航**：承接 D03 的点积和 softmax、D04 的可训练矩阵；本课学习一个位置怎样给可见位置打分并汇总信息；完成后应能手算三 token 注意力，并追踪 `Q/K/V -> 分数 -> 权重 -> 输出` 的形状。

## 今日目标

能解释 Q、K、V、缩放点积、softmax、因果遮罩和多头的分工，手算一个小例子并追踪每一步的张量形状，而不把注意力权重误当成完整解释。

## 为什么要学这一课

语言中的一个位置经常要结合相隔很远的信息，例如代词要找到所指对象，代码变量要找到定义位置。注意力让每个位置根据当前内容动态选择和汇总可见信息，是现代 Transformer 处理上下文的核心机制。不理解它，就无法判断长上下文、KV Cache、稀疏注意力和多模态连接到底改了哪里。

## 三张便签

处理一个位置时，模型从该位置的表示经过可训练线性投影得到三个向量。讲单个位置时常写成小写 $q,k,v$，把多个位置堆起来参与矩阵计算时常写成大写 $Q,K,V$：

- **Query**：这个位置拿什么去匹配。
- **Key**：其他位置拿什么接受匹配。
- **Value**：匹配后真正汇入的信息。

“搜索词、索引、内容”是有用类比，但 $q/k/v$ 实际都是训练得到的向量，不是人工写好的句子标签。大写 $Q/K/V$ 通常表示多行向量组成的矩阵或更高维张量。

若输入隐藏状态为 `X: (B, T, D)`，实现常用一个线性层一次产生 `(B, T, 3D)`，再切成三个 `(B, T, D)` 的 Q、K、V。这里的 `D -> 3D` 表示生成三套不同投影，不是把单个隐藏状态自然变成了更丰富的一套 `3D` 语义。

| 符号 | 对象类型 | 本节中的形状提示 |
|---|---|---|
| $x$ | 一个 token 位置的隐藏向量 | `D` 个坐标 |
| $X$ | 多个位置堆起来的输入张量 | `(B, T, D)` |
| $q,k,v$ | 一个位置、一个头中的 Query / Key / Value 向量 | `D_h` 个坐标 |
| $Q,K,V$ | 多个位置的向量堆起来的矩阵或张量 | 常包含 `T × D_h` 两条核心轴 |
| $d_k$ | Key 向量的坐标数量 | 标量，不是向量或矩阵 |

论文和代码可以采用别的大小写；若文字与大小写冲突，以明确给出的形状为准。

## 三 token 小例子

当前 Query 对三个 Key 的原始点积分数设为 `[4, 2, 0]`，并令 $d_k=4$。先除以 $\sqrt{4}=2$，得到缩放分数 `[2, 1, 0]`；softmax 后约为 `[0.67, 0.24, 0.09]`。若三个 Value 是 `[10, 0, -10]`，加权汇总为：

$$
0.67\times10 + 0.24\times0 + 0.09\times(-10) = 5.8
$$

刚才的数字例子可以拆成四个动作：

| 动作 | 例子里发生了什么 | 正式公式中的部分 |
|---|---|---|
| 1. 算匹配分数 | 点积得到 `[4, 2, 0]` | $QK^\mathsf{T}$ |
| 2. 控制分数尺度 | 除以 $\sqrt{4}=2$，得到 `[2, 1, 0]` | $QK^\mathsf{T}/\sqrt{d_k}$ |
| 3. 变成权重 | 得到约 `[0.67, 0.24, 0.09]` | $\operatorname{softmax}(\cdot)$ |
| 4. 汇总内容 | $0.67\times10+0.24\times0+0.09\times(-10)=5.8$ | 最后乘 $V$ |

把这四步压缩后，正式的缩放点积注意力写成：

$$
\operatorname{Attention}(Q,K,V)
= \operatorname{softmax}\left(\frac{QK^\mathsf{T}}{\sqrt{d_k}}\right)V
$$

这行公式应读成一条从左到右的计算流程，不需要一次记住所有符号。

因此，标题里的“注意力”不是某一个 $Q$ 或某一个权重，而是从输入表示产生 $Q/K/V$、计算匹配权重、再汇总 $V$ 的整条规则。

除以 `√d_k` 是为了在维度增大时控制点积分数尺度，改善 softmax 和优化的数值行为。把它仅解释为“防止梯度消失”过于狭窄。

## Decoder 必须遮住未来

训练因果语言模型时，整段 token 可以并行输入，但位置 2 不能借用位置 3 的答案。因果遮罩把未来位置的注意力分数屏蔽掉：

```text
       可看位置
位置0  0
位置1  0 1
位置2  0 1 2
```

所以“自注意力能看到所有位置”只在没有相应遮罩时成立。

## 为什么多头

不同头使用不同投影，在不同表示子空间中计算注意力，再拼接并投影。某些头可能学到局部、语法或长距离模式，但不能预先保证每个头有清晰的人类角色。

设头数为 `H`，每头维度为 `D_h`，通常满足 `D = H × D_h`。一条常见的形状路线是：

| 步骤 | 形状 | 发生了什么 |
|---|---|---|
| 当前层隐藏状态 | `(B, T, D)` | 每个位置有一个 D 维表示 |
| Q/K/V 投影 | 三个 `(B, T, D)` | 学习三种不同用途的表示 |
| 拆头并转轴 | `(B, H, T, D_h)` | reshape 与转轴，没有减少总元素数 |
| QK 分数 | `(B, H, T, T)` | 每个头中，每个位置给各可见位置打分 |
| 加权 Value | `(B, H, T, D_h)` | 按权重汇总 Value |
| 拼头并输出投影 | `(B, T, D)` | 回到残差流需要的隐藏宽度 |

“子空间”可以先理解成每个头通过自己的投影读取的一组受限方向，而不是从原向量机械切下的几段固定语义。拆头本身是形状重排，头之间的差异来自学习到的投影矩阵。

MQA 和 GQA 通过减少或分组共享 Key/Value 头来降低推理时 KV Cache 成本；这是质量、速度、实现与内存之间的权衡，不应笼统宣称某方案“完全无损”。
