# 14 天理论课

按 D01 到 D14 顺序学习。每篇只承担一个主要问题；拓展链接不属于当日必修。

完成每一天后，请回到 [每日打卡表](../00-从这里开始/每日打卡表.md)。每课有 6 道验收题，覆盖问答、选择和计算。先闭卷作答；问答与计算题点击“显示答案”后直接核对完整推理，单选题在选中后立即标出正确项并显示解析，多选题答完后再点击检查。若答不上来，先用自己的话写一个错误版本，再对照详细推理修订。

解析会同时给出明确答案和完整推理，不要求学习者再次点击展开。二维铅笔流程和三维视图的逐步讲解会同步显示当前状态、这一步的用途及其必要性；切换到流程总览可快速复习全部步骤，三维视图还可拖动观察。先预测下一步，再操作视图，不要把播放动画当成已经掌握。

## 周节奏

- D01-D04：从输入输出到学习机制。
- D05-D07：注意力、Transformer 与生成。
- D08-D10：数据、训练循环与规模化。
- D11-D12：微调、对齐和评测。
- D13-D14：应用系统、多模态与总复习。
