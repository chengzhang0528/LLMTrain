# 理论基础模块

第一次学习建议按 D01 到 D14 顺序完成。D 是稳定模块编号，不要求一天完成一课；每篇只承担一个主要问题，拓展链接不属于首次必修。

不知道某个模块为什么需要时，先看[课程为什么这样安排](../00-从这里开始/课程为什么这样安排.md)。尤其是神经网络基础：大模型是经过训练的神经网络，只有理解 `前向 -> loss -> 梯度 -> 参数更新`，才能继续理解 Transformer、微调、蒸馏和训练排错。

完成每个单元后，请回到[学习记录与复习](../00-从这里开始/学习记录与复习.md)，查看自动记录的阅读、答题和复习状态，并写下本单元最模糊的一点。每课有 6 道验收题，覆盖问答、选择和计算。先闭卷作答；问答与计算题点击“显示答案”后直接核对完整推理，单选题在选中后立即标出正确项并显示解析，多选题答完后再点击检查。若答不上来，先用自己的话写一个错误版本，再对照详细推理修订。

解析会同时给出明确答案和完整推理，不要求学习者再次点击展开。二维铅笔流程和三维视图的逐步讲解会同步显示当前状态、这一步的用途及其必要性；切换到流程总览可快速复习全部步骤，三维视图还可拖动观察。先预测下一步，再操作视图，不要把播放动画当成已经掌握。

## 模块分组

- D01-D04：从输入输出到学习机制。
- D05-D07：注意力、Transformer 与生成。
- D08-D10：数据、训练循环与规模化。
- D11-D12：微调、对齐和评测。
- D13-D14：应用系统、多模态与总复习。

## 知识接力

| 阶段 | 先回答什么 | 再把结果交给哪里 |
|---|---|---|
| D01-D03 输入与表示 | 文本怎样成为可计算数字，数字怎样变成概率与 loss | D04-D07 的学习、注意力与生成 |
| D04-D07 模型与生成 | 参数怎样更新，Decoder 怎样汇总并逐 token 输出 | D08-D10 的数据与规模化训练 |
| D08-D10 数据与训练 | 训练信号从哪里来，日志和资源约束怎样判断 | D11-D12 的后训练与独立评测 |
| D11-D14 后训练与应用 | 何时微调、检索、用工具或接入多模态 | D15-D21 的训练过程案例与进阶路线 |

每页开头的“学习导航”都是一个停靠点：若还不能完成其中的“完成证据”，先回看对应小节或数学急救包，不要只靠继续翻页获得熟悉感。
