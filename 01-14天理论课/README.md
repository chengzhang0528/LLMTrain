# 理论基础模块

理论基础不再是一串并列术语，而是三条可以闭卷重建的主线。先读一张总纲建立完整对象，再进入 D 课放大关键环节，学完后回到总纲重画因果链。D 是稳定模块编号，不要求一天完成一课，原有网址和当前浏览器学习记录继续有效。

## 三条主线总览

| 主线 | 完整问题 | 总纲 | 放大课 |
|---|---|---|---|
| 模型原理 | 数据为什么能改变参数，静态参数为什么能根据上下文预测 | [模型原理总纲](模型原理总纲.md) | D01-D04 |
| 模型架构 | 完整模型、Block、子层、参数矩阵、激活与缓存怎样分层 | [模型架构总纲](模型架构总纲.md) | D05-D07 |
| 模型训练 | 从问题定义到数据、训练任务、检查点、后训练、评测和部署怎样闭环 | [模型训练总纲](模型训练总纲.md) | D08-D12 |

D13-D14 负责把三条主线接入应用系统与多模态。第一次学习建议按侧栏顺序完成；已经掌握局部概念时，也应先读对应总纲，确认自己能把概念放回完整对象。

三条主线共用教学模型 L0：`V=8、D=4、N=2、H=2、M=8、T=4`。同一个 `<bos> / 我 / 爱 / 学习` 序列会反复出现，用来连接 token、张量形状、参数层级、loss、训练 step 和检查点；它是教学模型，不代表真实产品能力。

不知道某个模块为什么需要时，先看[课程为什么这样安排](../00-从这里开始/课程为什么这样安排.md)。尤其是神经网络基础：大模型是经过训练的神经网络，只有理解 `前向 -> loss -> 梯度 -> 参数更新`，才能继续理解 Transformer、微调、蒸馏和训练排错。

完成每个单元后，请回到[学习记录与复习](../00-从这里开始/学习记录与复习.md)，查看自动记录的阅读、答题和复习状态，并写下本单元最模糊的一点。每课有 6 道验收题，覆盖问答、选择和计算。先闭卷作答；问答与计算题点击“显示答案”后直接核对完整推理，单选题在选中后立即标出正确项并显示解析，多选题答完后再点击检查。若答不上来，先用自己的话写一个错误版本，再对照详细推理修订。

解析会同时给出明确答案和完整推理，不要求学习者再次点击展开。二维铅笔流程和三维视图的逐步讲解会同步显示当前状态、这一步的用途及其必要性；切换到流程总览可快速复习全部步骤，三维视图还可拖动观察。先预测下一步，再操作视图，不要把播放动画当成已经掌握。

## 推荐学习顺序

1. 原理总纲 -> D01-D04 -> 回到原理总纲闭卷重建。
2. 架构总纲 -> D05-D07 -> 回到架构总纲沿形状重建。
3. 训练总纲 -> D08-D12 -> 回到训练总纲区分项目、训练任务和 step。
4. D13-D14：应用系统、多模态与总复习。

| D11-D14 后训练与应用 | 何时微调、检索、用工具或接入多模态 | D15-D21 的训练过程案例与进阶路线 |

每页开头的“学习导航”都是一个停靠点：若还不能完成其中的“完成证据”，先回看对应小节或数学急救包，不要只靠继续翻页获得熟悉感。
