# 理论基础模块

理论基础不再是一串并列术语，而是两个机制对象和一条六阶段生命周期。先用原理与架构总纲建立“为什么成立、由什么组成”，再沿生命周期学习“怎样从问题走到线上迭代”。D 是稳定模块编号，不要求一天完成一课，原有网址和当前浏览器学习记录继续有效。

## 六段理论主线

| 主线 | 完整问题 | 入口 | 放大课 |
|---|---|---|---|
| 模型原理 | 数据为什么能改变参数，静态参数为什么能根据上下文预测 | [模型原理总纲](模型原理总纲.md) | D01-D04 |
| 模型架构 | 完整模型、Block、子层、参数矩阵、激活与缓存怎样分层 | [模型架构总纲](模型架构总纲.md) | D05-D07 |
| 数据准备与模型训练 | 数据怎样进入训练，参数怎样形成检查点 | [模型全生命周期总纲](模型训练总纲.md) | D08-D10 |
| 模型评估与优化 | 怎样塑造行为，并用独立评测防止自欺 | [模型全生命周期总纲](模型训练总纲.md) | D11-D12 |
| 推理、部署与应用 | 检查点怎样进入服务、检索和工具系统 | [模型全生命周期总纲](模型训练总纲.md) | D13 |
| 监控、反馈与持续迭代 | 线上问题怎样变成可核验的下一轮改进证据 | [模型全生命周期总纲](模型训练总纲.md) | D14 |

多模态和软硬件系统会横跨表示、架构、训练、评测、部署与监控，因此放在专题拓展，不再伪装成生命周期最后一步。第一次学习建议按侧栏顺序完成；已经掌握局部概念时，也应先读对应总纲，确认自己能把概念放回完整对象。

六段主线共用教学模型 L0：`V=8、D=4、N=2、H=2、M=8、T=4`。同一个 `<bos> / 我 / 爱 / 学习` 序列会反复出现，用来连接 token、张量形状、参数层级、loss、训练 step、检查点和线上证据；它是教学模型，不代表真实产品能力。

不知道某个模块为什么需要时，先看[课程为什么这样安排](../00-从这里开始/课程为什么这样安排.md)。尤其是神经网络基础：大模型是经过训练的神经网络，只有理解 `前向 -> loss -> 梯度 -> 参数更新`，才能继续理解 Transformer、微调、蒸馏和训练排错。

每课有 6 道验收题，覆盖问答、选择和计算。先闭卷作答，再显示解析；答不上来时，先写下自己的版本，再对照修订。完成后到[学习记录与复习](../00-从这里开始/学习记录与复习.md)查看状态，并记录最模糊的一点。

解析会同时给出明确答案和完整推理，不要求学习者再次点击展开。二维铅笔流程和三维视图的逐步讲解会同步显示当前状态、这一步的用途及其必要性；切换到流程总览可快速复习全部步骤，三维视图还可拖动观察。先预测下一步，再操作视图，不要把播放动画当成已经掌握。

## 推荐学习顺序

1. 原理总纲 -> D01-D04 -> 回到原理总纲闭卷重建。
2. 架构总纲 -> D05-D07 -> 回到架构总纲沿形状重建。
3. 生命周期总纲 -> D08-D10：数据准备、训练任务与规模化训练。
4. D11-D12：后训练、行为优化与独立评测。
5. D13：推理、部署、RAG 与 Agent。
6. D14：监控、反馈与持续迭代 -> 回到生命周期总纲重画完整闭环。

每页开头的“学习导航”都是一个停靠点：若还不能完成其中的“完成证据”，先回看对应小节或数学急救包，不要只靠继续翻页获得熟悉感。
