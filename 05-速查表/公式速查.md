# 公式速查

本页用于学过之后快速回忆，不承担首次讲解。若某行看不懂，应先回到[数学基础课](../01-14天理论课/D03-够用就好的数学基础.md)或[数学急救包](../03-数学急救包/README.md)，先用具体数字完成一次计算，再回来查看通式。

同一个字母在不同资料中可以代表不同对象，例如 $D$ 既可能表示隐藏维度，也可能表示数据 token 数；大写 $L$ 也可以是标量 loss。下面每一行的“输入”和“输出”列才是判断符号身份的依据。

| 公式 | 输入 | 输出 | 用途 |
|---|---|---|---|
| $a\cdot b = \sum_i a_i b_i$ | 两个等长向量 | 一个分数 | 匹配与线性计算 |
| $\lVert a\rVert_2=\sqrt{\sum_i a_i^2}$ | 一个向量 | 非负标量 | 汇总向量幅度 |
| $\cos(a,b)=\frac{a\cdot b}{\lVert a\rVert_2\lVert b\rVert_2}$ | 两个非零向量 | $[-1,1]$ 内的方向相似度 | 减少长度对比较的影响 |
| $y=xW+b$ | 输入表示、权重、偏置 | 新表示 | 在表示空间之间做线性投影 |
| $\operatorname{softmax}(z_i)=e^{z_i}/\sum_j e^{z_j}$ | logits | 和为 1 的分布 | 下一 token 概率 |
| $L=-\log p(\text{正确 token})$ | 正确 token 概率 | 非负惩罚 | 训练目标 |
| $\theta\leftarrow\theta-\eta\nabla L$ | 参数、学习率、梯度 | 新参数 | 最简梯度下降 |
| $\operatorname{Attention}=\operatorname{softmax}(QK^\mathsf{T}/\sqrt{d_k})V$ | Q/K/V | 汇总后的表示 | 自注意力 |
| $\operatorname{PPL}=\exp(\text{平均交叉熵})$ | 平均交叉熵 | 正数 | 相同设置下比较语言建模 |
| $kv^\mathsf{T}$ | 键向量、值向量 | 矩阵 | 把一个键值方向写入状态 |
| $\Delta W=sBA$，常见 $s=\alpha/r$ | 两个含秩 $r$ 中间维度的矩阵与缩放系数 | 秩最多为 $r$ 的权重更新 | LoRA 的低秩更新；实现可能把缩放吸收到其他约定 |
| $q=mk/n$ | token 数、专家数、每 token 激活数 | 平均负载 | MoE 路由的均衡目标 |
| $\operatorname{softcap}(x,\beta)=\beta\tanh(x/\beta)$ | 标量、幅值上界 | 平滑有界值 | 限制大激活并保留平滑梯度 |

公式只在相同定义、数据、tokenizer 和汇总方式下比较。困惑度低不自动意味着事实性、安全性或任务成功率高。
