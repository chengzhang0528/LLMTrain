# 训练排错

| 症状 | 首要检查 | 常见动作 |
|---|---|---|
| 安装失败 | Python、平台、官方 wheel 支持 | 新建干净虚拟环境 |
| CUDA 不可用 | 驱动、PyTorch 构建、设备可见性 | 用官方选择器重装匹配构建 |
| OOM | batch、序列长度、激活 | 先减 batch，再减 block size |
| loss 不降 | 数据错位、梯度、学习率 | 过拟合一个 batch |
| loss NaN | 首个异常 step、数据、精度 | 降学习率、检查非有限值 |
| train 降 val 升 | 泄漏、过拟合、分布差异 | 复查切分、早停、增加有效数据 |
| 输出乱码 | tokenizer、数据编码、训练不足 | 检查 UTF-8 和 encode/decode |
| 生成重复 | 小数据过拟合、解码、长度 | 看验证 loss，调整采样但别掩盖数据问题 |
| 无法复现 | seed、配置、代码、数据版本 | 保存完整实验清单 |

排错时一次只改一个变量，并保留原始配置和完整报错。
