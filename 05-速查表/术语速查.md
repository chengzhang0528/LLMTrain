# 术语速查

课程正文中的核心术语与本页保持同一份定义。每个词条都包含一句话解释和最常见的误解。

| 术语 | 一句话解释 | 不要误解为 |
|---|---|---|
| <span id="term-token"></span>**token（词元）** | 文本经过分词规则得到的离散单元，随后会映射成整数 ID | 必然等于一个字或一个完整单词 |
| <span id="term-tokenizer"></span>**tokenizer（分词器）** | 把文本切成 token，并在 token 与整数 ID 之间转换的规则和词表 | 模型自己临时决定的切词方式 |
| <span id="term-vocab"></span>**vocab（词表）** | tokenizer 可以表示的 token 集合 | 模型掌握的全部知识 |
| <span id="term-parameter"></span>**parameter（参数）** | 模型中由训练确定的数字；只有未冻结参数会被更新 | 一个参数对应一条可直接读取的事实 |
| <span id="term-embedding"></span>**embedding（嵌入）** | 把离散 ID 映射为连续向量的可训练表示 | 人工指定的固定语义坐标 |
| <span id="term-logits"></span>**logits** | softmax 之前用于比较候选 token 的任意实数分数 | 已经是概率或正确率 |
| <span id="term-softmax"></span>**softmax** | 把一组分数转换为非负且总和为 1 的相对权重 | 会让答案自动真实或概率自动校准 |
| <span id="term-loss"></span>**loss（损失）** | 训练目标对应的误差标量，优化器尝试让它下降 | 足以代表模型的全部质量 |
| <span id="term-gradient"></span>**gradient（梯度）** | loss 对各参数的局部变化率 | 直接给出全局最优答案 |
| <span id="term-learning-rate"></span>**learning rate（学习率）** | 控制每次参数更新幅度的超参数 | 越大就一定训练得越快越好 |
| <span id="term-optimizer"></span>**optimizer（优化器）** | 根据梯度及内部状态计算参数更新的算法 | 负责计算前向预测或损失 |
| <span id="term-batch"></span>**batch（批次）** | 一次前向与反向计算共同处理的一组样本 | 必然等于一次更新或整个数据集 |
| <span id="term-step"></span>**step（训练步）** | 本课程默认指一次优化器更新；具体日志可能另有定义 | 所有框架里的 step 都完全相同 |
| <span id="term-epoch"></span>**epoch（轮次）** | 训练过程大致遍历一遍训练集 | 总有固定数量的 step |
| <span id="term-context"></span>**context（上下文）** | 模型本次计算能够看到的 token 序列 | 已永久写入模型参数的记忆 |
| <span id="term-transformer"></span>**Transformer** | 由注意力、MLP、残差连接和归一化等模块组成的一类架构 | 所有大模型都只能采用同一种结构 |
| <span id="term-attention"></span>**attention（注意力）** | 根据 Query 与 Key 的匹配权重，对 Value 做加权汇总 | 权重就是完整可靠的人类可读解释 |
| <span id="term-causal-mask"></span>**causal mask（因果遮罩）** | 阻止当前位置读取未来 token 的遮罩 | 会阻止读取当前位置之前的内容 |
| <span id="term-backpropagation"></span>**backpropagation（反向传播）** | 用链式法则把误差逐层传回并计算梯度 | 本身就是优化器更新 |
| <span id="term-cross-entropy"></span>**cross-entropy（交叉熵）** | 衡量目标分布与预测分布差异的常用损失 | 就是准确率 |
| <span id="term-checkpoint"></span>**checkpoint（检查点）** | 权重及恢复训练所需状态的快照 | 天然就是可直接上线的完整产品 |
| <span id="term-pretraining"></span>**pretraining（预训练）** | 在大规模数据上学习通用模式的基础训练阶段 | 数据越多，回答就必然越真实 |
| <span id="term-sft"></span>**SFT（监督微调）** | 用输入与理想输出示例训练目标行为 | 会自动完成事实核验 |
| <span id="term-lora"></span>**LoRA** | 冻结大部分基础权重，用低秩矩阵学习权重增量 | 自动压缩推理模型或保证无损 |
| <span id="term-qlora"></span>**QLoRA** | 低比特保存冻结的基础模型，同时训练 LoRA 适配器 | LoRA 适配器本身被简单量化成 4 bit |
| <span id="term-rlhf"></span>**RLHF** | 利用人类偏好信号和强化学习优化行为的一类流程 | 所有对齐都只能通过它完成 |
| <span id="term-dpo"></span>**DPO** | 直接利用偏好样本对优化策略 | 不包含偏好目标或参考约束 |
| <span id="term-rag"></span>**RAG（检索增强生成）** | 检索外部资料并放入上下文辅助生成 | 能保证资料和答案都真实 |
| <span id="term-agent"></span>**Agent（智能体）** | 模型参与工具选择、读取结果和多步决策循环的应用结构 | 可脱离权限和人工确认自主执行 |
| <span id="term-inference"></span>**inference（推理）** | 使用训练好的参数计算预测或生成结果 | 通常会继续更新模型权重 |
| <span id="term-overfitting"></span>**overfitting（过拟合）** | 训练数据表现改善，未见数据表现却没有同步改善 | 训练 loss 下降就一定没有发生 |
| <span id="term-validation-set"></span>**validation set（验证集）** | 不参与梯度更新，用来选配置和观察泛化的数据 | 反复针对它调参不会泄漏信息 |
| <span id="term-quantization"></span>**quantization（量化）** | 用更低精度表示权重或激活，以降低内存和计算成本 | 总能四倍加速且完全无质量变化 |
| <span id="term-kv-cache"></span>**KV Cache（KV 缓存）** | 生成时缓存历史 token 的 Key/Value，避免重复计算 | 主要用于降低训练显存 |
| <span id="term-moe"></span>**MoE（混合专家）** | 通过路由让每个 token 只激活部分专家子网络 | 多个完整模型对同一答案投票 |
