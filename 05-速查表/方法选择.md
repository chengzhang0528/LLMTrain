# 方法选择

| 需求 | 先尝试 | 何时升级 |
|---|---|---|
| 固定规则或计算 | 普通代码 | 需要理解自由文本时引入模型 |
| 输出格式不稳定 | Schema、结构化输出、提示 | 大量高质量示例仍失败时 SFT |
| 私有或常变知识 | RAG | 检索正确但行为仍不稳定时再微调 |
| 特定语气/格式/任务行为 | 提示与少样本 | 稳定评测显示差距后 LoRA/SFT |
| 多步依赖工具结果 | 受控工作流 | 分支难以预先枚举时 Agent |
| 领域语言分布差异大 | 继续预训练实验 | 必须先有数据许可和独立评测 |
| 基础能力不足 | 换更适合的基础模型 | 资源充分时才考虑重训练 |

先定义失败和指标，再选方法。方法名不是目标。
