# 数据卡审查框架

这不是需要提交的空白表。下面用课程的 tiny-llm 演示语料展示一份已经填写的数据卡，学习任务是判断每个字段能支持什么结论、还缺什么证据。

| 字段 | 冻结案例记录 | 审查重点 |
|---|---|---|
| 名称 | tiny-llm 课程原创短篇演示文本 | 名称能否对应到明确版本 |
| 来源与授权 | 课程原创，仅用于教学演示 | 许可边界清楚，但不能代表互联网数据 |
| 采集日期 | 随课程版本冻结 | 修改正文后应产生新的数据版本 |
| 语言与领域 | 单一中文短篇 | 文风和主题覆盖极窄 |
| 原始规模 | 1331 个字符、44 行 | 足以观察管线，不足以训练通用模型 |
| 清洗与去重 | 保留原始段落；案例未提供近重复报告 | 无法据此排除相邻片段泄漏 |
| 数据切分 | 前 90% 训练、后 10% 验证 | 切分简单稳定，但同文档相邻内容可能相似 |
| 隐私与安全 | 原创文本，不含真实个人信息或密钥 | 只说明此演示语料，不代表真实数据审计已完成 |
| 已知偏差 | 单一作者、单一文风、极小规模 | 结果不能外推到陌生领域或真实用户输入 |
| 允许用途 | 演示字符词表、训练循环和过拟合 | 用途必须和数据规模匹配 |
| 不适用用途 | 客服、医疗、法律、内容自动发布 | 教学模型不能承担真实决策 |
| 再分发 | 跟随仓库许可和课程说明 | 引入外部数据时必须重新核对授权 |

审查时先问三件事：来源能否追溯，切分是否泄漏，结论是否超出覆盖范围。完整讲解见[D16：数据怎样限制结论](D16-准备和检查数据.md)和[D08：训练数据与分词器](../01-14天理论课/D08-训练数据与分词器.md)。
