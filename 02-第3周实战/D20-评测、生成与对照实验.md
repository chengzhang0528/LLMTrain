## 至少做一个单变量对照

从 `cpu.yaml` 复制出新配置，只改一项：

- `n_layer: 1` 与 `2`
- `block_size: 32` 与 `64`
- `dropout: 0.0` 与 `0.1`
- 训练 `200` 与 `800` steps

保持数据切分、seed、提示和评测设置一致。比较参数量、耗时、train loss、val loss 和输出样例。小样本随机波动较大，不要从一次实验推出普遍规律。
