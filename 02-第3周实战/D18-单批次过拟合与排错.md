# D18：单批次过拟合与排错

运行：

```powershell
.venv\Scripts\python.exe -m tiny_llm.train --config configs/overfit.yaml
```

配置会固定同一个 batch，反复更新 200 步。预期 batch loss 明显下降。验证 loss 可能不改善，甚至变差，这是正常的：今天只检查模型能否记住固定训练片段。

若不能明显下降，按顺序检查：

1. 输入和目标是否错开一位。
2. 参数是否得到非空、有限梯度。
3. `optimizer.step()` 是否执行。
4. 学习率是否过小或过大。
5. loss 是否把所有位置正确展开。
6. 模型是否处于训练模式。

不要用增加层数掩盖管线错误。
