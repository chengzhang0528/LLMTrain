# D21：模型卡、复现与成果验收

## 整理交付

填写 [模型卡模板](模型卡模板.md)，附上：

- 代码版本或 Git commit。
- 环境报告。
- 使用的配置。
- 数据卡。
- 训练和验证 loss。
- 未训练、训练后和对照实验输出。
- 已知失败和不适用场景。

## 复现实验

关闭终端后重新打开，只看 README，从创建环境开始执行 smoke 训练。能够在干净环境跑通，比“我电脑上有一个检查点”更有价值。

## 最终口试

1. 数据如何变成训练 batch？
2. 因果遮罩在代码哪里生效？
3. loss 如何产生梯度？
4. 训练 loss 与验证 loss 各说明什么？
5. 检查点需要哪些信息才能继续或复现？
6. 为什么这个项目不是通用大语言模型？
7. 若要扩展，先增加高质量数据、参数量还是训练步数，怎样设计对照？

七题中至少六题能闭卷说明，并且 smoke 流程可复现，项目即完成。
