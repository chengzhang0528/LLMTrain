# D19：正式训练与保存检查点

CPU 路线：

```powershell
.venv\Scripts\python.exe -m tiny_llm.train --config configs/cpu.yaml
```

有兼容 CUDA 环境时，先让 `smoke.yaml` 在 CUDA 上通过，再尝试 `gpu-small.yaml`。

训练会保存：

| 文件 | 内容 |
|---|---|
| `checkpoint.pt` | 模型权重、配置、tokenizer 和最后指标 |
| `metrics.jsonl` | 每次评测的 step、train/val loss 和耗时 |
| `summary.json` | 参数量、设备与汇总 |
| `sample.txt` | 固定提示生成的样例 |

观察的是趋势，不是最后一个点。若训练中断，先保留完整错误、配置和最后正常 step，再修改一个变量重试。
