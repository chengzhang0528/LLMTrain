# 判断榜单与结论有多可信

> **学习导航**：承接指标口径；本课把“分数看起来高”与“证据足以支持选择”分开；完成后应能为一个排行榜结论标出证据等级、混杂变量和仍待本地复核的缺口。

## 本课目标

- 使用统一证据梯度审查厂商、第三方和本地评测。
- 理解样本量、置信区间、成对评测与污染风险。
- 把 Agent、RAG 和托管服务成绩拆成模型与系统共同结果。

## 为什么要学这一课

厂商模型卡不是“不可信”，而是利益相关的一手材料：它最适合确认官方版本、接口和作者实验条件，却不能自动成为独立结论。社区 Arena 也不是“无用”，它测量了真实用户偏好，却不回答专业事实、合规和部署成本。教材必须说明每类证据能支持到哪一步。

## 五级证据梯度

| 等级 | 典型证据 | 能支持的结论 |
|---|---|---|
| A：项目验收 | 真实分布的冻结测试、版本与配置完整、盲评或可执行真值、样本不参与选型 | 在本合同和置信范围内是否过线 |
| B：独立复测 | 第三方公开脚本、版本、提示与预算，可复现且有失败切片 | 候选在相近任务上的较强线索 |
| C：透明作者实验 | 模型卡给出数据版本、harness、提示、采样、预算和比较对象 | 发布方在这些条件下观察到的结果 |
| D：聚合偏好或不完整榜单 | Arena、只给部分配置的排行榜、裁判模型大规模打分 | 发现候选和总体偏好趋势 |
| E：演示与转述 | 精选样例、截图、社交媒体、无版本的“领先” | 只能形成待验证假设 |

等级不是对发布者诚信的评价，而是对“这条证据能否推出当前结论”的评价。A 级也只对其样本和系统边界负责，不是永久真理。

## 置信区间在说什么

在有限样本上观察到 80% 通过率，不表示总体真实通过率恰好是 80%。置信区间用一种预先规定的重复抽样程序表达估计的不确定性。通俗说：样本越少、结果越接近一半，区间通常越宽；样本越多，随机波动通常越小。

不要把“95% 置信区间”解释成“真实值有 95% 概率落在这次算出的区间内”。在经典频率学派定义里，95% 指重复使用该构造方法时，长期约 95% 的区间会覆盖固定真值。项目报告可以写“估计为 82%，95% CI 为 76%–87%”，但仍要说明算法、样本与独立性假设。

## 为什么优先成对评测

若同一批样本同时交给 A、B 两个候选，逐题记录谁成功，称为成对评测。它能控制样本难度差异，并直接观察：

- 两者都对；
- 只有 A 对；
- 只有 B 对；
- 两者都错。

“只有 A 对”和“只有 B 对”的不平衡，才是候选差异的核心证据。分别抽两批不同难度的题给 A、B，再比较总平均，容易把题目差异误当模型差异。开放生成没有唯一真值时，也可以成对盲评，但需交换答案顺序、允许平局并校准裁判。

## 排行榜常见的八个混杂变量

1. 权重版本、托管快照或模型别名不同。
2. system prompt、聊天模板与 few-shot 示例不同。
3. 思考模式、最大输出、采样次数和停止规则不同。
4. 工具、浏览器、代码执行器与 Agent harness 不同。
5. 量化、精度、推理引擎或硬件不同。
6. 数据版本、答案清洗和评测脚本不同。
7. 训练数据与 benchmark 存在直接、近重复或派生污染。
8. 只报告最优运行，未报告失败、方差或选择过程。

因此“模型 A 比模型 B 高 2 分”只有在上述条件足够一致、差异大于不确定性且任务相关时，才可能有工程意义。

## Agent 成绩必须拆成两部分

```text
Agent 结果 = 模型权重与运行配置
           + system prompt / 工具 schema
           + 执行循环 / 错误恢复
           + 上下文压缩 / 文件与网络环境
           + 时间、token、重试和并发预算
```

在 SWE 类任务中，仓库 revision、依赖安装、测试补丁、可访问工具和最大步数都会改变结果。某些模型卡还会使用定制或尚未完整发布的 harness；这类作者实验可以记录，但不能和另一模型的不同 harness 直接横比。

## 模型裁判怎样校准

- 先让一批样本同时由领域人工和裁判评分，检查一致与冲突。
- 对 A/B 答案交换顺序，估计位置偏差。
- 隐藏模型名称和格式线索，减少品牌与风格偏差。
- 把事实正确、指令遵循、写作风格和安全分开评分。
- 对裁判分歧、高风险样本和边界样本回到人工或可执行真值。

裁判模型提高评测吞吐，不会把主观量表变成客观真值。

## 一张结论审计卡

看到“X 在 Y 上领先”时，逐项填写：

| 审计项 | 记录内容 |
|---|---|
| 主张主体 | 发布方、独立机构还是课程推导 |
| 比较对象 | 完整模型版本与运行配置 |
| 数据与指标 | 数据 revision、样本数、切片、判分规则 |
| 预算 | token、采样、工具、重试、时间与硬件 |
| 不确定性 | 区间、多次运行或成对差异 |
| 可复现性 | harness、prompt、日志与依赖是否公开 |
| 污染与裁判 | 去污染证据、裁判类型与校准 |
| 可迁移性 | 与本项目用户、语言、风险和系统有何差异 |

## 本课验收

1. 为什么厂商模型卡适合确认官方事实，却不自动属于独立复测？
2. 两个候选分别在不同题集上得到 82% 和 80%，为什么不能直接宣布前者更强？
3. Agent 排行榜除了权重，还必须记录哪些系统变量？
4. Arena 偏好排名高，为什么不能推出医疗事实任务更可靠？

## 方法边界

- 证据分级不会自动发现隐蔽污染、错误标签或未披露的服务路由。
- 置信区间刻画抽样不确定性，不覆盖数据偏差、指标失真和系统性错误。
- 成对评测需要同一输入确实适用于两个候选；不同模态或不同权限边界不能强行配对。
- 独立第三方也可能使用不合适的数据或配置，“第三方”不是质量免检标签。
