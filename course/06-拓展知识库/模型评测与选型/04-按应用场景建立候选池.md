# 代码与 Agent 榜单

<!-- benchmark-snapshot: 2026-08-12 -->

> **学习导航**：代码和 Agent 只在仓库、工具、循环与预算相近时比较。

## 本课目标

能区分代码编辑、仓库修复和 Agentic Coding 三类榜单。

## 为什么要学这一课

代码榜分数常常同时包含模型和 harness，换工具就可能换结论。

## 本课验收

1. 说出 SWE-bench Verified 与 Aider Polyglot 的题集差异。
2. 写出 Agent 结果至少需要记录的三个系统变量。

## 方法边界

- `% Resolved` 不是通用代码正确率。
- 成本、重试和最大步数必须和分数一起记录。
- 不把 Aider、SWE-bench 和 LiveBench 分数相加。

代码榜测的是“在给定仓库、工具和 harness 下完成修复”，不是聊天榜的换皮。下面三张图各自只在自己的题集和环境里比较。
