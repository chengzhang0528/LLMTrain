# GLM 论文深读

这是 GLM 系列的逐篇阅读路线，不是把 GLM 家族写成一篇产品介绍。路线选取改变了研究问题、训练方法或系统边界的代表性一手材料；材料目录中的其他版本仍可查阅，但只有满足“问题清楚、方法可核对、实验能对账、影响能迁移”四项条件的材料进入主线。

其他材料请进入[GLM 全系列材料](论文.md)：目录会列出当前论文库中的 GLM 条目，点击标题进入论文导读或完整课件。

## 选择标准

- **研究转折**：论文提出了新的预训练目标、规模化方法、对齐范式或长任务系统。
- **公开证据**：有论文/技术报告、配置或实验表，能把作者事实与教学推导分开。
- **学习价值**：能连接课程中的 token、注意力、后训练、工具和部署，而不只是背模型排行榜。
- **代表而非穷尽**：ChatGLM 的每个小版本、GLM-4-Voice 等分支会留在[论文库](../01-论文库.md)作为选读，不把同一类增量重复写成主线课。

## 推荐路线

| 顺序 | 深读论文 | 要回答的问题 |
|---:|---|---|
| 1 | [GLM：生成式预训练的空白填充](01-GLM预训练目标.md) | 为什么不是只有“预测下一个 token”一种预训练目标？ |
| 2 | [GLM-130B：开放规模化训练](02-GLM-130B规模化.md) | 规模扩大后，数据、并行和稳定性怎样一起记账？ |

| 4 | [GLM-4.5：通用模型变成智能体](04-GLM-4.5智能体.md) | 工具、长轨迹和推理预算怎样改变“模型能力”的含义？ |

每篇都按“真实问题 → 信息流 → 训练/推理 → 数字证据 → 代价与边界 → L1–L4”展开。完成后再回到[GLM 系列演进](../04-GLM系列演进.md)，用路线图检查自己是否把版本名称误当成因果解释。

## 不进入主线的材料

GLM-V、GLM-4-Voice、GLM-OCR 等多模态分支很重要，但它们首先要放进[多模态基础](../../多模态基础/)建立统一接口，再做跨系列比较；GLM-4.5V 和 GLM-5 的后续报告也会随版本稳定性和证据完整度更新。目录不是“越多越好”，而是让每篇深读都能完成一次可核查的学习闭环。

课程不要求下载权重、安装环境或运行训练；示例数字来自公开报告，算式是帮助理解口径的教学推导。
