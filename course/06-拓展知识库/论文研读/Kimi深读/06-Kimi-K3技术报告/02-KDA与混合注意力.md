# KDA 与混合注意力

## 学习目标

理解 KDA 的核心交易：把随长度增长的逐 token 缓存，换成固定形状、持续改写的状态矩阵。

## 一块会被覆盖的黑板

单头简化表示中，符号身份如下：

| 符号 | 对象类型 | 当前时间步的作用 |
|---|---|---|
| $k_t,q_t$ | $d_k$ 维向量 | 写入地址方向与读取查询方向 |
| $v_t$ | $d_v$ 维向量 | 要写入的内容 |
| $S_t$ | $d_k\times d_v$ 状态矩阵 | 压缩到当前步的历史状态 |
| $I$ | $d_k\times d_k$ 单位矩阵 | 表示“不改变方向”的基准变换 |
| $\beta_t$ | 标量 | 控制当前键方向的擦除与写入强度 |
| $\alpha_t$ | 向量 | 控制状态各通道的保留比例 |
| $t$ | 时间步下标 | 表示当前处理到第几个 token |

$$
S_t=(I-\beta_tk_tk_t^\mathsf{T})\operatorname{Diag}(\alpha_t)S_{t-1}
    +\beta_tk_tv_t^\mathsf{T},
\qquad \widetilde{o}_t=S_t^\mathsf{T}q_t.

按动作拆开：

1. $\operatorname{Diag}(\alpha_t)S_{t-1}$：逐通道保留或遗忘。
2. $(I-\beta_tk_tk_t^\mathsf{T})$：沿当前键方向擦除旧内容。
3. $\beta_tk_tv_t^\mathsf{T}$：写入新值。
4. $S_t^\mathsf{T}q_t$：按查询方向读取。

因此，本节标题中的“状态矩阵”就是持续被保留、擦除和写入的 $S_t$；其他小写向量和标量是操作这个状态的当前步输入，不是新的状态空间。

更小的两维例子见[外积与状态矩阵](../../../../03-数学急救包/06-外积与状态矩阵.md)。

## 固定状态不等于无限记忆

状态元素数为 $d_kd_v$，不随 token 数增长，这是资源优势。代价是越来越多历史必须压进同一矩阵：相似键会干扰，衰减会遗忘，有限精度会积累误差。因而“支持 1M 上下文”与“能无损回忆 1M token 中任意细节”是不同命题。

## 为什么还要分块并行

逐 token 递推天然串行，不适合 GPU。KDA 将序列切块：块间传递固定状态，块内改写成可并行矩阵运算。分块式需要用累计保留因子的倒数做重缩放；若保留因子太小，倒数会溢出。

K3 把每步对数衰减限制在 $(g_{\min},0)$，报告取 $g_{\min}=-5$。在 16-token 小片中，累计下界约为 $-80$，从而约束倒数重缩放的范围。这是数值格式和算法形式共同决定设计的例子，不是“数学推完再找工程实现”。

## 为什么混入 Gated MLA

每个常规 block 使用 3 KDA + 1 Gated MLA，末尾再加一个 Gated MLA。KDA 用固定状态混合长程信息，Gated MLA 保留 token 级全局访问。报告没有穷尽混合比例的消融，因此 3:1 是采用的配置，不是普适最优解。

## 四级练习

**L1 · 直接应用**：$d_k=d_v=128$、BF16 每元素 2 字节时，单头状态矩阵约占多少字节？

<details><summary>参考答案</summary>

$128\times128\times2=32,768$ 字节，即 32 KiB。还未计其他状态和框架开销。

</details>

**L2 · 变形迁移**：把 $\beta$ 调到接近 0 会发生什么？

<details><summary>参考答案</summary>

擦除和写入都变弱，状态主要由 $\alpha$ 衰减后的旧内容决定。它更保守，但不代表记忆必然更准。

</details>

**L3 · 构造反例**：构造一个需要精确 token 级回看的任务，说明固定状态可能不如保留完整 KV 历史。

<details><summary>一种构造</summary>

输入包含大量随机、互不相关的键值对，最后要求逐字复述其中一个长随机值。固定维状态需要压缩所有对，完整历史允许全局注意力直接定位原 token。

</details>

**L4 · 多概念综合**：下界衰减同时改变了模型行为与内核实现的哪些边界？

<details><summary>参考答案</summary>

模型侧限制单步最快遗忘速度；数值侧限制累计重缩放的最大量级；实现侧使更多块内计算可以使用规则的稠密矩阵内核。它也缩小了可表达的衰减范围，因此不是无代价改动。

</details>
