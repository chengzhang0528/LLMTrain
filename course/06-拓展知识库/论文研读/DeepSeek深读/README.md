DeepSeek 主线围绕开放基座、专家路由、KV 缓存、规模化训练、推理后训练和视觉接口展开。每篇回答一个瓶颈，不合成一篇总论。代码模型、Prover、OCR 等材料仍在[论文库](../01-论文库.md)按证据等级维护。

其他材料请进入[DeepSeek 全系列材料](论文.md)：目录会列出当前论文库中的 DeepSeek 条目，点击标题进入论文导读或完整课件。

## 证据边界

V2/V3/R1 是技术报告，Janus 是公开论文条目；作者自评、模型卡和第三方评测的证据等级不同。DeepSeek-Prover、DeepSeek-OCR、Engram 和 V3.2-Exp 仍然有很高的研究价值，但分别属于形式化验证、视觉压缩和实验性稀疏轴，暂不塞进这条基础主线。

课程不要求运行模型。纸面算例只帮助理解路由、状态和奖励的口径，不构成对论文实验的复现。
