# 论文材料库与学习进度

学习导航：本页把主要模型系列的论文、技术报告和官方版本说明放在同一张可筛选目录里；先从[论文知识图谱](02-跨系列问题地图.md)选一个研究问题，再挑选少量关联材料加入学习队列，阅读状态只保存在当前浏览器。

## 目录怎样帮助学习

“全部找到”不等于把所有论文排成一条必读队列。本库按证据角色区分材料：

- **纳入**：模型团队的正式论文、arXiv 技术报告、官方仓库随附的完整报告，以及重要的官方机制伴读论文。
- **单独标注**：只有博客、模型卡或仓库发布说明而没有独立论文的版本；它们可以帮助理解产品演进，但不能充当论文证据。
- **暂不纳入**：第三方只把模型当作实验对象的评测、应用或安全论文。它们属于对应专题的外部证据，不属于模型家族主干。

目录核查日期：**2026-08-09**。论文的版本、模型卡和仓库内容会变化；链接打开后仍需核对版本号。

论文或报告中的收益只在它记录的模型、数据、预算和评测条件下成立。目录会显示来源类型，帮助你区分论文、技术报告和发布说明。

## 阅读顺序

第一次进入论文区，先看[如何读懂一篇论文](03-如何读懂一篇论文.md)，建立“三遍阅读 + 五节点回放”的共同方法；下面的顺序用于选择材料，不替代单篇论文里的证据核对。

1. 先在当前系列中选一篇标为“先读”的主干材料，建立基线问题；不要求按年份把所有条目读完。
2. 再选一篇讨论效率或训练瓶颈的机制论文作为对照，学会区分“参数量”和“每 token 计算量”。
3. 最后读一个推理、代码、数学或多模态分支，把基础模型接到实际任务。
4. 能解释问题、机制、关键数字和失败边界后，再把状态改为“已学完”；打开 PDF 不等于掌握。
