# 拓展知识库

这里不是“主线结束后才允许进入”的资料堆，而是按问题组织的专题课程区。基础闭环解释稳定机制；本区从模型失败、训练决策、实际项目、模态扩展和软硬件系统继续深入。前沿内容会在正文中区分论文事实、作者实验、课程推导和仍待确认的结论。

## 按问题找专题

| 你正在追问什么 | 进入专题 |
|---|---|
| 一个真实需求该用普通程序、检索、调用模型还是训练模型 | [实际模型案例](实际模型项目/) |
| 想直接查当前模型、代码、开放权重和专用组件榜单 | [模型评测与选型](模型评测与选型/) |
| 基座模型完成后，怎样改变能力和回答风格 | [模型后训练](模型后训练/) |
| 为什么模型会编造、什么时候拒答、怎样验证 | [幻觉与可靠性](幻觉与可靠性/) |
| 如何降低模型体积、延迟或部署成本 | [小模型与蒸馏](小模型与蒸馏/) |
| 图像、语音和视频怎样接入模型 | [多模态基础](多模态基础/) |
| 慢在哪里，是算法、引擎、通信还是硬件问题 | [软硬件瓶颈](软硬件瓶颈/) |
| 思考强度、路由、搜索和所谓“降智”怎样控制与验证 | [推理控制与服务行为](推理控制与服务行为/) |
| 当前研究还卡在哪些问题 | [前沿瓶颈地图](前沿瓶颈地图.md) |
| 想从论文原始证据深入某个机制或模型系列 | [论文研读](论文研读/) |

进入专题后，左侧目录只显示该专题的路线和文章。需要换问题时，再回到本页。

## 推荐学习顺序

完成 D01-D21 基础闭环后，不要先按模型名称挑课程。推荐先确定项目问题，再依次补行为、可靠性、效率、模态和系统知识，最后进入前沿与论文。

| 顺序 | 路线 | 为什么放在这里 |
|---:|---|---|
| 1 | [实际模型案例](实际模型项目/) | 先固定用户问题、失败代价、两套评测集和最简单基线，避免把训练当成默认答案 |
| 2 | [模型评测与选型](模型评测与选型/) | 汇聚带出处和可信度的当前榜单，再把候选带回许可证、成本与本地验收 |
| 3 | [模型后训练](模型后训练/) | 理解基座完成后怎样做 SFT、偏好优化、RLVR 和能力保护 |
| 4 | [幻觉与可靠性](幻觉与可靠性/) | 在会改模型之后，学习怎样分层测错、核验、拒答和治理 |
| 5 | [小模型与蒸馏](小模型与蒸馏/) | 当强模型可用但成本不合格时，再研究学生模型、蒸馏、压缩和部署 |
| 6 | [多模态基础](多模态基础/) | 先掌握文本模型主链，再扩展图像、语音、视频的表示、连接和评测 |
| 7 | [软硬件瓶颈](软硬件瓶颈/) | 已能解释训练与推理后，再定位算子、显存、带宽、调度、通信和集群问题 |
| 8 | [推理控制与服务行为](推理控制与服务行为/) | 把“思考强度、模型路由、降智和长任务退化”还原为可观测的控制项 |
| 9 | [前沿瓶颈地图](前沿瓶颈地图.md) | 用稳定基础判断当前研究到底在缓解哪类瓶颈 |
| 10 | [论文研读](论文研读/) | 最后用真实论文练习方法复原、数字对账、证据分层和反例构造 |

这个顺序是第一次学习的默认路线，不是强制先修链。已经有明确问题时，可以从实际模型案例判断缺口，再跳到对应专题。

## 专题课程群

| 课程群 | 核心问题 | 能力证据 |
|---|---|---|
| [实际模型案例](实际模型项目/) | 为一个真实问题应该训练什么、复用什么、怎样验收 | 审查项目决策与复现记录 |
| [模型评测与选型](模型评测与选型/) | 当前各类榜单、来源、更新时间、可信度和选型边界 | 维护榜单证据卡并完成冻结验收记录 |
| [模型后训练](模型后训练/) | 基座完成后怎样做 SFT、偏好优化、RLVR 与能力保护 | 审查后训练方案卡 |
| [幻觉与可靠性](幻觉与可靠性/) | 为什么流畅回答仍会错误，怎样测量、拒答、核验与治理 | 解释可靠性评测报告 |
| [小模型与蒸馏](小模型与蒸馏/) | 强模型有效但成本不合格时，怎样训练、蒸馏、压缩和部署学生模型 | 判断教师/学生/部署对照 |
| [多模态基础](多模态基础/) | 图像、语音、视频怎样表示、对齐并接入模型 | 解释模态接口图与分层评测 |
| [软硬件瓶颈](软硬件瓶颈/) | 性能问题发生在算法、引擎、通信还是硬件 | 从冻结记录定位性能瓶颈 |
| [推理控制与服务行为](推理控制与服务行为/) | 厂商怎样控制思考预算、搜索、路由和服务行为，以及“降智”怎样验证 | 为一次回答写出可复现的控制面与回归证据 |

这些课程群共享 D01-D21 的基础模块，也可以互相组合。例如“低成本可靠领域助手”会同时用到实际模型案例、小模型与蒸馏、幻觉与可靠性以及软硬件瓶颈。上表中的课程群名称就是当前可用入口；未建设的素材分类不作为用户目录展示。

## 专题研究方法

1. 根据真实问题选择一个专题，不要顺序通读全部领域。
2. 先读课程提供的案例材料，列出所有绝对表述、数字和版本条件。
3. 对照课程附带的论文、官方文档和模型卡摘录逐条核查。
4. 从预生成实验记录判断结论是否可反驳、比较是否公平。
5. 在站内练习中记录确认项、反例和证据缺口，不需要访问外部服务。

## 论文研读案例

- [论文研读中心](论文研读/)：按研究问题和模型系列双向浏览，先学习证据分层，再用当前浏览器维护待读、研读中和已复核状态。
- [模型系列论文库](论文研读/01-论文库.md)：收录 GLM、Kimi、DeepSeek、Qwen 的官方主论文、技术报告、仓库随附报告和明确标注的版本空白。
- [模型系列逐篇深读](论文研读/#模型系列入口)：每个系列把推荐路线、完整目录和逐篇课程收在同一入口；课程逐篇拆解真实问题、机制、训练/推理、证据数字和失败边界。
- [在策略蒸馏论文深读](在策略蒸馏深读/)：用教师选择、学生访问状态、token 重叠和长轨迹失效练习后训练机制审计。不要求运行蒸馏训练。
