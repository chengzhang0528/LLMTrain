# 从这里开始

**第一次接触大模型：直接打开 [D01](../01-14天理论课/D01-大模型到底是什么.md)。** 不用先自测、选路线或看完整知识图谱。

## 第一次学习只做三件事

1. 从 [D01：大模型到底是什么](../01-14天理论课/D01-大模型到底是什么.md)开始。
2. 每学完一课，只跟随页尾“下一课”继续；数学或术语卡住时再按需查阅，不提前补完整套前置知识。
3. 完成 D01-D14 后，直接进入 [D15：未训练基线](../02-第3周实战/D15-确定目标与跑通基线.md)，沿同一个微型模型读到 D21。

D01-D21 是稳定模块编号，**不是 21 个自然日**。一课可分多次完成；课程不要求安装环境、写代码或实际训练模型。

## 每个学习单元的固定动作

1. **回忆 10 分钟**：不看笔记，说出上一个单元的三个关键词。
2. **学习 45-70 分钟**：先读直觉，再看数字例子，最后看公式。
3. **观察 20-40 分钟**：播放站内动效、阅读预生成记录，或完成纸笔和浏览器内计算。
4. **闭卷 10 分钟**：完成单元验收。问答和计算先写下自己的结果，选择题先勾选再显示答案；逐步对照解析，答不上来就回看对应小节。
5. **写一句话**：到[学习记录与复习](学习记录与复习.md)写下本单元最模糊的一点，记录保存在当前浏览器。

一个学习单元通常需要 1.5-2.5 小时。所有训练、推理和部署过程都由课程用预生成材料展示，不要求等待外部计算。

## 学习规则

- 不背公式名称，先说清输入、动作和输出。
- 不用“loss 下降了”代替“模型变好了”，还要看未参与训练的数据。
- 不追逐模型名和排行榜，先判断问题需要生成、检索、微调还是普通程序。
- 遇到“模型为什么失败”，先判断错误发生在数据、模型、解码、推理服务还是应用系统，不把所有问题都归因给模型权重。

## 能力边界与运行记录

- **基础闭环只证明你能解释和审查训练过程，不代表得到可用于业务的模型。** 字符级微型模型用于暴露机制，不承担通用语言能力。
- 课程中的 CPU、GPU、显存和推理引擎都用于读记录，不要求检测本机。硬件决定执行成本，不直接决定权重学会了什么。
- 看性能数字时至少核对模型、tokenizer、模板、精度、软件与硬件版本、输入输出长度、batch 和并发；条件不同的数字不能直接排序。
- 暂不要求从头推导矩阵微积分、维护多机集群、自定义 CUDA 算子或背诵所有模型家族。

## 卡住时怎么做

- 看到数学符号：到 [数学急救包](../03-数学急救包/) 找同名概念。
- 想先看懂算法在做什么、暂时不做计算：到 [模型算法图解](../09-模型算法图解/) 按问题选一章。
- 术语太多：查 [术语速查](../05-速查表/术语速查.md)。
- 不知道选什么方法：查 [方法选择](../05-速查表/方法选择.md)。
- 看不懂日志或报错：先读 [训练排错](../05-速查表/训练排错.md)，再对照课程提供的完整日志和配置定位层级。

## 完成标准

**课程没有“全部学完”，只有能否完成当前任务。** 基础闭环要求闭卷画出训练与推理链路，并指出微型模型记录能支持什么、不能支持什么；专题路线分别用证据判断、案例审计或方案比较验收。完成一条路线只表示获得对应能力。
