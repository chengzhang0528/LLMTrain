# 课程为什么这样安排

课程目录不应只回答“要学什么”，还要回答“缺少它会在哪一步卡住”。本页从最终任务反推各课群存在的理由；具体单元用页首核心判断直接指出误判，不再重复一段学习说明。

理论基础先回答主线问题，再按 D 课放大：模型为何能学习和预测；内部怎样组成和运行；怎样从真实问题得到经过评测、部署并持续迭代的模型系统。Attention、LoRA、检查点由此回到各自环节，不再只是并列术语。入口见[理论基础](../01-14天理论课/)。

## 为什么大模型课程要学神经网络

大语言模型不是一套由工程师逐条编写的问答规则，而是一个经过训练的神经网络。训练数据进入模型后，前向计算产生预测，loss 衡量差距，反向传播计算梯度，优化器再更新参数。Transformer 是这种神经网络的一类架构，注意力、MLP、归一化和残差都在同一个可训练系统中工作。

不学习神经网络，会直接留下五个断点：

1. 不知道训练数据怎样改变模型参数。
2. 不知道为什么普通推理只读取参数，不会自动继续学习。
3. 无法解释 loss、梯度、学习率、过拟合和检查点。
4. 无法判断 LoRA、SFT、蒸馏到底更新了什么。
5. 看到 Transformer 代码时只能记模块名，无法沿数据流排错。

因此本课程不是为了完整教授所有神经网络，而是教到足以看懂大模型训练、改造和失败分析的程度。

## 为什么不先完整学习随机森林和所有机器学习算法

线性回归、逻辑回归、训练/验证切分、欠拟合、过拟合和模型评估属于通用机器学习基础，对建立实验方法很有帮助。决策树、随机森林、支持向量机等也很重要，但它们不是理解 Decoder-only Transformer 的直接前置。

本站采用“主线需要什么就先学什么”的原则：

- **主线必修**：张量、神经网络、反向传播、优化、过拟合、评测、Transformer。
- **按需急救**：线性回归、概率、向量、矩阵、交叉熵和基础统计。
- **历史对照**：RNN、LSTM、Seq2Seq，用来理解 Transformer 解决了什么，不要求先完整实现。
- **拓展选修**：决策树、随机森林、支持向量机等一般机器学习算法，可在做分类基线时补充。

这不是说其他算法不重要，而是避免初学者为了进入大模型主线，先穿过一整套暂时用不到的算法目录。

## 为什么不直接把高 Star 开源仓库当课程目录

开源项目适合证明一种教学或工程方法怎样落地，但它们的目标不同：有的是书籍代码，有的是资源导航，有的是极简训练框架，有的是云服务教程，还有的是依赖 API 的论文工具。把这些仓库按 Star 从高到低串起来，会同时混入重复内容、版本老化、硬件门槛和商业服务绑定。

本站采用“吸收方法，不继承运行前提”的原则：

- 从第一性原理课程吸收逐层构建、先预测再揭示和闭卷重建。
- 从最小训练系统吸收模型、训练循环、参考实现、优化实现和测试之间的责任边界。
- 从论文注释项目吸收公式、文字、代码和版本的一一对应。
- 从 AI 论文工具吸收“先检索证据、再组织答案”，同时保留引用校验和隐私闸门。

课程正文仍使用自己的教学模型、数字例子、图和预生成证据。学习者不需要安装这些项目；已经弃用、缺少许可证或依赖快速变化云服务的仓库不会作为课程运行条件。

## 每个课群为什么存在

| 课群 | 为什么需要 | 缺少后最常见的误判 |
|---|---|---|
| 数学与张量 | 看懂形状、概率、loss 和参数更新 | 只能背公式，无法检查数字是否合理 |
| 神经网络基础 | 解释数据怎样变成参数行为 | 把模型当成固定规则库或实时数据库 |
| Attention 与 Transformer | 解释上下文怎样汇总并形成 logits | 不知道长上下文、KV Cache 和新架构改了哪里 |
| 生成与解码 | 解释静态参数怎样逐 token 产生可变回答 | 把随机性、模型能力和推理引擎混为一谈 |
| 数据与预训练 | 解释能力上限、成本和规模化约束 | 认为只要增加 step 或数据就必然变好 |
| 后训练与评测 | 塑造行为并检查遗忘、投机和安全 | 只看新任务分数，忽略旧能力和真实目标 |
| 推理与应用系统 | 把模型放进检索、工具、权限和服务链 | 所有线上错误都归因给模型权重 |
| 多模态 | 解释图像、语音和视频怎样进入模型 | 把维度相接误认为已经理解模态语义 |
| 软硬件系统 | 判断模型为什么慢、贵或放不下 | 只看标称算力或单个 tokens/s 数字 |
| 项目与研究 | 把知识变成可反驳实验和可复现成果 | 看过很多内容，却无法完成一个可验收问题 |

## 每个正式单元都要留下的证据

1. **核心判断**：只扫粗体也能知道本页解决哪个误判。
2. **必看主线**：用编号、表格或流程保留最短因果链。
3. **展开证据**：具体数字、机制、反例和边界支撑结论。
4. **掌握证据**：用计算、重画、实验、回归集或项目产物验收。

只写定义、应用列表或“这是基础、很重要”不算完成课程内容。同一观点在页内第二次出现时，必须增加证据或边界，否则删掉。

## 第一次学习顺序

先完成[基础闭环路线](基础闭环路线.md)，让同一个微型语言模型贯穿表示、训练、生成和评测。之后按[能力路线](能力路线.md)选择专题，不要求学习完所有分支。已经有实际问题时，可以直接从[学科地图](学科地图.md)的“现象”或“项目”入口开始。
