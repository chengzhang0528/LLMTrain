# 基础闭环路线

这条路线用于第一次建立完整心智模型，不是整门课程的时间边界。D01-D21 是稳定模块编号，不表示必须按自然日完成。

## 现在从 D01 开始

1. 打开 [D01：大模型到底是什么](../01-14天理论课/D01-大模型到底是什么.md)。
2. 完成页尾验收后，使用“下一课”继续，不需要返回本页反复选课。
3. 遇到不懂的数学、术语或算法时再打开对应辅助页；它们不是开始 D01 的前置条件。

下面的阶段表用于查看全程位置，不要求开始前记住。

理论基础按“总纲 -> 放大课 -> 回到总纲”学习：[模型原理](../01-14天理论课/模型原理总纲.md)讲数据、参数与预测，[模型架构](../01-14天理论课/模型架构总纲.md)讲层级与运行状态，[模型全生命周期](../01-14天理论课/模型训练总纲.md)讲从问题、训练到上线后持续迭代。理论主线共用教学模型 L0。

## 各阶段为什么存在

| 阶段 | 学习必要性 | 缺少后会怎样 |
|---|---|---|
| 原理总纲 + D01-D04 | 建立文字变数字、数据经训练改变参数、参数按上下文预测的主链 | 无法区分结构、参数、上下文、解码和普通程序规则 |
| 架构总纲 + D05-D07 | 解释模型、Block、子层、矩阵、激活与缓存怎样协作 | 只能背模块名，无法沿形状理解生成、KV Cache 和新架构 |
| 生命周期总纲 + D08-D10 | 区分完整项目、一次训练任务和一个 step，并连接数据、预训练与规模化 | 把 loss 循环误当完整项目，只看局部指标或线性想象规模收益 |
| D11-D12 评估与优化 | 用后训练改变行为，并以独立评测约束选择 | 把训练分数或单一榜单当成真实可用性 |
| D13 推理、部署与应用 | 把模型接入推理服务、检索和工具 | 把检查点误当成完整产品 |
| D14 监控、反馈与迭代 | 从线上现象定位责任层，并控制反馈回流、发布和回滚 | 把最终产品错误全归给权重，或把点击直接当训练标签 |
| D15-D21 训练过程案例 | 用同一个微型模型把理论连到形状、日志、对照和模型卡 | 看过概念却不能解释训练证据、定位失败或判断结论 |

完成本路线后，根据目标进入[能力路线](能力路线.md)，不要继续无目的顺序阅读。
