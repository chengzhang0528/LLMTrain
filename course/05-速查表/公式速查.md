# 公式速查

本页用于学过之后快速回忆，不承担首次讲解。若某行看不懂，应先回到[数学基础课](../01-14天理论课/D03-够用就好的数学基础.md)或[数学急救包](../03-数学急救包/)，先用具体数字完成一次计算，再回来查看通式。

同一个字母在不同资料中可以代表不同对象，例如 $D$ 既可能表示隐藏维度，也可能表示数据 token 数；大写 $L$ 也可以是标量 loss。先从公式和深入链接确认对象，再扫“为什么这样构造”和“少一项会怎样”，不要只靠字母大小写猜身份。

| 公式 | 为什么这样构造 | 少一项会怎样 | 深入 |
|---|---|---|---|
| $a\cdot b = \sum_i a_i b_i$ | 同坐标配对相乘，再把各坐标贡献合成一个分数 | 不配对会比较错坐标；不求和就得不到单一匹配分 | [向量与点积](../03-数学急救包/02-向量、矩阵与点积.md#点积不只反映方向) |
| $\lVert a\rVert_2=\sqrt{\sum_i a_i^2}$ | 平方消除正负抵消，开方恢复与坐标相同的尺度 | 不平方会正负抵消；不开方得到的是长度平方 | [长度与归一化](../03-数学急救包/02-向量、矩阵与点积.md#vector-length-normalization) |
| $\cos(a,b)=\frac{a\cdot b}{\lVert a\rVert_2\lVert b\rVert_2}$ | 用两者长度消掉整体缩放，只比较方向 | 不除长度就退回同时受幅度影响的点积；零向量时无定义 | [点积与余弦](../03-数学急救包/02-向量、矩阵与点积.md#点积不只反映方向) |
| $y=xW+b$ | $W$ 的每列定义一个输出坐标组合，$b$ 允许固定平移 | 无 $W$ 不能学坐标组合；无 $b$ 的单层映射必须经过原点 | [矩阵映射](../03-数学急救包/02-向量、矩阵与点积.md#构造理由与删项检查) |
| $p_i=e^{z_i}/\sum_j e^{z_j}$ | 指数保证为正，分母保证总和为 1 | 无指数可能出现负“概率”；无分母则不归一 | [Softmax](../03-数学急救包/03-概率与softmax.md#为什么必须先取指数再除总和) |
| $L=-\log p_y$ | 对数把序列概率乘积变成和，负号把最大似然改成最小损失 | 无负号会把优化方向反转；无对数则失去对数似然关系 | [交叉熵](../03-数学急救包/05-对数与交叉熵.md#为什么是负对数) |
| $\theta\leftarrow\theta-\eta\nabla L$ | 一阶近似下，负梯度给出局部下降方向，$\eta$ 控制步长 | 加号局部上坡；无梯度不看误差方向；无学习率等于硬设步长 | [梯度下降](../03-数学急救包/04-导数、梯度与学习率.md#负号不是约定出来的) |
| $\operatorname{Attention}=\operatorname{softmax}(QK^\mathsf{T}/\sqrt{d_k})V$ | Q/K 负责匹配，缩放控制高维分数，权重再汇总 V | 无缩放更易饱和；无 V 只有匹配分，没有内容 | [注意力](../01-14天理论课/D05-注意力机制.md#scaled-dot-product-proof) |
| $\operatorname{PPL}=\exp(\text{平均交叉熵})$ | 指数把平均对数损失变回乘法尺度 | 不取指数仍是交叉熵，不是困惑度；口径不同不可横比 | [交叉熵](../03-数学急救包/05-对数与交叉熵.md#再汇总多个位置) |
| $kv^\mathsf{T}$ | 外积让键的每个方向都携带值的各坐标 | 改成点积只剩一个数，无法形成状态矩阵写入 | [外积与状态](../03-数学急救包/06-外积与状态矩阵.md#外积把两个向量写成一张表) |
| $\Delta W=sBA$，常见 $s=\alpha/r$ | 两个窄矩阵把更新限制在至多 $r$ 个独立方向，$s$ 控制尺度 | 无 $A$ 或 $B$ 就没有低秩更新；去掉 $s$ 等于固定缩放约定 | [LoRA](../01-14天理论课/D11-SFT、LoRA与QLoRA.md) |
| $q=mk/n$ | 总分配 $mk$ 均摊给 $n$ 个专家，得到理想平均负载 | 少任一数量就无法计算平均；平均值不证明实际均衡 | [MoE](../09-模型算法图解/06-MoE专家路由.md#为什么不是随便设计的) |
| $\operatorname{softcap}(x,\beta)=\beta\tanh(x/\beta)$ | 内部缩放控制进入 tanh 的位置，外部缩放把输出界设为 $\pm\beta$ | 无内部缩放会过早饱和；无外部缩放上界固定为 1 | [平滑封顶](../03-数学急救包/07-分位数与平滑封顶.md) |

公式只在相同定义、数据、tokenizer 和汇总方式下比较。困惑度低不自动意味着事实性、安全性或任务成功率高。
