# D04：神经网络如何学习

> **学习导航**：承接 D03 的 `loss -> 梯度 -> 更新`；本课把单个算式扩成可重复训练循环；完成后应能手算一次参数更新，并把伪代码中的前向、反向、清梯度和更新逐项指出来。

> **主线位置**：[模型原理总纲](模型原理总纲.md) -> D01-D03 -> **D04 数据怎样写入参数**。完成本课后回到总纲，闭卷重建训练路径与推理路径的分叉。

## 本课目标

说清前向传播、loss、多参数梯度、反向传播、优化器、batch、step 和 epoch。

## 先记四个动作

1. **前向：用当前参数产生预测，参数还没有改变。**
2. **Loss：把预测与目标的差异压成可优化标量。**
3. **反向：计算梯度，仍没有写回参数。**
4. **优化器更新：读取梯度并写回参数，下一步才使用新参数。**

## 一次学习中的角色

**第一次必看。**

| 角色 | 回答什么 | 本课中的例子 |
|---|---|---|
| 训练样本 | 这一次给模型看什么 | 输入 `2`，目标 `6` |
| 训练目标 | 希望哪些预测更可能、哪些行为得高分 | 让预测接近 `6` |
| 前向传播 | 当前权重会产生什么预测 | $1\times2=2$ |
| 损失函数 | 当前预测离目标有多远 | $(2-6)^2=16$ |
| 反向传播 | 每个参数附近怎样变化会影响 loss | 得到 $w$ 的梯度 `-16` |
| 优化器更新 | 怎样结合梯度和学习率真正改写参数 | 把 $w$ 从 `1` 改为 `1.8` |

**梯度**指向目标值局部上升最快的方向，**梯度下降**沿负梯度方向更新，以尝试降低目标值。AdamW 等优化器还会加入动量、缩放或其他状态，不能把“梯度下降”与某个具体优化器当成同一个算法。训练目标决定“奖励什么”，loss 把目标变成当前可计算的数，优化器才决定“这一步怎样改参数”。

学习率、batch size、训练步数、正则化强度等由训练者设定而非模型直接学出的配置叫**超参数**。**拟合**是根据训练数据调整参数、让模型逼近其中关系的过程；训练集指标改善只是可能表现。同样规律能否迁移到未见样本叫**泛化**，两者不能只看同一条 loss 曲线判断。

## 一台由旋钮组成的机器

**第一次必看。**

一个极简模型是 $\text{预测} = w \times \text{输入}$。设输入为 `2`，目标为 `6`，初始 $w = 1$：

- 前向传播：预测 $1\times2 = 2$
- 平方误差：$(2-6)^2 = 16$
- 计算梯度：这个例子的梯度是 $2\times(2-6)\times2 = -16$
- 若学习率为 `0.05`：$w = 1 - 0.05\times(-16) = 1.8$
- 新预测：$1.8\times2 = 3.6$，更接近 6，但还没到

真实 LLM 有大量参数，损失常用下一 token 的交叉熵，PyTorch 用自动微分计算梯度。核心循环没有变。

这里最容易卡住的是负号。梯度 `-16` 表示：在当前位置把 $w$ 稍微增大，loss 会下降；更新规则又是“旧参数减去学习率乘梯度”，所以减去负数后 $w$ 从 `1` 增大到 `1.8`。梯度只描述当前位置附近的变化，更新后必须重新前向计算，不能假设沿这个方向一直走都正确。

“一个旋钮”只是帮助入门的切片。真实模型同时有许多矩阵和向量参数；参与当前计算图、影响本次 loss 且允许训练的参数，通常会得到同形状的梯度张量。冻结参数、未被路由选中的分支或已经断开计算图的参数可能没有梯度。把所有参数想象成一个极高维坐标，当前模型就是这个参数空间中的一个点，梯度给出 loss 在当前位置上升最快的局部方向，优化器据此组合出更新。

梯度范数把整组梯度的总体幅度汇总成一个数，适合发现梯度爆炸、比较更新尺度或执行裁剪；它会丢掉每个方向的细节，所以“范数正常”不代表每个参数都更新合理。

## 训练词汇

**随用随查。**

- **training sample**：一个训练样本，包含本次训练需要的输入及目标或监督信息。
- **dataset**：按用途组织的一组样本；训练、验证和测试分区承担不同职责。
- **batch**：一次并行处理的一组样本或序列片段。
- **step**：通常指完成一次优化器更新。
- **epoch**：完整看过一遍训练集。语言模型常直接按 token 或 step 计量，超大数据甚至不强调整数 epoch。
- **optimizer**：把梯度变成参数更新的方法，如 AdamW。
- **learning rate**：更新尺度，不是模型“学会了多少”的百分比。

## 非线性与多层（进入 Transformer 前再读）

只有线性变换时，多层线性变换仍可合并成一个线性变换。激活函数给网络加入非线性，使其能表达更复杂关系。Transformer 的 MLP 通常包含非线性或门控激活。
