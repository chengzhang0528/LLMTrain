# D05：注意力机制

> **学习导航**：[模型架构总纲](模型架构总纲.md) -> **D05 放大 Attention 子层** -> D06 组装完整模型；本课承接点积、softmax 与可训练矩阵，追踪 `Q/K/V -> 分数 -> 遮罩 -> 权重 -> 输出`。完成后应能手算三 token 注意力、核对每步形状，并说明注意力权重为什么不是完整解释。

## 先记四步信息流

1. **Q 与 K 点积：当前位置给可见位置打匹配分。**
2. **遮罩：先排除当前位置不允许读取的未来信息。**
3. **Softmax：把有效分数变成归一化权重。**
4. **权重 × V：汇总内容，得到当前位置的新上下文表示。**

## 三张便签

**第一次必看：先分清 Q、K、V 三种职责。**

处理一个位置时，模型从该位置的表示经过可训练线性投影得到三个向量。讲单个位置时常写成小写 $q,k,v$，把多个位置堆起来参与矩阵计算时常写成大写 $Q,K,V$：

- **Query**：这个位置拿什么去匹配。
- **Key**：每个可见位置拿什么接受匹配，包括当前位置。
- **Value**：每个可见位置在匹配后实际提供什么信息。

“搜索词、索引、内容”是有用类比，但 $q/k/v$ 不是直接存进参数里的固定向量，也不是人工写好的句子标签。训练得到的是投影矩阵 $W_Q/W_K/W_V$ 等参数；每次运行时，当前隐藏状态再经过这些矩阵，动态算出本次输入对应的 $q/k/v$。大写 $Q/K/V$ 通常表示多个位置的这些结果堆成的矩阵或更高维张量。

在标准多头注意力的教学设定中，输入 `X: (B,T,D)` 可经一个合并线性层得到 `(B,T,3D)`，再切成三份 `(B,T,D)` 的 Q、K、V。`D -> 3D` 是并列生成三组投影，不是把语义“升到三倍”。MQA、GQA 等结构的形状不同，要以配置为准。

| 符号 | 对象类型 | 本节中的形状提示 |
|---|---|---|
| $x$ | 一个 token 位置的隐藏向量 | `D` 个坐标 |
| $X$ | 多个位置堆起来的输入张量 | `(B, T, D)` |
| $q,k,v$ | 一个位置、一个头中的 Query / Key / Value 向量 | `D_h` 个坐标 |
| $Q,K,V$ | 多个位置的向量堆起来的矩阵或张量 | 常包含 `T × D_h` 两条核心轴 |
| $d_k$ | Key 向量的坐标数量 | 标量，不是向量或矩阵 |

论文和代码可以采用别的大小写；若文字与大小写冲突，以明确给出的形状为准。

## 三 token 小例子

**第一次必看。**

为了让三个位置都可见，这里计算序列最后一个位置 2：它可以看位置 0、1、2。设当前 Query 对三个 Key 的点积分数为 `[4,2,0]`，且 $d_k=4$。除以 $\sqrt{4}=2$ 后得到 `[2,1,0]`，因果遮罩在本例中不删除任何分数，softmax 约为 `[0.67,0.24,0.09]`。

$$
0.67\times10 + 0.24\times0 + 0.09\times(-10) = 5.8
$$

刚才的数字例子可以拆成四个动作：

| 动作 | 例子里发生了什么 | 正式公式中的部分 |
|---|---|---|
| 1. 算匹配分数 | 点积得到 `[4, 2, 0]` | $QK^\mathsf{T}$ |
| 2. 控制分数尺度 | 除以 $\sqrt{4}=2$，得到 `[2, 1, 0]` | $QK^\mathsf{T}/\sqrt{d_k}$ |
| 3. 变成权重 | 得到约 `[0.67, 0.24, 0.09]` | $\operatorname{softmax}(\cdot)$ |
| 4. 汇总内容 | 这个坐标为 $0.67\times10+0.24\times0+0.09\times(-10)=5.8$ | 最后乘 $V$ |

把这四步压缩后，正式的缩放点积注意力写成：

$$
\operatorname{Attention}(Q,K,V)
= \operatorname{softmax}\left(\frac{QK^\mathsf{T}}{\sqrt{d_k}}\right)V
$$

这行公式应读成一条从左到右的计算流程，不需要一次记住所有符号。

因此，标题里的“注意力”不是某一个 $Q$ 或某一个权重，而是从输入表示产生 $Q/K/V$、计算匹配权重、再汇总 $V$ 的整条规则。

## 为什么按键维度开方缩放

先看一个用于解释尺度的理想化假设：$q$ 与 $k$ 的各坐标彼此独立、均值为 0、方差为 1。单项 $q_i k_i$ 的方差为 1，而点积是 $d_k$ 项之和，因此：

```formula-story
{
  "ariaLabel": "点积由 d_k 个方差约为一的乘积项相加，方差随 d_k 增长，再除以平方根维度恢复尺度",
  "title": "为什么分母恰好是 √d_k：先看方差怎样累加",
  "goal": "加了 d_k 项，方差约放大 d_k 倍；要把标准差拉回原尺度，就除以 √d_k。",
  "coversNext": 2,
  "pattern": "flow",
  "source": { "label": "qᵢkᵢ", "name": "一个坐标乘积", "detail": "理想化假设下均值 0、方差约 1", "tone": "blue" },
  "items": [
    { "label": "Σᵢ qᵢkᵢ", "name": "把 d_k 个独立乘积项相加", "detail": "独立项的方差相加，所以点积方差约为 d_k", "tone": "orange", "arrow": "累加 d_k 项" },
    { "label": "标准差 √d_k", "name": "分数典型幅度随维度增长", "detail": "方差开方才是与原分数同单位的标准差", "tone": "rose", "arrow": "开方" }
  ],
  "result": { "label": "÷ √d_k", "name": "缩放后方差约回到 1", "detail": "控制的是分数量级，不是修正语义相似性", "tone": "green", "arrow": "抵消尺度" },
  "example": { "label": "d_k=64", "text": "未缩放点积的标准差约为 8；除以 √64=8 后，标准差回到约 1。" },
  "counterfactual": { "label": "少开一次方", "text": "若直接除以 d_k，方差会从 d_k 压到约 1/d_k，缩放过强；若完全不除，softmax 输入会随维度变宽而更容易出现极端值。" },
  "boundary": "推导依赖坐标近似独立、零均值、单位方差；真实模型不严格满足，因此这是尺度设计依据，不是逐层精确统计定律。"

```

$$
\operatorname{Var}(q^\mathsf{T}k)=d_k.
$$

标准差于是随 $\sqrt{d_k}$ 增长。除以 $\sqrt{d_k}$ 后，理想化方差回到约 1：

$$
\operatorname{Var}\left(\frac{q^\mathsf{T}k}{\sqrt{d_k}}\right)\approx1.
$$

这解释了分母的数量级：它是在维度增大时控制 logits 尺度，不是让相似度“更正确”。真实训练后的坐标未必独立、同方差，LayerNorm 与初始化也会影响分布，所以这是设计动机和尺度推导，不是所有模型中方差都严格等于 1 的定理。

| 拿掉什么 | 立即发生什么 | 不能越界推出什么 |
|---|---|---|
| $1/\sqrt{d_k}$ | 高维点积典型幅度随维数增长，softmax 更容易饱和，较小概率项的梯度可能变弱 | 不能只凭公式断言任何具体模型质量必然下降 |
| 因果遮罩 | 训练时较早位置可读取未来 token，next-token 任务发生标签泄漏 | 不能说所有注意力都需要因果遮罩；编码器可双向读取 |
| softmax | 原始分数可为负且总和不受控，标准注意力不再是凸加权汇总 | 不能说所有注意力家族只能用 softmax |
| $V$ | 只剩“匹配了谁”的分数，没有对应内容可供汇总 | 不能把 Key 偷换成 Value；两者由不同投影承担不同职责 |

因此，把缩放项仅解释为“防止梯度消失”过于狭窄。是否带来质量、速度或稳定性收益，仍要在固定实现和训练口径下做消融实验。

## Decoder 必须遮住未来

**理解生成训练时必看。**

训练因果语言模型时，整段 token 可以并行输入，但位置 2 不能借用位置 3 的答案。因果遮罩把未来位置的注意力分数屏蔽掉：

```text
       可看位置
位置0  0
位置1  0 1
位置2  0 1 2
```

所以“自注意力能看到所有位置”只在没有相应遮罩时成立。

## 为什么多头

**需要追踪多头形状时再读。**

不同头使用不同投影，在不同表示子空间中计算注意力，再拼接并投影。某些头可能学到局部、语法或长距离模式，但不能预先保证每个头有清晰的人类角色。

设头数为 `H`，每头维度为 `D_h`，通常满足 `D = H × D_h`。一条常见的形状路线是：

| 步骤 | 形状 | 发生了什么 |
|---|---|---|
| 当前层隐藏状态 | `(B, T, D)` | 每个位置有一个 D 维表示 |
| Q/K/V 投影 | 三个 `(B, T, D)` | 学习三种不同用途的表示 |
| 拆头并转轴 | `(B, H, T, D_h)` | reshape 与转轴，没有减少总元素数 |
| QK 分数 | `(B, H, T, T)` | 每个头中，每个位置给各可见位置打分 |
| 加权 Value | `(B, H, T, D_h)` | 按权重汇总 Value |
| 拼头并输出投影 | `(B, T, D)` | 回到残差流需要的隐藏宽度 |

“子空间”可以先理解成每个头通过自己的投影读取的一组受限方向，而不是从原向量机械切下的几段固定语义。拆头本身是形状重排，头之间的差异来自学习到的投影矩阵。

MQA 和 GQA 通过减少或分组共享 Key/Value 头来降低推理时 KV Cache 成本；这是质量、速度、实现与内存之间的权衡，不应笼统宣称某方案“完全无损”。
