# D17：跟着张量走过 Transformer

> **学习导航**：承接 D06 的 Decoder 骨架与 D07 的运行过程；本课读取预生成前向追踪，不要求打开终端或修改代码。完成后应能把 tokenizer、Embedding、QKV、拆头、注意力、MLP、残差和 LM Head 对到真实形状，并判断每次变化是投影、reshape 还是轴保留。

## 本课核心判断

**结构图只列模块；形状追踪才能证明拆头是否改变信息量、残差能否相加、词表轴在哪里出现。**

## 预设案例：一次前向追踪

本页沿用调试模型的宽度，并把输入缩成便于观察的形状：`batch=2`、`time=8`、`hidden=32`、`heads=2`、`head_dim=16`、字符词表约 `418`。这是形状追踪配置，不是 D19 正式训练使用的 `cpu.yaml`；两者的模块和轴含义相同，具体层数、宽度和上下文长度不同。

| 顺序 | 张量 | 形状 | 发生了什么 |
|---:|---|---|---|
| 1 | `input_ids` | `(2, 8)` | 两个样本，每个 8 个 token ID |
| 2 | token + position Embedding | `(2, 8, 32)` | 每个位置变成 32 维浮点表示 |
| 3 | 合并 QKV | `(2, 8, 96)` | 一次线性层产生三份 32 维投影 |
| 4 | 拆头后的 Q/K/V | 各 `(2, 2, 8, 16)` | `32 = 2 x 16`，只是重排轴 |
| 5 | 注意力分数 | `(2, 2, 8, 8)` | 每个头中，每个查询位置对 8 个键位置打分 |
| 6 | 合并多头 | `(2, 8, 32)` | 头轴重新合并回隐藏宽度 |
| 7 | MLP 中间层 | `(2, 8, 128)` | 每个位置独立扩张到 `4D` |
| 8 | MLP 输出 | `(2, 8, 32)` | 收缩回残差宽度 |
| 9 | LM Head logits | `(2, 8, 418)` | 每个位置得到一份字符词表分数；单轮生成使用最后位置的这一份 |

## 三种容易混淆的变化

- `32 -> 96`：学习三套线性投影，数值和特征空间都改变。
- `32 -> 2 x 16`：reshape/转轴，总元素数不变，不是信息压缩。
- `32 -> 128 -> 32`：MLP 在每个 token 位置扩张再收缩，token 数仍是 8。

因果遮罩的预设测试在评估模式下使用两个“前缀相同、后缀不同”的序列。正确结果是：相同前缀位置的 logits 不应被未来不同后缀改变。这个测试检查局部因果性质，不证明模型已经学会语言。

对一个已有 8 个输入 token 的单轮生成，选择第 9 个 token 时读取最后位置 `logits[:, 7, :]` 的 418 个词表分数。训练时则把每个位置的 logits 与错开一位的下一个 token 目标比较。若样本来自连续 token 流，数据切片通常读取连续 9 个 token：前 8 个作输入，后 8 个作目标，因此第 8 个输入的目标就是第 9 个 token。若样本在序列末尾结束，则可把 EOS 作为目标，或用 loss mask 忽略没有目标的位置；不能随意拿无关的下一段文本补上。

## 用元素数量检查 reshape

`(B,T,D)=(2,8,32)` 一共有 `2 x 8 x 32 = 512` 个元素。拆成两个头后，单个 Q 的形状变为 `(2,2,8,16)`，元素仍是 `2 x 2 x 8 x 16 = 512`。这一步只是把 `D=32` 改写成 `H=2` 与 `D_h=16` 两个轴。

合并 QKV 的 `(2,8,96)` 有 1,536 个元素，因为线性层一次生成 Q、K、V 三份各 512 个元素的投影。注意力分数 `(2,2,8,8)` 则有 256 个元素，它来自每个头中 8 个 query 对 8 个 key 的两两打分，不应拿它与 QKV 元素数做“信息是否守恒”的判断。

元素数相同只证明 reshape 没有丢位置，不证明数值或语义没变。线性投影、softmax 和加权求和都会改变数值；检查形状是排错的一层，不是完整正确性证明。

## 从一个位置追踪它能读什么

把位置编号为 0 到 7。因果遮罩下，位置 5 的 query 可以读取 key 0 到 5，不能读取 6 和 7。softmax 后，这 6 个允许位置的权重在该头内归一化；被遮住位置应得到零权重或等价的不可见效果。

随后，位置 5 用这些权重汇总对应的 value，得到该头的上下文结果。两个头各做一次，再合并回 32 维。残差支路把进入注意力子层前的位置 5 表示加回来，因此主支路输出必须与残差保持相同 `(B,T,D)` 形状。
