# D18：用单 Batch 过拟合定位训练故障

> **学习导航**：承接 D09 的训练任务内部循环和 D17 的张量形状；本课阅读一份预生成单 batch 过拟合记录，不要求启动训练；完成后应能根据 loss 是否下降，把故障排查到输入目标、梯度、更新、学习率或 loss 实现。

## 本课目标

能把单 batch 过拟合理解为训练管线的局部测试，并区分“能记住眼前样本”和“能泛化到新样本”。

## 本课核心判断

**连一个固定 batch 都记不住时，先查训练管线，不要先增加数据、层数或训练时间。**

## 预设案例：冻结的教学日志

以下数值用于判读练习，不作为硬件或模型 benchmark：

| step | 固定 batch loss | 验证 loss | 观察 |
|---:|---:|---:|---|
| 0 | 6.10 | 6.05 | 随机初始化 |
| 25 | 3.72 | 5.98 | 开始记住固定 batch |
| 50 | 1.84 | 6.12 | 训练片段继续改善 |
| 100 | 0.42 | 6.48 | 已明显过拟合 |
| 200 | 0.08 | 6.91 | 几乎记住固定 batch，验证更差 |

正确结论是“前向、梯度和参数更新至少能让模型记住这个固定 batch”。它不能证明数据切分正确、验证泛化良好、生成自然或真实项目可用。

## 如果曲线不下降，按因果链排查

1. 输入与目标是否错开一位。
2. loss 是否读取了正确 logits 和 targets。
3. 参数是否得到非空、有限梯度。
4. 更新步骤是否真的改变参数。
5. 学习率是否过小、过大或被错误调度。
6. 训练模式、遮罩和随机层是否符合预期。

不要用“模型太小”作为第一解释。一个容量足够的微型模型通常应该能记住一个很小的固定 batch；先把最短因果链逐段验证。

## 把每一段因果链变成可观察证据

“检查梯度”不能只看代码里有没有 `backward()`，而要为每一段留下一个能证伪的观察：

| 链路 | 最小观察 | 能排除什么 | 仍不能证明什么 |
|---|---|---|---|
| 输入 -> 目标 | 打印同一样本的 token 与右移目标 | 明显错位、空目标、错误 mask | 数据语义正确 |
| loss -> 梯度 | 至少一个目标参数的梯度有限且非零 | 参数完全没接入计算图 | 梯度方向一定正确 |
| 梯度 -> 更新 | 更新前后同一参数存在有限差值 | `optimizer.step()` 没生效 | 学习率合适 |
| 多步趋势 | 固定 batch loss 在若干步总体下降 | 管线具备记忆这批样本的能力 | 验证泛化 |

如果 loss 不动，可以按这张表从左到右缩小范围。若参数有更新但 loss 剧烈振荡，再检查学习率、梯度裁剪和数值范围；若固定 batch 很快下降而验证持续变差，训练内核可能正常，问题转向覆盖、切分和泛化。

## 四种曲线对应四条下一步

| 现象 | 当前最合理的解释 | 下一项检查 |
|---|---|---|
| 固定 batch loss 完全水平 | 没有有效学习信号或更新 | 目标、mask、梯度、参数差值 |
| 先降后 NaN | 学习链已接通，但出现数值异常 | 首个异常 step、学习率、输入范围 |
| 很快接近 0 | 模型成功记忆固定样本 | 切回训练/验证分离的正常流程 |
| 固定 batch 降，验证升 | 局部记忆成立，泛化未成立 | 数据覆盖、切分、正则化和训练时长 |

单 batch 测试结束后应恢复正常的数据采样、dropout 和评测配置，不能把这个调试状态继续当作正式训练。
