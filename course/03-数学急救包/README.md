上面最后一行不要背成“所有可能的三元数字组合”。先看例子：`[2, 0.5, -1]` 就是**一排三个数**，第一格是 `2`，第二格是 `0.5`，第三格是 `-1`。每一格都允许换成任意实数，所有这样的三格数列合在一起才叫 $\mathbb{R}^3$；它不是某一个向量，也不是某一张矩阵。

**实数**就是数轴上能找到位置的数，包括负数、0、正数、分数和小数；还包括 $\sqrt2$ 这类写不成有限小数或循环小数的数。第一次只需记住：模型公式说“实数”，通常是在说明某个位置允许放哪一类数。

## 公式里的字母先这样读

数学字母是名字，不是对象本身。作者可以把 $x$ 改名为 $u$，把 $W$ 改名为 $M$；真正不能随意改变的是它代表的对象类型、形状和运算关系。本课程默认使用下面的习惯，但每个公式旁边的局部说明优先：

| 常见写法 | 本课程通常表示 | 需要记住 |
|---|---|---|
| $x,y,a,b,q,k,v$ | 单个标量或向量 | 小写只是常见习惯，必须结合正文和形状判断 |
| $W,A,B,S,Q,K,V,X$ | 矩阵、状态，或把多个向量堆起来的张量 | 大写不保证一定是矩阵，例如某些论文用 $N,D,B$ 表示数量 |
| $\alpha,\beta,\eta$ | 缩放、上界、学习率等标量系数 | 希腊字母同样只是命名习惯 |
| $i,j,t$ | 位置、列号或时间步下标 | 下标回答“第几个”或“第几步” |
| $\mathbb{R}^d$ | 所有 $d$ 维实数向量组成的空间 | 空间不是某一个向量，也不是执行变换的矩阵 |

## 核心公式的七问读法

看到核心公式时按下面顺序读；已经掌握者可以只扫每页的“构造理由与删项检查”。

1. **问题来源**：没有这条规则时，具体失败是什么？
2. **构造过程**：能否从约束、目标或前一行一步步得到它？
3. **参数职责**：每个符号是什么对象、形状和作用？
4. **数值方向**：案例结果是越大越好、越小越好、越接近目标越好，还是根本没有统一好坏？理想端、当前数值的含义与可比条件是什么？
5. **删项检查**：删掉一项、固定为 `0/1` 或换错运算，哪个性质立即消失？
6. **反向白话**：能否用两三个数构造错误结果，而不是只复述定义？
7. **成立边界**：这是数学恒等式、局部近似、设计动机，还是需要消融实验支持的效果结论？

数学推导可以证明等式或局部性质；删项反例可以证明某个部件在该机制中承担什么；“质量更高、训练更快、泛化更好”仍需受控对照或消融实验，不能由公式外形直接推出。
