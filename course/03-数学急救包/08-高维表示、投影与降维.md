# 高维表示、投影与降维

> **使用位置**：D02-D06、D11 和 D14 会反复遇到维度变化；学完应能判断一次操作是查表、线性投影、reshape、低秩限制还是只用于分析的可视化降维。

本页把 Embedding、隐藏状态、Q/K/V、MLP、LoRA 和二维可视化放进同一套“表示空间”语言中。学习目标不是想象出 4096 维空间，而是能追踪形状，并判断一次操作到底是查表、投影、重排还是分析降维。

## 从一排数到表示空间

若隐藏维度 $D=4096$，每个 token 在某一层、某一位置都有 4096 个数。可以把这排数看成高维空间中的一个点，也可以把它看成从原点出发的一条方向。

这两种视角分别帮助回答：

- 点视角：两个表示在选定度量下是否接近？
- 方向视角：某个变换或查询沿哪些组合方向读取信息？

坐标位置和维数由模型架构规定，训练则塑造每个位置怎样参与表示，以及哪些方向、区域或边界对任务有用。这些坐标通常没有固定的人类名称；有用模式可能分散在许多坐标中。

## Embedding 不等于后续隐藏状态

Embedding 是根据 token ID 查出的初始向量。同一个模型中，同一个 ID 首先读取同一行 token Embedding；加入位置信息并经过 Transformer 层后，它会逐步变成上下文化隐藏状态。

因此，同一个“苹果”出现在“吃苹果”和“苹果发布新品”中，初始 token Embedding 可以相同，后续隐藏状态却会因上下文不同而变化。讨论模型内部语义时，必须说明观察的是哪一层、哪个位置、哪种表示。

## 投影是在学习新的坐标组合

先看形状，不急着看公式。若输入 $x=[2,1]$ 有 2 个坐标，矩阵 $W$ 为 `2 × 3`，那么输出会有 3 个坐标：

```text
[2 个输入坐标] × [2 × 3 的矩阵] -> [3 个输出坐标]
```

三个输出坐标分别由输入 `[2,1]` 按矩阵的三列重新组合。若还加上偏置 $b$，完整线性层写成：

| 符号 | 对象类型 | 作用 |
|---|---|---|
| $x$ | 输入向量 | 输入空间中的一个具体表示 |
| $W$ | 权重矩阵 | 从输入空间到输出空间的变换规则，不是空间本身 |
| $b$ | 偏置向量 | 给每个输出坐标增加一个可学习偏移 |
| $y$ | 输出向量 | 输出空间中的一个具体表示 |

$$
y=xW+b.
$$

若 $x$ 的最后一维是 $D_{in}$，矩阵 $W$ 把它映射到 $D_{out}$。$D_{out}>D_{in}$ 常被口语化为升维，$D_{out}<D_{in}$ 常被称为降维，但维度数量变化本身不保证信息增加或减少多少：这还取决于矩阵、数据分布、非线性和训练目标。

所以“投影是在学习新的坐标组合”与公式的对应关系是：$W$ 的每一列定义一个输出坐标怎样组合输入，$y$ 收集这些新坐标；输入空间和输出空间是所有可能的 $x$ 与 $y$，不是某一个矩阵变量。

Transformer 中常见的变化包括：

| 位置 | 形状变化 | 应怎样理解 |
|---|---|---|
| token Embedding | `ID -> D` | 按 ID 查表，不把 ID 当连续数值升维 |
| QKV 投影 | `D -> 3D` | 产生 Query、Key、Value 三套表示 |
| 拆成多头 | `D -> H × D_h` | 通常是 reshape，且 `D = H × D_h` |
| MLP | `D -> 4D -> D` | 暂时扩展逐位置计算宽度，再回到残差宽度 |
| LM Head | `D -> V` | 为词表中 $V$ 个候选产生 logits |
| 多模态连接器 | `D_{vision} -> D_{language}` | 对齐接口宽度，不保证两种模态已经语义对齐 |

残差相加两侧必须具有兼容形状，所以多数 Transformer Block 的入口和出口都保持同一个隐藏维度。内部可以暂时变宽、拆头或进入较窄潜空间，最后仍需回到残差流的宽度。

## 子空间与低秩

子空间可以先理解成高维空间中受限的一组方向。例如三维房间中的一张平面只有两个独立方向，但仍位于三维空间中。

若矩阵更新写成 $\Delta W=BA$，且中间秩 $r$ 很小，那么 $\Delta W$ 的秩最多为 $r$。$A$、$B$ 都由训练学习，因此这些方向不是事先固定的；LoRA 限制的是更新矩阵的秩和可训练自由度，不保证这种限制足以表达目标任务需要的全部更新。

“低秩”描述的是独立方向数量受限，不等于权重数值小、模型被无损压缩，或推理计算一定按相同比例下降。

## 二维图是高维关系的摘要

把高维表示画到二维时，不可能保留所有关系。不同方法保护的重点不同：

| 方法 | 主要目标 | 常见误读 |
|---|---|---|
| PCA | 保留线性投影下较大的总体变化方向 | 前两轴解释了全部结构 |
| t-SNE | 强调局部邻域的可视分离 | 簇间距离和簇大小可直接比较 |
| UMAP | 在一定假设下兼顾局部结构与部分整体关系 | 一张图就是高维空间的真实地图 |

使用二维图至少要写清：取自哪一层、哪些 token、是否归一化、使用什么降维方法、随机种子和参数。图上的簇可以提出问题，不能单独证明模型形成了人类定义的概念。

## 高维空间里的三个提醒

1. 维度增大时，点积会累加更多项，所以注意力需要按 $\sqrt{d_k}$ 缩放分数。
2. 欧氏距离、点积和余弦相似度回答的问题不同，不能只说“距离”。
3. 高维数据的距离分布可能变得不直观；是否适合某种度量，应通过任务和检索评测验证。

## 四级练习

**L1 · 形状追踪**：`D=64, H=4` 时，每个头的维度 $D_h$ 是多少？拆头后总数是否减少？

<details><summary>参考答案</summary>

$D_h=64/4=16$。`4×16=64`，拆头只重排同一批数，没有因为增加了 head 轴就减少总元素数。

</details>

**L2 · 概念辨析**：为什么不能把 token ID `7` 经过 Embedding 说成“把数值 7 升维到 4096 维”？

<details><summary>参考答案</summary>

这里按程序常用的零基索引编号：ID 7 指人从第 1 行数起的第 8 行，不是带有连续大小意义的输入坐标。Embedding 操作读取这一行的 4096 个可训练数字；把 ID 改成 8 会读取下一行，而不是对数值 7 做连续变换。

</details>

**L3 · 构造反例**：两个向量方向完全相同，但点积不同。给出一个例子并解释原因。

<details><summary>一种构造</summary>

取 $a=[1,0]$、$b=[2,0]$、$c=[10,0]$。$a\cdot b=2$，$a\cdot c=10$，但 $b$ 与 $c$ 相对 $a$ 的余弦相似度都为 1。点积差异来自长度，不是方向。

</details>

**L4 · 多概念综合**：一张 t-SNE 图显示两个簇相距很远，可以直接宣布模型把它们理解成完全无关的概念吗？

<details><summary>参考答案</summary>

不能。t-SNE 主要保护局部邻域，二维簇间距离可能被算法和参数显著改变。还要核对原始高维度量、样本选择、层位置、随机种子，并用独立任务验证这种分离是否有实际意义。

</details>

参考：[scikit-learn 降维方法说明](https://scikit-learn.org/stable/modules/manifold.html)与 [PCA 文档](https://scikit-learn.org/stable/modules/decomposition.html#pca)。
