# 数、比例与平均数

> **使用位置**：D01 的候选概率、D03-D04 的学习率、D08 的数据比例、D09-D10 的日志与数量级都会用到；学完应能写清分子、分母、平均范围和数量级。

## 第一次必看：本页公式先给数起名字

在本页的比例与平均数例子中，字母不是一种新数字，而是给暂时未知或会变化的数起的名字，数学上叫**变量**。例如“共有 20 题，答对 15 题”可以写成 $n=20,k=15$；$n>0$ 读作“$n$ 大于 0”。更一般地，变量也能代表向量、矩阵等对象，必须看公式在当前位置怎样定义它。

| 写法 | 小学算术读法 | 本页用途 |
|---|---|---|
| $-3$ | 比 0 小 3 的负数；在数轴 0 的左边 | 可表示温度差、参数或 logit，但比例不能因此随意为负 |
| $0.25$ | 小数，等于四分之一 | 直接表示比例 |
| $\frac{k}{n}$ | $k\div n$；$k$ 是分子，$n$ 是分母，分母不能为 0 | 满足条件数除以总机会数 |
| $75\%$ | 每 100 份中占 75 份，等于 $75\div100=0.75$ | 把比例改写成百分数 |

**同一个数可以有不同写法：** $\frac34=0.75=75\%$。它们的数值相同，只是强调方式不同。

## 比例

若 $n>0$ 个对象中有 $k$ 个满足条件，就把比例命名为 $r$，写成 $r=k/n$。这里的分数线就是除法。因此 20 个样本中答对 15 个，准确率为：

$$
r=\frac{15}{20}=0.75=75\%.
$$

**比例必须同时写清事件、分子和分母。** “错了 5 个”在 10 个样本中是 50%，在 1000 个样本中是 0.5%；不同测试集、过滤规则或缺失值处理得到的分母不同，比例就不能直接比较。

**为什么是“事件数除以机会数”？** 分母给出事件本可发生的总机会，分子只数实际满足条件的机会。去掉分母只剩计数，无法跨样本量比较；换错分母则回答了另一个问题。例如 20 题答对 15 题，若误除以“答错的 5 题”得到 3，这不再是限制在 `[0,1]` 的准确率。

还要区分**百分点**与**相对变化**：准确率从 60% 升到 75%，增加了 `15 个百分点`，相对原值则增加了 $(75-60)/60=25\%$。两种说法都可以，但不能混用。

在同一批题、同一判分规则下，准确率通常越大越好，`100%` 是最高端；上例 `75%` 表示每 100 次有效判断中约 75 次答对。但换了题集、样本难度或判分规则后，两个准确率不能仅凭数值直接比较；准确率也不描述错误有多严重、概率是否校准或生成文本是否安全。

## 平均数

三个同样大小、计分位置同样多的 batch，其 loss 分别是 `2、1、3`，算术平均是 $(2+1+3)/3=2$。**这里的 loss 采用后文的平均交叉熵：同口径下越小越好，理论最小值为 0；但 `2` 本身没有跨任务通用的“及格/不及格”含义。** 本节只用它练习平均，完整解释见[对数与交叉熵](05-对数与交叉熵.md#先看单个位置)。

若第 $i$ 个 batch 的平均 loss 是 $x_i$，有效 token 数是 $w_i$，并且所有 $w_i\ge0$、总有效 token 数 $\sum_iw_i>0$，整体逐 token 平均应为加权平均：

```formula-story
  "counterfactual": { "label": "拿掉 wᵢ", "text": "直接算 (1+3)/2=2，会让 10-token 批次与 90-token 批次拥有同样话语权。" },
  "boundary": "计数权重必须非负、总权重必须大于 0，并对应被平均量的计数单位；若所有 batch 都没有有效 token，分母为 0，公式没有定义。按样本、token 或序列加权会得到不同而各自可能合理的口径。"

```

$$
\bar{x}=\frac{\sum_i w_i x_i}{\sum_i w_i},\qquad w_i\ge0,\quad \sum_iw_i>0.
$$

例如两个 batch 的平均 loss 都是按 token 算的：第一个有 10 个有效 token、loss 为 1；第二个有 90 个有效 token、loss 为 3。简单平均得到 2，而逐 token 平均应为 $(10\times1+90\times3)/100=2.8$。这只说明这 100 个有效 token 的平均交叉熵为 `2.8`；要判断训练是否改善，应与**相同模型目标、数据、tokenizer、mask 和聚合口径**下的其他 step 或验证集结果比较，不能只凭 `2.8` 设统一好坏线。

加权平均的分子 $\sum_iw_ix_i$ 先把每组平均还原为总贡献，分母 $\sum_iw_i$ 再除以全部有效单位。去掉权重会让 10 token 与 90 token 的 batch 拥有相同话语权；只保留加权和而不除总权重，结果会随样本数量放大，不再是“每个有效 token 的平均”。若所有 $w_i$ 都为 0，则没有任何有效单位可供平均，不能执行除法；实现应跳过该批或采用事先写明的处理规则。

**平均值相同不代表分布相同。** `[0,100]` 与 `[49,51]` 的平均值都是 50，但波动和风险完全不同；训练曲线仍要同时看时间变化、分位数或异常点。

## 科学记数法

`1e-3` 是程序常用的科学记数法，读作“$1\times10^{-3}$”，不是 softmax 中常数 $e$ 的三次方。展开就是 $1\mathrm{e}{-3}=1\times10^{-3}=1/(10\times10\times10)=0.001$。

同理，`2e-4 = 0.0002`。学习率常这样写。`1e-4` 是 `1e-3` 的十分之一，也就是小一个数量级，不是只小一点点；右上角的 `-4` 叫负整数指数，表示先算 $10^4$ 再取倒数，所以 $10^{-4}=1/10^4$，并不表示结果是负数。

## 自测

1. 80 个样本中 60 个合格，合格率是多少？
2. 准确率从 40% 升到 50%，增加了多少个百分点？相对提升多少？
3. `1e-5` 与 `1e-4` 哪个更大，相差几倍？

<details><summary>核对</summary>

合格率是 $60/80=0.75=75\%$。准确率增加 10 个百分点，相对提升 $(50-40)/40=25\%$。`1e-4` 更大，是 `1e-5` 的 10 倍。

</details>
