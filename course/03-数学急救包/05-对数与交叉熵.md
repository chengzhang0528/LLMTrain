# 对数与交叉熵

> **使用位置**：D03 的 loss、D08 的标签和 D09 的训练日志都会用到；学完应能从正确 token 的概率算出单位置 loss，再把多个有效位置汇总成平均 loss。

## 先看单个位置

只需记住：自然对数 $\ln(p)$ 在 $0 < p \le 1$ 时不大于 0，所以 $-\ln(p)$ 不小于 0。

这里 $p$ 是“正确 token 的预测概率”这个标量，$\ln$ 是对数函数，不是另一个变量。字母 $p$ 常取自 probability，但换成别的字母不会改变计算。

如果正确 token 的预测概率是：

| 正确 token 概率 | 损失 $-\ln(p)$（约） |
|---:|---:|
| 0.9 | 0.105 |
| 0.5 | 0.693 |
| 0.1 | 2.303 |

模型越相信正确答案，损失越小；对错误答案越自信，惩罚越大。语言模型训练通常对序列中需要预测的位置取平均交叉熵。

## 再汇总多个位置

若一句训练序列有三个有效预测位置，单位置 loss 分别是 `0.105、0.693、2.303`，平均交叉熵约为：

$$
(0.105+0.693+2.303)\div3\approx1.034.
$$

这个平均数能用于优化和比较趋势，却不能指出第三个位置到底错成了哪个 token。padding、提示词或其他不应计分的位置必须先 mask 掉；它们不计入 loss，最后只对有效位置求平均。

困惑度常定义为 $\exp(\text{平均交叉熵})$。它依赖 tokenization 和数据集，不能脱离相同评测设置横向比较。

## 立即自检

正确 token 概率从 `0.1` 提高到 `0.9`，交叉熵会增大还是减小？这能否单独证明整段生成更可靠？

<details><summary>核对</summary>

单位置交叉熵从约 `2.303` 降到 `0.105`。它只说明这个位置对正确 token 的概率提高，不能单独证明整段文本的事实性、安全性或泛化能力。

</details>
