# 对数与交叉熵

> **使用位置**：D03 的 loss、D08 的标签和 D09 的训练日志都会用到；学完应能从正确 token 的概率算出单位置 loss，再把多个有效位置汇总成平均 loss。

## 第一次必看：对数是在反问右上角的指数

先看 $2^3=2\times2\times2=8$。这种把相同的数连续相乘并简写的运算叫**乘方**：`2` 是反复相乘的**底数**，右上角的 `3` 是**指数**，整个 $2^3$ 叫一个**幂**，它算出的值是 `8`。

对数把问题倒过来问：**“底数 2 的右上角应该填几，结果才是 8？”** 答案是 3，所以写成 $2^3=8\Longleftrightarrow\log_2(8)=3$。这里 $\log_2(8)$ 读作“以 2 为底，8 的对数”；右下角的 `2` 是底数，括号里的 `8` 是已知结果，算出来的 `3` 是原来右上角的指数。

一般地，在 $a>0$ 且 $a\ne1$、输入 $p>0$ 时，若 $a^b=p$，就有 $\log_a(p)=b$。第一次先记大白话：**对数的答案，就是乘方中原本要填在右上角的数。**

$\ln$ 是底数固定为 $e\approx2.718$ 的对数，叫自然对数。它是一个函数名：函数可以先理解为“每给一个允许的输入，就按固定规则给一个输出的机器”。因此 $\ln(p)$ 是把 $p$ 交给 `ln` 计算，不是字母 `l`、`n`、`p` 相乘。

## 先看单个位置

自然对数是底数为 $e$ 的指数运算的逆运算：若 $e^a=p$，则 $\ln(p)=a$。当 $0<p\le1$ 时，$\ln(p)\le0$，所以 $-\ln(p)\ge0$。

这里 $p$ 是“正确 token 的预测概率”这个标量，$\ln$ 是对数函数，不是另一个变量。字母 $p$ 常取自 probability，但换成别的字母不会改变计算。

如果正确 token 的预测概率是：

| 正确 token 概率 | 损失 $-\ln(p)$（约） |
|---:|---:|
| 0.9 | 0.105 |
| 0.5 | 0.693 |
| 0.1 | 2.303 |

**先建立数值印象：这里的 loss 越小越好，理论最小值是 0，不是越接近 1 越好。** 当正确 token 概率 $p=1$ 时，$-\ln(1)=0$；$p$ 越接近 0，loss 越大，并在 $p=0$ 时达到正无穷。表中的 `0.105` 比 `0.693` 好，是因为模型给正确 token 的概率更高；`2.303` 表示只给了正确 token 约 `10%` 的概率。

但 loss **没有脱离口径的统一及格线**。训练时通常希望同一目标下的训练 loss 下降，并更关注未参与训练的验证 loss 是否也下降；只有 loss 定义、数据、tokenizer、mask 和求平均方式一致时，两个数才适合直接比较。loss 更低也只说明更符合这项训练目标，不自动代表事实性、安全性或最终产品质量更好。

## 为什么是负对数

先认两个缩写符号：$\prod$ 表示把一串数相乘，$\sum$ 表示把一串数相加。例如 $\prod_{t=1}^{3}p_t=p_1p_2p_3$，而 $\sum_{t=1}^{3}\ln p_t=\ln p_1+\ln p_2+\ln p_3$。

设一段序列中正确 token 的条件概率依次为 $p_1,p_2,\ldots,p_T$。联合似然是乘积 $\prod_t p_t$，长序列中它会迅速变成极小数。取对数后，乘积变成可相加的和：

$$
-\ln\prod_t p_t=-\sum_t\ln p_t.
$$

负号把“最大化正确序列的似然”改写成常见优化器可最小化的非负损失；对数还会重罚非常自信的错误。例如线性惩罚 $1-p$ 在 $p=0.9$ 与 $p=0.001$ 时分别是 `0.1` 与 `0.999`，差不到 10 倍；负对数约为 `0.105` 与 `6.908`，能明显区分后者的极端错误。

| 改掉什么 | 立即发生什么 |
|---|---|
| 去掉负号 | 正确概率越高，$\ln p$ 越接近 0、数值反而越大；直接最小化会把方向弄反 |
| 去掉对数，改用 $1-p_y$ | 仍可构造一种损失，但失去对数似然的可加关系，对极小正确概率的惩罚也弱得多 |
| 去掉 one-hot 标签中的 $q_i$ | 不再知道哪个候选是训练目标，无法从整组预测中选出应受奖励的一项 |

这说明负对数似然的构造理由，不表示交叉熵是所有任务唯一的损失函数；软标签、多标签、排序或偏好任务会使用不同目标。

## 交叉熵的一般定义

设目标分布为 $q=(q_1,\ldots,q_K)$，模型预测分布为 $p=(p_1,\ldots,p_K)$。它们都是按同一候选顺序排列的概率向量，第 $i$ 个位置必须指同一个候选。交叉熵为：

```formula-story
  "title": "单位置交叉熵：先在类别轴计分，再谈跨 token 汇总",

  "example": { "label": "one-hot", "text": "若正确候选 y 的 q_y=1、其余 q_i=0，单位置交叉熵只剩 -ln p_y。" },
  "counterfactual": { "label": "混错轴", "text": "Σ_i 加的是同一位置的候选类别；Σ_t 加的是多个预测位置，二者回答不同问题。" },
  "boundary": "采用 0·ln 0=0 的极限约定；若 q_i>0 而 p_i=0，交叉熵为正无穷。q 和 p 必须是同一候选集合上的概率分布。"

```

$$
H(q,p)=-\sum_{i=1}^{K}q_i\ln p_i.
$$

语言模型的普通 next-token 标签通常是 one-hot：正确 token 的 $q_y=1$，其余为 0，于是公式化简为 $-\ln p_y$。**“只看正确 token 概率”是 one-hot 标签下的特例，不是交叉熵对所有软标签任务的完整定义。**

对固定目标分布 $q$，交叉熵在预测分布 $p=q$ 时达到最小；这个最小值是目标分布自身的熵 $H(q)$，一般不一定为 0。只有 one-hot 目标的熵为 0，才得到上文“理论最好端为 0”的结论。例如 $q=[0.5,0.5]$ 时，最优预测同样是 $p=[0.5,0.5]$，交叉熵最小值为 $-0.5\ln0.5-0.5\ln0.5=\ln2\approx0.693$，不是 0。

公式使用极限约定：当 $q_i=0$ 时，即使 $p_i=0$，该项也按 $0\ln0=0$ 计；当目标要求某项 $q_i>0$ 而模型给出 $p_i=0$ 时，该项及交叉熵为正无穷。实际实现通常直接使用数值稳定的 `log_softmax` / cross-entropy 算子，避免先计算极小概率再取对数。

## 再汇总多个位置

$$
(0.105+0.693+2.303)\div3\approx1.034.
$$

**怎样读 `1.034`：** 它是这三个有效位置的平均交叉熵，不是 `103.4%`，也不是准确率。对这项交叉熵而言，`0` 是理论最好端，`1.034` 越往 0 降表示模型平均给目标 token 更高的概率；但只有在数据、tokenizer、mask 和聚合方式不变时，才能据此说另一个 loss 更好。

更一般地，令 $m_t\in\{0,1\}$ 表示位置 $t$ 是否计分，$y_t$ 是该位置的目标 token，则：

$$
L=-\frac{1}{\sum_t m_t}\sum_t m_t\ln p_t(y_t).
$$

这个平均数能用于优化和比较趋势，却不能指出某个位置到底错成了哪个 token。padding、被遮掉的提示词或其他不计分位置必须满足 $m_t=0$；不同框架也可能按 token、序列或 batch 再聚合，读日志时必须核对口径。

这里的 $m_t$ 与分母各有独立职责：去掉 mask，padding 或本来不应监督的位置会污染目标；保留 mask 但去掉有效 token 分母，loss 会随本批有效长度线性放大，不同长度 batch 的数值与更新尺度就不能直接比较。若 $\sum_t m_t=0$，公式没有定义，实现必须跳过该批或采用明确的安全处理，不能除以零。

使用自然对数时，困惑度常定义为 $\exp(\text{平均交叉熵})$。在相同口径下，它同样越小越好，理论最小值为 1；本例平均 loss 为 `1.034`，对应困惑度约为 $e^{1.034}\approx2.81$。它可直观理解为该损失对应的“有效候选规模”，但不是字面上的候选数量。它强烈依赖 tokenizer、数据集、mask 和聚合口径，不能脱离相同设置横向比较。

## 立即自检

正确 token 概率从 `0.1` 提高到 `0.9`，交叉熵会增大还是减小？这能否单独证明整段生成更可靠？

<details><summary>核对</summary>

单位置交叉熵从约 `2.303` 降到 `0.105`。它只说明这个位置对正确 token 的概率提高，不能单独证明整段文本的事实性、安全性或泛化能力。

</details>
