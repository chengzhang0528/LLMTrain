# 对数与交叉熵

> **使用位置**：D03 的 loss、D08 的标签和 D09 的训练日志都会用到；学完应能从正确 token 的概率算出单位置 loss，再把多个有效位置汇总成平均 loss。

## 先看单个位置

自然对数是指数函数的逆运算：若 $e^a=p$，则 $\ln(p)=a$。当 $0<p\le1$ 时，$\ln(p)\le0$，所以 $-\ln(p)\ge0$。

这里 $p$ 是“正确 token 的预测概率”这个标量，$\ln$ 是对数函数，不是另一个变量。字母 $p$ 常取自 probability，但换成别的字母不会改变计算。

如果正确 token 的预测概率是：

| 正确 token 概率 | 损失 $-\ln(p)$（约） |
|---:|---:|
| 0.9 | 0.105 |
| 0.5 | 0.693 |
| 0.1 | 2.303 |

模型越相信正确答案，损失越小；对错误答案越自信，惩罚越大。语言模型训练通常对序列中需要预测的位置取平均交叉熵。

## 交叉熵的一般定义

设目标分布为 $q=(q_1,\ldots,q_K)$，模型预测分布为 $p=(p_1,\ldots,p_K)$，则交叉熵为：

$$
H(q,p)=-\sum_{i=1}^{K}q_i\ln p_i.
$$

语言模型的普通 next-token 标签通常是 one-hot：正确 token 的 $q_y=1$，其余为 0，于是公式化简为 $-\ln p_y$。**“只看正确 token 概率”是 one-hot 标签下的特例，不是交叉熵对所有软标签任务的完整定义。**

数学上若目标要求某项 $q_i>0$，而模型给出 $p_i=0$，loss 会趋于无穷大。实际实现通常直接使用数值稳定的 `log_softmax` / cross-entropy 算子，避免先计算极小概率再取对数。

## 再汇总多个位置

若一句训练序列有三个有效预测位置，单位置 loss 分别是 `0.105、0.693、2.303`，平均交叉熵约为：

$$
(0.105+0.693+2.303)\div3\approx1.034.
$$

更一般地，令 $m_t\in\{0,1\}$ 表示位置 $t$ 是否计分，$y_t$ 是该位置的目标 token，则：

$$
L=-\frac{1}{\sum_t m_t}\sum_t m_t\ln p_t(y_t).
$$

这个平均数能用于优化和比较趋势，却不能指出某个位置到底错成了哪个 token。padding、被遮掉的提示词或其他不计分位置必须满足 $m_t=0$；不同框架也可能按 token、序列或 batch 再聚合，读日志时必须核对口径。

使用自然对数时，困惑度常定义为 $\exp(\text{平均交叉熵})$。它可直观理解为该损失对应的“有效候选规模”，但不是字面上的候选数量。它强烈依赖 tokenizer、数据集、mask 和聚合口径，不能脱离相同设置横向比较。
