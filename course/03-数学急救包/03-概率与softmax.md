# 概率与 softmax

> **使用位置**：D01 的候选概率、D05 的注意力权重和 D07 的采样都会用到；学完应能把两三个 logits 手算成总和为 1 的归一化权重，并根据计算轴说明它何时是条件概率、何时只是加权系数。

## 从任意分数到归一化权重

**事件**就是要判断是否发生的一件事，例如“下一次抛硬币出现正面”。**概率**是在某个明确模型或实验条件下给事件分配的 0 到 1 之间的数；数越大，表示在该条件下越可能发生。事件 $A$ 的概率记为 $P(A)$，读作“$A$ 的概率”，满足 $0\le P(A)\le1$。它不是只凭一次结果算出的百分比，也不自动等于模型答案的事实正确率。

若要把一组事件的各自概率直接并列成一份**无重叠、无遗漏的分类分布**，这些事件必须彼此互斥并穷尽当前样本空间，此时它们的概率和必为 1。“会写代码”和“会数学”可以同时发生，不能直接当成二选一分类相加。反过来，几个概率数值碰巧加到 1，也不能证明对应事件互斥且穷尽；必须检查事件本身的关系。

模型先对 $K$ 个候选产生一排任意实数分数 `[z₁,…,zₖ]`，这排数叫 logits 向量。$K$ 是候选总数，$z_i$ 是第 $i$ 个候选的分数；$\sum_{j=1}^{K}$ 读作“把 $j=1$ 到 $K$ 的各项加起来”。softmax 将它们转换为：

$$
w_i=\frac{e^{z_i}}{\sum_{j=1}^{K}e^{z_j}},\qquad i=1,\ldots,K.
$$

当 $z_1,\ldots,z_K$ 都是有限实数时，数学上每个 $w_i$ 都严格大于 0，全部 $w_i$ 的和为 1。若这些索引代表一组互斥且穷尽的候选事件，可以记 $p_i=w_i$ 并解释为预测概率；其他场景继续称为权重。**softmax 只把当前计算轴上的相对分数归一化，不负责证明候选集合、模型知识或答案本身正确。** 同一个公式的输出含义由“沿哪个轴算、后面拿它做什么”决定：

| 使用位置 | softmax 沿什么轴 | 输出应怎样解释 |
|---|---|---|
| 语言模型输出头 | 当前词表候选 | 给定当前上下文时的 next-token 条件分布；解码器随后才决定采样或取最大项 |
| 分类模型输出头 | 预先定义、互斥且穷尽模型目标空间的类别 | 封闭类别集合内的预测分布，不自动等于校准后的真实正确率；开放集输入仍可能被迫分给已有类别 |
| 注意力机制 | 当前 Query 可见的 Key 位置 | 汇总 Value 的非负归一化权重；标准计算并没有据此随机选中一个位置 |

注意力遮罩常把不可见位置的分数写成 $-\infty$，这是“从候选集合排除该位置”的记号或极限写法，不是有限实数 logit。更直接的定义是：只对至少一个可见位置做 softmax，再令被遮罩位置权重为 0。若某一行没有任何可见位置，普通公式会变成无有效分母，数学上无定义；实现必须禁止这种输入或明确规定专门行为，不能把它默认为正常概率分布。即使全部 logits 有限，浮点计算也可能把极小权重下溢成 0，所以“严格大于 0”是实数公式的性质，不是所有数值存储结果的保证。

### 先看懂 $e^z$：乘方、底数、指数与幂

$2\times2\times2$ 可以简写成 $2^3$，这种运算叫**乘方**。在这个例子里，反复参与相乘的 `2` 叫**底数**，右上角说明“有几个 2 相乘”的 `3` 叫**指数**，整个 $2^3$ 叫一个**幂**，算出的值是 `8`。有些资料也会把结果 `8` 叫作“这个幂的值”，所以看到“幂”时要问清是在说表达式还是结果。

$e^z$ 读作“$e$ 的 $z$ 次方”，也常写成 $\exp(z)$。它和 $2^3$ 使用同一种乘方写法，但这里的指数 $z$ 不一定是正整数：

| 对象 | 在 $e^z$ 中是谁 | 先这样理解 |
|---|---|---|
| 底数 | $e\approx2.718$ | 一个固定数学常数，不是模型参数 |
| 指数 | $z$ | 写在右上角，告诉乘方按哪个指数来算；它是输入，不是答案 |
| 幂 | $e^z$ | 整个表达式；算出的值是正数，softmax 把这个值当作尚未归一化的权重 |

| $z$ | 怎样理解 | $e^z$ 约等于 |
|---:|---|---:|
| $0$ | 任意非零底数的 0 次方为 1 | $1$ |
| $1$ | 保留一个 $e$ | $2.718$ |
| $2$ | 正整数时可看作 $e\times e$ | $7.389$ |
| $-1$ | 负号表示取倒数：$e^{-1}=1/e$ | $0.368$ |

“重复相乘几次”只解释**正整数指数**。它不能直接解释 $e^{-1}$ 或 $e^{0.5}$；这些写法是数学家在保留乘方法则的前提下向负数和小数指数扩展后的定义。一般的 $a^b$ 还要检查允许输入：在实数范围内，负底数配某些小数指数不一定有实数结果；softmax 固定使用正底数 $e$，因此任意实数 $z$ 都可以计算。对 softmax，先记住三件事就够：$e^z$ 对每个实数 $z$ 都大于 0；$z$ 越大，$e^z$ 越大；负指数给出介于 0 与 1 之间的正数，不是负数。单个 $e^z$ 还不是概率，必须再除以所有候选乘方结果的总和。

## 为什么必须先做指数运算再除总和

这两步不是任意装饰。归一化权重需要非负且总和为 1，而 logits 可以是任意实数：

1. $e^{z_i}>0$，先把每个任意实数变成正权重。
2. 再除以所有正权重之和，使结果严格归一化。
3. 两个候选的权重比满足 $w_a/w_b=e^{z_a-z_b}$，所以 logit 差控制相对优势。

| 改掉什么 | 立即发生什么 | 反向小例子 |
|---|---|---|
| 去掉指数运算，只做 $z_i/\sum_jz_j$ | 负 logit 可能变成负权重，分母还可能为 0 | `[-1,2] / 1 = [-1,2]`，既有负数又有大于 1 的数 |
| 去掉分母，只保留 $e^{z_i}$ | 都是正数，但总和不受约束，不能保证为 1 | `[0,1] -> [1,2.72]`，总和约 `3.72`；`[-\ln2,-\ln2] -> [0.5,0.5]` 虽碰巧为 1，仍没有执行归一化 |
| 给所有 logits 加同一常数 $c$ | 权重不变，因为分子分母都多乘 $e^c$ | `[0,1]` 与 `[10,11]` 得到相同权重向量 |

这些性质说明 softmax 为什么能把相对分数变成非负且总和为 1 的权重向量；在互斥且穷尽的候选事件上，它可以参数化分类概率分布。它们不证明 softmax 是所有任务唯一或最优的归一化方法。

假设两个候选的 logits 是 $[0, 1]$：

1. 做指数运算，得到约 $[1.00, 2.72]$。
2. 总和约 $3.72$。
3. 各自除以总和，得到约 $[0.27, 0.73]$。

softmax 保留有限 logits 的排序，并把 logit 差映射为权重比：若 $z_a-z_b=\Delta$，则 $w_a/w_b=e^{\Delta}$。在词表概率模型中可写成 $p_a/p_b=e^{\Delta}$，但它不证明 0.73 是“现实中 73% 正确”；这只是模型在当前输入、参数和候选词表下分配的 next-token 概率质量。若要讨论整段答案的长期正确率，必须先另行定义**答案级置信分数、什么算答案正确、目标人群和评测窗口**，再用独立样本检查相近分数对应的正确率。校准只能调整这个已定义分数与该事件频率的匹配，不能自动把单个 token 的 softmax 概率变成整段答案的事实正确率。

给所有 logits 同时加上或减去同一个数，softmax 权重不变。例如 `[1000,1001]` 可先减去最大值 `1001` 变成 `[-1,0]` 再计算，这样更不容易发生数值溢出。这里改变的是计算方式，没有改变两个候选的相对差。

## 温度改变选择分布

温度 $T>0$ 时，常计算 $\operatorname{softmax}(z_i/T)$：$T<1$ 放大 logit 差，分布更集中；$T>1$ 缩小差异，分布更平坦。它不改变 logits 的高低顺序；当有限 logits 不全相等时，改变正温度会改变 softmax 分布，而 `[0,0]` 这类全同分输入在任意 $T>0$ 下仍为 `[0.5,0.5]`。softmax 只产出分布：后续若直接按它采样，温度会改变抽样概率；若取最大项，或随后还有 top-k、top-p 等处理，最终选择行为还取决于这些规则。

不写温度等价于固定 $T=1$，并不表示 softmax 缺了一项而失效。$T$ 的职责是控制分布锐度，不负责修正错误排序；原本错误候选分数最高时，调温度不能凭空补回知识。

**$T=0$ 不能直接代入除法公式。** 数学上可以研究 $T\to0^+$：若只有一个 logit 取得最大值，权重趋向该项为 1、其余为 0；若有 $m$ 个并列最大项，极限在这 $m$ 项上各为 $1/m$。这仍不是带某种固定并列裁决规则的贪心算法。软件接口对 `temperature = 0` 没有统一数学语义：可能拒绝该值、忽略温度、切换到确定性选择，或采用其他专门行为，必须以具体接口文档为准。

2. 把 `[0,1]` 同时加 10，候选排序和 softmax 权重会改变吗？

<details><summary>核对</summary>

两个候选完全同分，所以权重是 `[0.5,0.5]`；若它们是互斥且穷尽的类别，也可称预测概率为 `[0.5,0.5]`。同时加 10 不改变差值、排序和 softmax 权重。
