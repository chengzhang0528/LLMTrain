# LLMTrain：零基础大模型开放课程

这是一套面向数学和编程基础薄弱学习者的开放课程。课程从文本语言模型的基础闭环出发，继续延伸到实际模型案例、后训练、可靠性、多模态、软硬件系统与前沿研究；知识库持续更新，但每条学习路线都有明确的能力出口。

## 第一次来：直接开始

如果你还不知道该选什么路线，不用先看地图，也不用先理解整个目录。按下面三步走：

1. 打开 [D01：大模型到底是什么](01-14天理论课/D01-大模型到底是什么.md)。
2. 学完一课后，只跟随页尾的“下一课”继续；公式卡住时再查[数学急救包](03-数学急救包/)。
3. 完成 D01-D14 后进入 [D15：未训练基线](02-第3周实战/D15-确定目标与跑通基线.md)，沿同一个案例读到 D21。

这就是零基础默认路线。它不要求安装环境、编程或实际训练模型，也不要求按 21 个自然日完成。完整阶段、跳读判断和学习边界都在[从这里开始](00-从这里开始/)一页内。

## 课程结构

| 层 | 回答的问题 | 主要入口 |
|---|---|---|

## 基础闭环完成后

- 用自己的话解释 `数据 -> token -> Transformer -> 概率 -> 文本`。
- 区分预训练、监督微调、偏好对齐、RAG 和 Agent，知道何时不该训练模型。
- 看懂损失、学习率、batch、epoch、过拟合等训练日志。
- 沿一份预生成的小型 Decoder-only Transformer 记录解释数据、张量、训练和生成。
- 用验证损失、固定提示词和对照实验判断模型是否真的变好。
- 审查配置、检查点说明、样例、指标和模型卡是否足以支持复现结论。

这不是课程终点。完成基础闭环后，从[学科地图](00-从这里开始/学科地图.md)选择与你当前问题最相关的专题，不需要顺序读完其他分支。

> 课程中的“理解”是指能够解释、比较、判断证据和识别错误。学习者只在网页内阅读、观察动效、计算和答题；不安装环境、不执行命令、不编程，也不实际训练或部署模型。
