# 数字漫画：梯度下降的旋钮

> **学习导航**：承接 D03 的 loss、梯度和学习率；本页把一次参数更新拆成“测量 -> 找方向 -> 走小步 -> 复测”。完成后应能从一个标量例子算出新参数，并解释为什么下降一步不等于已经找到最优值。

## 为什么要学这一页

训练不是“模型看一遍题就自动变聪明”，而是优化器根据当前误差修改参数。只看“梯度是方向”仍然太抽象；把数字走完，才能判断符号、学习率和新 loss 是否互相一致，也能看出过大的步子为什么会越过低点。

## 先预测

设模型只有一个参数 `w`，输入为 `2`，目标为 `6`，当前 `w=1`，学习率为 `0.05`。先猜：

1. 当前预测偏小，梯度应该是正还是负？
2. 一步更新后，`w` 会变大还是变小？
3. 新预测还没有到 `6`，这一步是否可能仍然有效？

## 四格：一次更新循环

### 第一格：先测 loss

```text
预测 = w × 输入 = 1 × 2 = 2
目标 = 6
loss = (预测 - 目标)² = (2 - 6)² = 16
```

当前预测小于目标。loss 是当前位置的误差测量，不是“模型整体质量”的完整报告。

### 第二格：梯度举方向牌

```text
∂loss/∂w = 2 × (预测 - 目标) × 输入
          = 2 × (-4) × 2
          = -16
```

梯度为负，表示在当前位置附近，增大 `w` 会让 loss 降低。梯度不是直接要加上的奖励分数；更新规则会沿负梯度方向走。

### 第三格：按学习率走一小步

```text
新 w = 旧 w - 学习率 × 梯度
     = 1 - 0.05 × (-16)
     = 1.8
```

学习率决定这一步有多大。同一个梯度配上过大的学习率，可能越过低点；过小则进展很慢。

### 第四格：回到输入重新测量

```text
新预测 = 1.8 × 2 = 3.6
新 loss = (3.6 - 6)² = 5.76
```

新 loss `5.76` 小于原来的 `16`，所以这一步有效；它不需要一次就把预测推到 `6`。真实训练会同时更新很多参数，并由 AdamW 等优化器进一步调整步幅，但因果顺序仍是先算梯度，再执行更新。

## 本页验收

遮住四格，换一个数字重做：`w=1`、输入 `3`、目标 `9`、学习率 `0.01`。

1. 初始预测和 loss 是多少？
2. 梯度的符号是什么？请写出 `2 × (预测 - 目标) × 输入`。
3. 更新后 `w` 是多少？新 loss 是否比原来小？

核对：预测为 `3`，loss 为 `36`；梯度为 `2×(-6)×3=-36`；新 `w=1-0.01×(-36)=1.36`，新预测 `4.08`，新 loss `24.2064`，确实下降但还没有到目标。若把负梯度直接代入“加法”而没有减号，回看第三格的更新规则。

## 方法边界

- 这是一个可手算的单参数平方误差示例，用来检查更新方向，不代表 Transformer 的完整 loss 或优化器实现。
- 梯度描述当前位置附近的变化，不能保证每一步都下降，也不是通往全局最优的地图。
- 参数更新发生在训练阶段；普通推理只读取固定参数，temperature 等解码设置不会替代训练更新。
